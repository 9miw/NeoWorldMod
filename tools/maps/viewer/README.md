# NeoWorld Map Review

เปิด `start.cmd` (ต้องมี Node.js) แล้วเปิด URL ที่แสดง โดยปกติเป็น http://127.0.0.1:8765
ปิดด้วย Ctrl+C ในหน้าต่างคำสั่ง เครื่องอื่นใน LAN ใช้ URL `LAN:` ที่แสดง

เครื่องมือนี้แสดงรายการแมพที่ AI สร้างและบันทึกไว้ เลือกแมพเพื่อดู 3D หมุน ซูม ดูมุมบนหรือมุมผู้เล่น และตัดความสูงเพื่อตรวจภายใน หน้าเว็บและ API อ่านอย่างเดียว

รายการอ่านจากโฟลเดอร์แมพภายใน `maps/<ชื่อ>` และ `maps/preview-exports/<ชื่อ>` ที่มี `map-manifest.json`, `level.dat` และ `region/` ไม่อ่านผังประกอบใน `maps/layouts`

พรีวิวอ่านบล็อกจากไฟล์ Anvil จริง ไม่สร้างแมพใหม่เมื่อเลือกดู หาก AI เพิ่มหรือแก้แมพแล้ว กดรีเฟรชรายการเพื่อโหลดข้อมูลล่าสุด รองรับแมพ Java 1.21.1 ที่สร้างด้วยเครื่องมือโปรเจกต์นี้ โหลดหน้าต่างพื้นที่สูงสุด 512 × 512 และข้อมูลไม่เกิน 48 ล้านช่องต่อครั้ง

ชื่อแสดงและคำอธิบายใช้ `name`/`description` ใน manifest ถ้าไม่มีจะใช้ชื่อโฟลเดอร์ รูปแบบ manifest เดิม (`footprint`, `floorY`, `rooms[].center`) ยังใช้ได้

กำหนด `origin: [worldX, worldZ]` ใน manifest เพื่อเลือกจุดเริ่มต้นของพื้นที่พรีวิว รวมถึงพิกัดติดลบ `footprint` กำหนดขนาดพื้นที่จากจุดนั้น ชื่อห้องและ Spawn ยังคงใช้พิกัดโลกจริง ตัวอ่านแปลงเป็นพิกัดภายในพรีวิวให้ ส่วนไฟล์ region ไม่ถูกย้ายหรือแก้ไข หากไม่มี origin จะใช้ `[0,0]` ตามเดิม

รายการ Cronus · Spawn (BreadBuilds) เปิดดูได้ครบขอบเขตชังก์ที่อยู่ในสำเนา แสดงผังย่อให้แตะเลือกจุดหรือกรอก X/Z และกลับ Spawn `-24 31 -8` ได้ ไม่เชื่อมอ่านโลกเซิร์ฟเวอร์สด

WASD เคลื่อนในมุมผู้เล่น, Q/E ลง/ขึ้น, Shift เร่ง ไม่มีการชนกำแพง

พรีวิวใช้ Texture, Blockstate และโมเดล JSON ของ Minecraft 1.21.1 จาก client.jar ที่ติดตั้งในเครื่อง อ่าน parent, variants, multipart, ทิศทาง, UV, แผ่นบน/ล่าง, รูปทรงบันได และส่วนเชื่อมของรั้ว/กระจก แยกส่วนโปร่งใสและวาดเป็นชังก์เพื่อลดหน่วยความจำ ไม่มีการดาวน์โหลดหรือเผยแพร่ client.jar ทั้งไฟล์

ค่าเริ่มต้นหา client.jar ใน `.gradle/caches/neoformruntime/artifacts/minecraft_1.21.1_client.jar` ของผู้ใช้ ตั้ง `MAP_VIEWER_CLIENT_JAR` หากติดตั้งที่อื่น ต้องใช้รุ่น 1.21.1 ไม่รองรับ Texture ของม็อดหรือ resource pack ภายนอกในตอนนี้

แสงยังเป็นแสงพรีวิวและใช้สีไบโอมพื้นฐาน Texture เคลื่อนไหวใช้เฟรมแรก ของเหลวใช้ผิวประมาณ กล่อง ป้าย เตียง และ shulker ที่เกมวาดด้วย renderer พิเศษยังใช้รูปทรงสำรอง (ไม่มีข้อความบนป้ายหรือภาพเคลื่อนไหวเปิดกล่อง) หน้าเว็บแจ้งจำนวนชนิดที่ใช้แบบสำรอง จึงยังไม่เหมือนภาพในเกมทุกจุด

มือถือและจอแคบไม่เกิน 850px แสดงพรีวิวเต็มพื้นที่หน้าจอ แผงเครื่องมืออยู่ในปุ่ม ☰ แตะพื้นหลังหรือปุ่ม × เพื่อปิด นิ้วเดียวหมุน สองนิ้วเลื่อนภาพ และบีบ/กางสองนิ้วเพื่อซูม ในมุมผู้เล่น นิ้วเดียวหันมอง สองนิ้วเลื่อนกล้อง และบีบเพื่อเดินเข้า/ออก

เครื่องมือไม่เรียก AI ระหว่างดู ภาพ 3D ไม่ใช่ตัวเรนเดอร์ของ Minecraft ไฟล์แมพและผังที่สร้างไว้ก่อนหน้านี้ยังเก็บอยู่

ตรวจสอบ: `node --test tools/maps/viewer/test.cjs tools/maps/viewer/gestures.test.cjs tools/maps/viewer/block-models.test.cjs tools/maps/viewer/view-chunks.test.cjs tools/maps/viewer/world-navigation.test.cjs`

ทุกชังก์ใช้โมเดลบล็อกรายละเอียดเต็ม พื้นที่ที่โหลดแล้วเก็บไว้ตลอดการดูแมพเดียวกัน เลื่อนกลับมาใช้ข้อมูลและ GPU buffer เดิม โดยโหลดพื้นที่ใหม่ต่อเพิ่ม หน่วยความจำเพิ่มตามพื้นที่ที่เปิดดู เปลี่ยนแมพหรือรีเฟรชหน้าเพื่อเริ่มใหม่

ทยอยสร้างชังก์ใกล้กล้อง (มือถือรัศมีประมาณ 144 บล็อก จอปกติ 192 บล็อก) และเก็บชังก์ที่สร้างแล้ว วาดพื้นที่สะสมทั้งหมดที่อยู่ในมุมกล้อง ใช้พิกัดโลกป้องกันชังก์ซ้ำ และเก็บ Texture แยกตามชุดทรัพยากรเพื่อให้พื้นที่เดิมแสดงถูกต้องหลังเลื่อนข้ามหน้าต่าง

ตั้ง `fullWorld: true` ใน manifest เพื่อให้ค้นขอบเขตทั้งหมดจาก header ของไฟล์ region โดยไม่อ่านบล็อกทั้งโลกพร้อมกัน มือถือใช้หน้าต่าง 384 × 384, จอปกติ 512 × 512 หากข้อมูลแนวตั้งมากเกินเพดานจะลดหน้าต่างเป็น 320 × 320 เมื่อกล้องใกล้ขอบหน้าต่างจะโหลดพื้นที่ถัดไปแล้วปรับพิกัดภายในโดยคงตำแหน่งกล้องในโลกไว้ พื้นที่ที่ไม่มีข้อมูลชังก์เป็นพื้นที่ว่างและไม่มีการสร้างโลกใหม่

ตัวอ่านชังก์รองรับทั้ง schema `sections/block_states` ปัจจุบัน และ schema เก่า `Level/Sections/Palette/BlockStates` รวมการจัดบิตแบบ dense ของเวอร์ชันก่อน 1.16 โดยไม่แก้ไขไฟล์ต้นฉบับ ชังก์เก่าที่บันทึกแต่ไม่มีบล็อกจะแสดงเป็นพื้นที่ว่าง
