# NeoWorld

ม็อด Minecraft **1.21.1 / NeoForge 21.1.248** สำหรับระบบเลเวลและเศรษฐกิจ ใช้ **JDK 21**

## Build และทดสอบ

ตั้ง `JAVA_HOME` ให้ชี้ไปยัง JDK 21 และตั้ง Gradle JVM ใน IDE เป็น 21 เช่นกัน
การกำหนด Java toolchain ในโปรเจคไม่ได้เปลี่ยน JVM ที่ใช้เริ่ม Gradle
Java 26 ทำให้ Gradle 9.2.1 ของโปรเจคนี้พบ `Unsupported class file major version 70`
เมื่อประมวลผล build script ใหม่

```powershell
.\gradlew.bat build
# ใช้เมื่อดาวน์โหลด dependencies ไว้ครบแล้ว
.\gradlew.bat build --offline --no-daemon
# ตรวจเฉพาะ regression checks
.\gradlew.bat regressionTest --offline
```

ไฟล์ม็อดอยู่ที่ `build/libs/neoworld-1.0.0.jar`
`build` เรียก regression checks ผ่าน task `check` โดยอัตโนมัติ
การทดสอบนี้ตรวจขอบเขตเงิน การรวมราคาสองช่อง EXP และการบันทึกข้อมูล
ยังต้องทดสอบ GUI, Mixin และสิทธิ์ LuckPerms ในเกมจริง

## Dependencies

- ต้องติดตั้ง Custom NPCs Unofficial **1.21.1.20251230** (CurseForge file 7411561)
  ทั้ง client และ server เพราะใช้คลาสและ Mixin ของรุ่นนี้โดยตรง
- สภาพแวดล้อมพัฒนามี Create, Epic Fight และ GeckoLib ตาม dependencies ใน `build.gradle`
  Gradle ไม่ได้รวมม็อดเหล่านี้ไว้ภายใน JAR ของ NeoWorld

## ระบบที่มีแล้ว

- เลเวล 1–100 และ EXP พร้อมการบันทึกข้อมูลผู้เล่นและ HUD
- Silver, Gold และ Diamond พร้อมฝากเหรียญอัตโนมัติใน Survival
- คำสั่ง `/level`, `/eco`, `/economy` และชื่อภายใต้ `/neoworld`
- เชื่อมเงื่อนไขเลเวลและการชำระเงินในร้านค้า Custom NPCs
- สิทธิ์ผ่าน NeoForge Permission API: ผู้เล่นใช้ค่าจาก permission handler รวมถึง deny
  เมื่อไม่มี handler เพิ่มเติม สิทธิ์ผู้ดูแลใช้ OP level 2 ตามค่าเริ่มต้นของแต่ละ node
- ไอคอนเงินใช้ texture มาตรฐาน iron nugget, gold nugget และ diamond

ยอดเงินสูงสุดต่อสกุลคือ `9,223,372,036,854,775,807` การฝากที่เกินเพดานจะถูกปฏิเสธ
และเก็บไอเทมไว้ การเพิ่มเงินด้วยคำสั่งที่เกินเพดานจะไม่เปลี่ยนยอดและแสดงข้อผิดพลาด
ร้านค้าปฏิเสธมูลค่าเหรียญที่ไม่เป็นบวกหรือมูลค่ารวมที่เกินขอบเขต
เมื่อใช้สองช่องชำระด้วยสกุลเดียวกันจะตรวจยอดรวมตามมูลค่าจริงของแต่ละช่อง

## งานตามแผนที่ยังไม่เปิดใช้งาน

EXP จากมอนสเตอร์/เควสต์, เงินดรอปจากมอนสเตอร์, การเพิ่ม Epic Fight Attributes ตามเลเวล,
การจำกัดอาวุธและสกิล, ระบบพื้นที่และดันเจี้ยนยังเป็นงานใน roadmap
EXP ปัจจุบันเพิ่มผ่านคำสั่งผู้ดูแล เอกสารแนวคิดอยู่ที่ `docs/ARCHITECTURE.md`
แผนพัฒนาเซิร์ฟเวอร์ฉบับอัปเดตตามสถานะโค้ดปัจจุบันอยู่ที่ `docs/SERVER_ROADMAP.md`

## ตรวจในเกมก่อนนำไปใช้

1. ฝากเหรียญปกติและเมื่อยอดเงินเต็ม ตรวจว่าเหรียญไม่หายหากฝากไม่สำเร็จ
2. ตั้งร้านค้าราคา Silver สองช่องที่มีมูลค่าต่อชิ้นต่างกัน ตรวจยอดรวมและยอดที่หัก
3. ทดสอบราคาติดลบ/ล้นจากข้อมูลผิดปกติ ต้องซื้อไม่ได้
4. ตั้ง deny ผ่าน LuckPerms สำหรับคำสั่งดูยอดและคำสั่งผู้ดูแล แล้วตรวจทั้งผู้เล่นทั่วไปและ OP
5. ออกจากเกม เข้าใหม่ ตายและเปลี่ยนมิติ ตรวจเงิน เลเวล และ HUD
