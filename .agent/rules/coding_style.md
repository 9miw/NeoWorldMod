# Coding & Commenting Style Rules

## 1. กฎการเขียนคอมเมนต์ในโค้ด (Code Comments)
* **ภาษาหลัก:** เขียนคอมเมนต์อธิบายโค้ดและเอกสารประกอบเป็น **ภาษาไทย**
* **คำศัพท์เทคนิค / ทับศัพท์:** อนุญาตและแนะนำให้ใช้ทับศัพท์ภาษาอังกฤษหรือศัพท์เทคนิคเฉพาะทางได้ เช่น:
  * `Codec`, `NBT`, `JSON`, `TOML`
  * `Event Bus`, `SubscribeEvent`, `Lifecycle`
  * `Data Attachment`, `Data Component`, `Capability`
  * `Entity`, `ItemStack`, `Block`, `Item`, `Creative Tab`
  * `Packet`, `Network Payload`, `Client`, `Server`, `HUD`, `GUI`
  * `Registry`, `DeferredRegister`, `Holder`

## 2. ความชัดเจนและกระชับ
* อธิบายวัตถุประสงค์ของเมธอด, ฟิลด์, หรือคลาสอย่างกระชับ เข้าใจง่าย
* ไม่ต้องแปลศัพท์เทคนิคจนเสียความหมายเดิม
