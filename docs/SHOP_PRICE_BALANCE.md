## 1. จุดสำคัญที่สุด: เควสต์ประจำวัน

ไฟล์เควสต์1และ3ยังมีLeaveItems=0 จึงหักของเมื่อส่งสำเร็จ แบบปรับเควสต์ให้เก็บของไว้ในเอกสารออกแบบยังไม่ได้ติดตั้งทั้งชุด

| ของที่ส่ง | จำนวน | ร้านรับซื้อต่อชิ้น | มูลค่าโอกาสขาย |
|---|---:|---:|---:|
| ไม้โอ๊ก | 64 | 1 | 64 |
| ข้าวสาลี | 32 | 2 | 64 |
| เหล็กดิบ | 24 | 3 | 72 |
| ถ่านหิน | 32 | 1 | 32 |
| รวม | | | 232Silver |

Quest4จ่ายSilver1ชิ้นมูลค่า100 จึงต่ำกว่าขายของชุดเดียวกันตรงให้ร้าน132Silver และยังมีงานล่าซอมบี้15/โครงกระดูก10เพิ่ม รายการนี้เป็นการเทียบต้นทุนทรัพยากร ไม่รวมของดรอปจากการล่าหรือคุณค่าการเล่นเนื้อเรื่อง

ข้อเสนอ: เลือกระหว่าง(ก)เปลี่ยนงานรวบรวมเป็นตรวจของแล้วเก็บไว้ ตามแบบเควสต์ใหม่ หรือ(ข)ถ้าคงการบริจาค ต้องตั้งรางวัลให้คุ้ม232Silverบวกค่าแรง/การล่า ไม่ควรปรับรางวัลพร้อมปล่อยของไว้โดยไม่ได้ทบทวนรายได้รวม ไม่มีการเลือกหรือแก้ตัวเลขใหม่อัตโนมัติ

## 4. ช่องว่างและความเสี่ยงที่ควรตรวจต่อ

- ร้านอีเทอร์ไม่มีสินค้า ไม่ควรเรียกว่าร้านอาวุธพร้อมใช้งานจากการมีNPC
- ร้านไม้มี16รายการแต่รับซื้ออย่างเดียว ไม่ขายไม้แปรรูปหรือวัสดุก่อสร้างให้ผู้เล่น จึงยังไม่ช่วยระบายเงินสำหรับผู้สร้างบ้าน
- เกษตร ขนแกะ ไข่ น้ำผึ้ง ไม้ และมอนสเตอร์ดรอป เป็นกลุ่มควรเก็บข้อมูลรายได้/ชั่วโมงและปริมาณขายก่อนปรับ ไม่ถือว่ามีช่องโหว่เพียงเพราะทำฟาร์มได้
- ยังไม่ตรวจครบทุกวงจรแปรรูป เช่น สูตรCreate การย้อม/คราฟต์ การเผา การแลกชาวบ้าน และม็อดเสริม จึงไม่รับรองว่าไม่มีarbitrageทุกชนิด
- ยังไม่ตรวจนโยบายจำกัดรับซื้อรายวันหรือเพดานรับซื้อในระบบจริง จึงไม่อ้างว่ามีหรือไม่มี

## ลำดับปรับที่เสนอ

1. แก้ความคุ้มค่าของประจำวันก่อน: ตกลงการหักของหรือเก็บของไว้ให้ชัด แล้วคำนวณรางวัลตามแบบที่เลือก
2. เติมสินค้าอาวุธ/เกราะพื้นฐานและวัสดุสร้างบ้านในร้านเดิม โดยกำหนดต้นทุนการคราฟต์และมูลค่ารับซื้อก่อน
3. เก็บข้อมูลการขายแยกไอเทมและรายได้ต่อชั่วโมงทั้งผู้เล่นใหม่/ผู้มีฟาร์ม ก่อนตัดสินใจปรับราคารับซื้อหรือเพดาน
4. ตรวจสูตรซื้อ→แปรรูป→ขายคืนของMinecraftและCreateที่ตรงกับรายการร้านจริง
5. ทบทวนราคาSkill Bookจากเวลาที่ต้องการให้เข้าถึงและผลผลิตจริง ไม่ใช้จำนวนแถวร้านค้ามาสรุปเงินเฟ้อ

การเก็บธุรกรรมหรือเปลี่ยนกลไก/โค้ดเพิ่มเติมต้องอยู่ในขอบเขตที่ผู้ใช้สั่ง งานนี้วิเคราะห์ข้อมูลราคาและเควสต์เท่านั้น
