# ระบบนำทางเควสต์ Custom NPCs

ใช้คำสั่งผ่าน `/neow questnav` เท่านั้น คำสั่งตั้งค่าอยู่ใต้ `admin` (OP 2) ดูรายการได้ที่ `/neow help questnav` ยกเลิก alias `/questnav` และ `/neoworld` แล้ว

## ตั้งเส้นทาง (แอดมิน OP ระดับ 2 และ Creative)

1. รับบล็อกด้วย `/give @s neoworld:navigation_marker`
2. วางบนพื้นตามถนน ห่างกันประมาณ 5–10 บล็อก เพิ่มจุดตรงทางเลี้ยว ประตู และบันไดได้ถี่ขึ้น
3. จุดที่มีทางเดินผ่านภายใน 10 บล็อกจะเชื่อมสองทิศทางอัตโนมัติ ไม่มีการโหลด chunk ทั้งโลก
4. ใช้ `/neow questnav admin view` แสดงเส้นเชื่อมใกล้ตัวชั่วคราว เพื่อตรวจทางแยกหรือถนนขนาน
5. ตัดการเชื่อมผิดด้วย `/neow questnav admin unlink <x1 y1 z1> <x2 y2 z2>` หรือเพิ่มด้วย `/neow questnav admin link <x1 y1 z1> <x2 y2 z2>` โดยพิกัดต้องเป็นตัวบล็อกนำทาง ทั้งสองคำสั่งบันทึกถาวร

บล็อกแสดงเป็นโคมขนาดเล็กเฉพาะ Creative ผู้เล่น Survival/Adventure/Spectator ไม่เห็นตัวบล็อกและเดินผ่านได้ การวางหรือทุบโดยผู้เล่นต้องมีทั้ง Creative และสิทธิ์ OP ระดับ 2 ไม่ให้ piston เคลื่อนบล็อก

`/neow questnav admin radius <1–16>` เปลี่ยนระยะเชื่อมอัตโนมัติทั้งโลก แล้วจัดคิวคำนวณใหม่สำหรับจุดที่โหลดอยู่ ระยะเริ่มต้น 10 บล็อก การเชื่อมแบบ manual จำกัดไม่เกิน 16 บล็อกและต้องมีทางเดินผ่านเช่นกัน

`/neow questnav admin rebuild` จัดคิวตรวจจุดในมิติปัจจุบันที่โหลดอยู่ทีละชุด เมื่อ chunk โหลดใหม่ระบบตรวจจุดใน chunk นั้นอีกครั้ง เก็บจุดที่ยังไม่โหลดไว้โดยไม่บังคับโหลด chunk

## ผูกจุดหมายกับเควสต์

เควสต์ประเภท Location ใช้บล็อก Waypoint ของ Custom NPCs เป็นเป้าหมายได้อัตโนมัติ ตั้งชื่อบล็อกให้ตรงกับชื่อ Location ในเควสต์ (รองรับทั้ง 3 จุด ไม่สนตัวพิมพ์เล็ก/ใหญ่) แล้วติดตามด้วย `/neow questnav track <questId>` หรือปุ่มติดตาม ไม่ต้อง bind objective ซ้ำ หากตั้ง objective เอง ระบบจะใช้ค่าที่ตั้งก่อน

ระบบเลือกจุดที่ยังไม่สำเร็จ โดยเลือกมิติปัจจุบันและระยะใกล้สุดก่อน เมื่อ Custom NPCs ยืนยันว่าไปถึงแล้วจะเปลี่ยนไปจุดที่เหลือ เมื่อครบแล้วใช้การส่งเควสต์เดิม พิกัด Waypoint ถูกบันทึกเมื่อ chunk โหลดหรือบล็อก tick และเก็บข้ามการ unload/รีสตาร์ต จึงต้องให้พื้นที่ของบล็อกโหลดอย่างน้อยหนึ่งครั้งหลังติดตั้งระบบนี้ ระบบไม่สแกนหรือบังคับโหลดทั้งโลก

ใช้ ID เควสต์จาก Custom NPCs ไม่ใช่ชื่อ NPC ตั้ง `objective` สำหรับจุดทำภารกิจ ส่วนเควสต์แบบ NPC ใช้ `turnin` ที่ตั้งเองก่อน ถ้าไม่ได้ตั้งจึงหาจุดส่งจากชื่อผู้รับส่งใน Custom NPCs อัตโนมัติ

ตัวอย่างสำหรับเควสต์ ID 42: ยืนตรงกลางพื้นที่เป้าหมาย แล้วตั้งรัศมี 5 บล็อก

```text
/neow questnav admin bind 42 objective 5
```

- `bind <questId> objective <radius>` ใช้ตำแหน่งเท้าจริงที่ผู้สั่งยืนอยู่เป็นศูนย์กลาง เช่น จุดล่ามอนสเตอร์ รัศมีถึงเป้าหมาย 1–32 บล็อก
- `bindnpc <questId> objective` หันมอง NPC ที่ต้องไปคุยแล้วพิมพ์คำสั่ง เลือก NPC ตัวแรกใต้เป้าเล็งภายใน 16 บล็อก ไม่เลือกทะลุกำแพงหรือ entity ที่บังอยู่ รัศมีถึง NPC 3 บล็อก
- รูปแบบเดิม `bind <questId> objective <x y z> <radius>` และ `bindnpc <questId> objective <NPC UUID หรือ selector>` ยังใช้ได้สำหรับการตั้งค่าจากพิกัดหรือ selector
- ต้องมีบล็อกนำทางที่เดินเชื่อมถึงจุดหมายได้ภายใน 16 บล็อก จุด `objective` ที่ผูกเองเป็นพิกัดคงที่ หากย้าย NPC เป้าหมายให้ผูกใหม่
- Completion = `Instant`: ทำครบแล้วหยุดนำทาง ไม่มีจุดส่ง
- Completion = `NPC`: อ่านชื่อ NPC ผู้รับส่งจากเควสต์ ถ้าชื่อซ้ำเลือกตัวใกล้ผู้เล่นที่สุดในมิติเดียวกัน หากชื่อที่ตรงอยู่เฉพาะมิติอื่นจะแจ้งให้ไปมิตินั้นเอง
- ถ้าไม่พบชื่อที่ตรง ใช้ NPC ใกล้สุดที่ระบบรู้จักในมิติปัจจุบัน พร้อมแจ้งว่าเป็นตัวสำรองและอาจรับส่งเควสต์ไม่ได้ ไม่มีการเปลี่ยนผู้รับส่งหรือให้รางวัลแทน Custom NPCs
- ตำแหน่ง NPC รู้จักอัตโนมัติเมื่อ NPC โหลดหรืออัปเดตขณะอยู่ในพื้นที่ที่โหลดอยู่ จำตำแหน่งล่าสุดข้ามการ unload/restart ได้ ต้องให้พื้นที่ NPC โหลดอย่างน้อยหนึ่งครั้งหลังติดตั้งระบบนี้ ไม่บังคับโหลด chunk ทั้งโลก
- ตั้งจุดส่งเองได้ด้วย `/neow questnav admin bindnpc 42 turnin` ขณะมอง NPC หรือ `/neow questnav admin bind 42 turnin 3` ขณะยืนที่จุดส่ง (รองรับรูปแบบ UUID/พิกัดเดิมด้วย) ระบบใช้จุดนี้ก่อนการค้นหา NPC อัตโนมัติ แม้จุดนี้อยู่ไกลกว่า หากทางขาดหรืออยู่ต่างมิติจะไม่สลับไป NPC อื่นเอง
- Completion = `Instant` ยังคงจบทันทีแม้มี `turnin` บันทึกไว้ จุดส่งที่ตั้งเองเปลี่ยนเฉพาะปลายทางนำทาง ไม่เปลี่ยนผู้รับส่งหรือวิธีรับรางวัลของ Custom NPCs
- `unbind <questId>` ลบการผูกจุดหมายของเควสต์นั้น

## ผู้เล่น

เมื่อรับเควสต์ใหม่จาก Custom NPCs ระบบจะติดตาม **เควสต์ที่รับล่าสุดอัตโนมัติ** แทนเควสต์ก่อนหน้า ใช้ลำดับการรับจริง ไม่ใช่ ID เควสต์ หากรับหลายรายการใน tick เดียวจะเลือกอันสุดท้ายที่เพิ่มสำเร็จ เควสต์ที่สคริปต์ยกเลิกการรับจะไม่เปลี่ยนการติดตาม

หากเควสต์ใหม่ยังไม่มี `objective` ระบบเลือกเควสต์ใหม่ไว้แต่แจ้งว่ายังนำทางไม่ได้ เมื่อแอดมินตั้งจุดหมายจึงเริ่มคำนวณตามเดิม เควสต์ Instant ที่จบทันทีไปแล้วจะไม่เริ่มการนำทาง

กด **L** เพื่อเปิดรายการเควสต์ Custom NPCs เลือกเควสต์ แล้วกด **ติดตาม** ใต้รายการฝั่งซ้าย หน้าต่างจะเปิดค้างและเริ่มนำทางเควสต์ที่เลือก เมื่อเซิร์ฟเวอร์ยืนยันว่าติดตามอยู่ ปุ่มจะเปลี่ยนเป็น **เลิกติดตาม** กดซ้ำเพื่อหยุดได้ หากเลือกเควสต์อื่น ปุ่มจะแสดง **ติดตาม** สำหรับเควสต์นั้น ปุ่มปิดใช้งานเมื่อยังไม่เลือกเควสต์ ไม่มีเควสต์ หรือผู้เล่นตาย/เป็นผู้ชม หากเซิร์ฟเวอร์พบว่าเควสต์ไม่มีจุดหมายหรือไม่ได้รับเควสต์แล้ว จะแจ้งเหตุผลในแชต

ยังเลือกเควสต์อื่นด้วยปุ่มหรือคำสั่งได้ และหยุดติดตามได้เช่นเดิม การหยุดจะไม่เปิดติดตามเองซ้ำ จนกว่าจะรับเควสต์ใหม่อีกครั้ง:

```text
/neow questnav track 42
/neow questnav stop
```

เลือกติดตามครั้งละหนึ่งเควสต์ที่รับแล้ว เส้นแสงแกนขาวขอบฟ้าอมเขียวเห็นเฉพาะผู้ติดตาม แสงไหลไปข้างหน้าตามทาง แสดงช่วงใกล้ตัวไม่เกิน 24 บล็อกและค่อยจางช่วงไกล เปลี่ยนไปจุดส่งเมื่อ Custom NPCs ระบุว่าทำเป้าหมายครบ ไม่ขึ้นกับการตั้งค่าจำนวน particle

เมื่อถึงบริเวณเป้าหมายเส้นทางหยุดแสดง แต่วงแหวนปลายทางยังแสดงถ้าพื้นที่รองรับ หากออกห่างโดยยังทำเควสต์อยู่จะนำทางต่อ ส่งหรือยกเลิกเควสต์แล้วล้างการนำทาง ออกจากเกมต้องเลือกติดตามใหม่ การตายซ่อนเอฟเฟกต์ชั่วคราว เป้าหมายต่างมิติจะแจ้งชื่อมิติและรอให้ผู้เล่นไปเอง

เซิร์ฟเวอร์อ่านสถานะจาก Custom NPCs โดยไม่แก้ความคืบหน้าหรือให้รางวัล และไม่คำนวณเส้นทางของผู้ติดตามแล้ว ส่งกราฟบล็อก/เส้นเชื่อมครั้งแรกเมื่อเข้าเกม จากนั้นส่งเฉพาะจุดหรือเส้นเชื่อมที่เปลี่ยนตาม revision เป้าหมาย (มิติ พิกัด รัศมี และขั้นทำ/ส่งเควสต์) ส่งเฉพาะเมื่อค่าเปลี่ยน ส่วนหยุด/ส่ง/ยกเลิกเควสต์ส่งคำสั่งล้างเป้าหมาย ไม่มีการส่งจุดเส้นแสงทุก 0.5 วินาทีหรือการหมดอายุ 2 วินาทีแล้ว

Client คำนวณเส้นทางจากตำแหน่งตัวเองเมื่อกราฟ/เป้าหมายเปลี่ยน เดินห่างจุดคำนวณเดิม 2 บล็อก หรือครบ 1 วินาทีเพื่อตรวจสิ่งกีดขวาง สร้างจุดภาพใกล้ตัวทุก 0.25 วินาที แล้ววาดแสงไหลทุกเฟรม การตรวจพื้นใช้ chunk cache ที่โหลดจริงและไม่โหลด chunk เพิ่ม พื้นที่ไกลที่ยังไม่โหลดใช้เส้นเชื่อมในกราฟไปก่อน แล้วตรวจพื้นจริงเมื่อเข้าใกล้

กราฟแบ่งเป็นหน้าที่มีขอบเขตและใช้ครบทุกหน้าก่อนสลับข้อมูลชุดใหม่ หากข้อมูลขาดหรือ revision ไม่ตรง client ขอ snapshot ใหม่ได้ โดย server จำกัดคำขออย่างน้อย 5 วินาทีต่อครั้ง ขณะข้อมูลไม่เปลี่ยนไม่มี packet นำทางส่งซ้ำ ทั้ง client และ server ต้องใช้ network protocol 34


## ข้อมูลและข้อจำกัด

- ข้อมูลกราฟ เส้นเชื่อม ระยะเชื่อม และจุดหมายเควสต์อยู่ใน `data/neoworld_quest_navigation.dat` ของโลก สำรองพร้อมโลก ไม่เก็บในฐานข้อมูลผู้เล่น
- รายชื่อและตำแหน่ง NPC ที่เคยโหลดอยู่ใน `data/neoworld_navigation_npcs.dat` ของโลก อัปเดตตำแหน่งที่โหลดอยู่ทุก 40 ticks และลบเมื่อ entity ถูกทำลาย; NPC ที่ยังไม่โหลดใช้ตำแหน่งล่าสุดที่เคยรู้จัก
- ทางโค้งใช้ได้เมื่อมีพื้นที่ยืนและช่องเดินเพียงพอ ถ้าโค้งตัดสิ่งกีดขวางจะใช้แนวตรงระหว่างจุดที่แอดมินวางไว้
- ถนนขนานอาจมีพื้นที่โล่งเชื่อมถึงกันได้ ระบบจึงอาจเชื่อมข้ามถนน ต้องตรวจด้วย `view` แล้วตัดเส้นเชื่อมตามต้องการ
- ตัวตรวจทางเดินใช้ขนาดผู้เล่นปกติ ไม่รองรับว่ายน้ำ กระโดดข้ามช่อง ปีนบันไดแนวตั้ง เปิดประตูปิดอัตโนมัติ หรือขนาดตัวพิเศษ ปิดประตูจะถือว่าทางถูกขวาง
- หากเปิดประตูหรือแก้ถนนหลังจากระบบตัดการเชื่อมแล้ว ใช้ `rebuild` เพื่อเชื่อมอัตโนมัติใหม่
- มีปุ่มติดตามในสมุดเควสต์ Custom NPCs แล้ว ยังไม่มีลูกศร HUD
- เอฟเฟกต์เส้นแสงใช้วัสดุ unlit สามชั้นเลียนขอบเรืองแสง ไม่ได้เปิด bloom post-processing หรือส่อง block light ไปที่ถนน ภาพจำลองอยู่ที่ `docs/gui/navigation/quest-light-ribbon-approved.png` ยังต้องเปรียบเทียบ screenshot จริงในเกม

## ตรวจสอบ

```text
.\gradlew.bat compileJava questNavigationRegressionTest regressionTest
```

ทดสอบกราฟ การตัดเส้นเชื่อม พิกัดต่างมิติ ทางอ้อม เส้นโค้ง สถานะเควสต์ทำซ้ำ และ NBT save/load ได้โดยไม่เปิดเกม ส่วนการมองเห็น Creative เทียบ Survival บันไดจริง และวงจรรับ/ทำ/ส่งเควสต์สองผู้เล่น ต้องทดสอบในเกมเพิ่มเติม
