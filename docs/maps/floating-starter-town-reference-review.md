# ผังเทียบภาพก่อนสร้างใหม่

สถานะ: ผังเสนอสำหรับตรวจสัดส่วน ยังไม่ใช่การอนุมัติพิกัดใหม่หรือแมพที่สร้างเสร็จ

เปิด `/reference-plan` บนเว็บตรวจแมพ เพื่อเทียบกรอบที่ไล่จากภาพกับผังมุมบน เปิดเส้นประ V3 เดิมได้ คลิกโซนหรือแถวตารางเพื่อเน้นพื้นที่เดียว

ข้อมูลต้นฉบับ: `tools/maps/viewer/reference-plan/plan.json` เก็บกรอบภาพแบบพิกเซลและผังโลกแบบบล็อกแยกกัน ภาพต้นแบบเป็นมุมมองที่มีความสูงหลายระดับ จึงไม่แปลงกรอบภาพเป็นขนาดพื้นจริงโดยตรง

การแก้จาก V3 ที่เสนอ:

- ขยายปราสาทในแนวกว้าง และแยกอาคารรับรอง ปีกข้าง ลานหน้า ไม่ใช้กรอบเดียวแทนทั้งอาคาร
- โรงตีเหล็กเลื่อนไปด้านหลังตลาด และมีแปลงรูปหลายเหลี่ยม
- ตลาดกว้างขึ้น อาคารสองหลังอยู่ขอบหลัง แผงขายของและสวนอยู่ลานด้านหน้า
- โถงนักผจญภัยกว้างขึ้นและลดความลึกแปลง ให้มีลานหน้าและทางต่อเกาะย่อย
- เกาะประตูมิติเยื้องลงด้านหน้า เชื่อมด้วยสะพานเฉียง
- ลดช่วงถนนว่างระหว่างจุดเกิดกับลานกลาง ไม่ขยายทุกส่วนด้วยตัวคูณเดียว
- ขอบเกาะตามรูปโซนและสวน ไม่ใช้วงรีรองรับสี่เหลี่ยมทั้งหมด

ขนาดแปลงเสนอคือกรอบครอบรูปหลายเหลี่ยม ไม่ใช่พื้นที่ใช้งานสุทธิ ตารางอาคารแยกขนาดภายนอกและขั้นต่ำภายใน ต้องออกแบบทางเข้า บันได และความสูงหลังล็อกผังอีกครั้ง

ยังไม่มีการสร้างโลกใหม่ในขั้นนี้ และยังไม่ได้ตรวจภาพฉายจากโมเดลสามมิติของผังเสนอ จึงยังไม่อ้างว่าตำแหน่งตรงต้นแบบแล้ว
