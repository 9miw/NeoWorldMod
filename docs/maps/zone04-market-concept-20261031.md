# ตลาดล้อมลานน้ำพุ — แบบแนวคิด

ผู้ใช้ยืนยันแนวทางวันที่ 2026-10-31 เพื่อทำมอคอัพ ยังไม่ใช่การอนุมัติแพตช์โลกหรือ deploy

อ้างอิงภาพโลกจริง zone04-market-existing-exterior-20261030.png และผลสำรวจ zone04-market-research-20261030/RESEARCH.md

- ร้านพ่อค้า: กรอบแกนเดิม25×23 หมุน30° ศูนย์X76/Z197 มวลตัวL สองชั้น มีปีกขายสินค้าเตี้ย ระเบียงและค้ำไม้
- ร้านอาหาร: กรอบ17×15 X94–110/Z181–195 มวลแนวนอน หน้าขายเปิด ปีกครัวและปล่อง กันสาดครีม–ส้ม
- ร้านสมุนไพร: กรอบ17×17 X115–131/Z181–197 หน้าจั่วไม่สมมาตร มุขกระจกและกระถาง กันสาดเขียว
- พื้นเดิมY103 ผู้เล่นยืน104 ไม่ย่อสเกลบล็อกหรือขนาดอาคารเพื่อใส่ของตกแต่ง
- รักษาน้ำพุเล็กในตลาด เสนอแผง6จุดแยกกลุ่มละ3ข้างลาน ไม่บังหน้าร้านใหญ่หรือรุกถนนหลักทางตะวันออก
- พื้นหญ้าและทางดิน ขอบหินเฉพาะทางสำคัญ เสนอทางหลักโล่ง5บล็อก ทางเข้าอาคารอย่างน้อย3บล็อก ต้องตรวจระยะจริงหลังวางเสาและสินค้าก่อนรับรอง
- วัสดุไม้เข้ม อิฐดิน/ปูนอุ่น หลังคาred_sandstone_stairs/slab แซมorange_terracotta โคมchain/lantern บานเกล็ดtrapdoor

ภาพสร้างด้วย imagegen เป็นภาพแนวคิดรูปทรงและบรรยากาศ ไม่ใช่ภาพตรวจแมพหรือแปลนที่วัดได้ ห้ามนำตัวเลขจากภาพไปอ้างเป็นการยืนยันตำแหน่งบล็อก ก่อนลงมือยังต้องทำแปลนพิกัด/ภายใน/ระดับ ตรวจNPCและทางเดินล่าสุด แล้วขออนุมัติการแก้เฉพาะพื้นที่
