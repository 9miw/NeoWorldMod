## ไฟล์

- index.html: ผังทุกชั้น กดบล็อกดู XYZ/สถานะ และมุม3Dจากข้อมูลเดียวกัน ใช้งานออฟไลน์ได้
- blocks.json: palette + RLE ครบทุกตำแหน่ง แกนXเดินเร็วสุด ตามด้วยZ แล้วY; พิกัดเริ่ม103,96,30
- blocks.json.gz: สำเนาบีบอัดข้อมูลเดียวกัน
- materials.csv: นับบล็อกที่วางแยกตามสถานะ รวมบริบทภูมิประเทศ ไม่ใช่จำนวนวัตถุดิบคราฟต์
- validation.json: ตรวจ round trip ทุกตำแหน่ง เส้นทาง และ hash แมพไม่เปลี่ยน

## ข้อจำกัด

เป็นแบบเสนอที่ระบุบล็อกแน่นอนสำหรับตรวจและปรับรายละเอียดต่อ ไม่กล่าวว่าเป็นแบบตรงภาพมอคอัพ1:1 และไม่ใช่ไฟล์นำเข้าเกม พรีวิว3Dแสดงบล็อกเต็มเพื่ออ่านมวลอาคาร บันได/ครึ่งบล็อกให้ดู Properties และผังชั้นเป็นหลัก ไม่มีข้อมูล block entities ไม่มีคำสั่งแก้แมพ ยังไม่ได้ทดสอบในเกมจริง
