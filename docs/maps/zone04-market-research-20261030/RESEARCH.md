# โซน 04 — วัสดุและแนวทางออกแบบตลาด

วันที่ 2026-10-30 · งานสำรวจและข้อเสนอเท่านั้น ยังไม่แก้บล็อกหรือ deploy

## ฐานข้อมูลจริง

ตรวจทรัพยากร Vanilla Java 1.21.1 จาก minecraft_1.21.1_client.jar: บล็อกที่เกี่ยวข้อง 69 ชนิด ไม่ใช่รายการบล็อกทั้งหมดของเกมหรือม็อด ดู [blocks.json](blocks.json) และ texture ต้นฉบับใน textures โครงสร้างที่บันทึกเป็นโมเดลแสดงผล ไม่ใช่ collision shape; properties ตัวอย่างไม่ใช่การรับรองค่า default ทุกบล็อก

อาคารตลาดปัจจุบันตรวจข้อมูลโลกและภาพ WebGL แล้ว: ร้านใหญ่แกน 25×23 หมุน 30° ศูนย์ X76/Z197; ร้านอาหาร 17×15 X94–110/Z181–195; ร้านสมุนไพร 17×17 X115–131/Z181–197 พื้น Y103 ผู้เล่นยืน Y104 ร้านเล็กสองหลังใช้ทรงหน้าจั่วและชุดวัสดุใกล้กัน จึงควรแยกมวลอาคารและการใช้งาน ไม่ใช่เปลี่ยนสีอย่างเดียว

## สีที่ต้องระวัง

options.txt ของเครื่องเล่นระบุเปิด Sapixcraft 32x 1.21.10 r1.zip และใส่ชื่อเดียวกันใน incompatibleResourcePacks ด้วย ข้อมูลนี้ยืนยันการตั้งค่าในไฟล์ ไม่ใช่การเปิดเกมทดสอบ ส่วน viewer ใช้ Vanilla จึงต้องตรวจในเกมก่อนรับรองสีสุดท้าย ไม่เปลี่ยน resource pack ในงานนี้

ค่าต่อไปนี้เป็นค่าเฉลี่ย sRGB ของพิกเซลถ่วง alpha ในเฟรม texture แรก ไม่รวมแสงหรือ biome tint:

| Texture | Vanilla | Sapixcraft |
|---|---|---|
| spruce_planks | #735531 | #52371a |
| dark_oak_planks | #432b14 | #362715 |
| red_sandstone ด้านข้าง | #bb631d | #c37d47 |
| orange_terracotta | #a25426 | #a35527 |
| mud_bricks | #89684f | #7d5d47 |
| white_terracotta | #d2b2a1 | #d3b3a2 |

ไม้ใน pack เข้มกว่า Vanilla และหินทรายแดงอ่อนกว่า จึงไม่ควรเลือกสัดส่วนสีจาก viewer เพียงอย่างเดียว

## ชุดวัสดุเสนอ

| ส่วน | บล็อก | วิธีใช้ |
|---|---|---|
| โครงเสาและคาน | spruce_log, stripped_spruce_log, dark_oak_log | แยกโครงรับน้ำหนัก คานยื่นและค้ำ ไม่ลายเสาทั่วผนังเท่ากันทุกหลัง |
| ผนังอุ่น | mud_bricks, packed_mud, white_terracotta | ผนังอิฐ/ปูนอุ่น ใช้ calcite เดิมเฉพาะจุดเด่น |
| ฐานอาคาร | stone_bricks, andesite, stone_brick_stairs/slab | ทำชั้นฐานและบัว ใช้บันไดจริงแทนก้อนเต็มเรียงเป็นขั้นหยาบ |
| หลังคา | red_sandstone_stairs/slab, smooth_red_sandstone_stairs/slab, orange_terracotta | บันไดและ slab ทำชายคา/สัน สีส้มเข้มเป็นแผงหรือจุดแซม |
| กันสาด | white/orange/red/green_wool และ carpet | แยกสีตามร้าน ใช้ carpet เป็นชั้นบาง ไม่สมมติว่ามี wool slab |
| รายละเอียด | spruce_trapdoor, fence, chain, lantern, hanging_sign, pots, barrel | บานเกล็ด ขอบหน้าต่าง ค้ำ ป้าย โคม และสินค้าหน้าร้าน |

ไม่มี orange_terracotta_stairs หรือ orange_concrete_stairs ในทรัพยากร Vanilla 1.21.1 ที่ตรวจ ต้องใช้ชนิดบันไดที่มีจริงและรับความต่างของ texture ไม่สร้างแปลนโดยอ้างชื่อบล็อกที่ไม่มี

spruce_hanging_sign และ decorated_pot ต้องใช้การแสดงผลพิเศษ; viewer ปัจจุบันแสดงบางรายการด้วยโมเดลสำรอง จึงต้องแยกข้อจำกัด viewer ออกจากข้อผิดพลาดในแมพ ถังและป้ายต้องตรวจ block entity เมื่อสร้างจริง งานนี้ยังไม่เพิ่มรายการเหล่านี้ลงโลก

## ผลงานอ้างอิงจากผู้สร้าง

ใช้เพื่อศึกษาประเภทอาคารและรายละเอียด ไม่ได้ดาวน์โหลด ซื้อ หรือคัดลอกแมพ และยังไม่ได้วัดขนาดจาก schematic ภาพบนเว็บไม่ใช่แปลนบล็อก 1:1

- [The Merchant’s Nook — EcoSMP](https://www.planetminecraft.com/project/the-merchant-nook/): ร้านค้าและที่พักแนวยุคกลาง ใช้เป็นแหล่งอ้างอิงประเภทอาคารร้านใหญ่
- [Sunrise Sweets — EcoSMP](https://www.planetminecraft.com/project/sunrise-sweets-medieval-bakery/): เบเกอรีและบ้าน ใช้ศึกษาอัตลักษณ์ร้านอาหาร
- [Leaf & Lumen — EcoSMP](https://www.planetminecraft.com/project/leaf-amp-lumen/): ผู้สร้างอธิบายร้านปรุงยาติดเนิน มีต้นไม้ วัสดุไม้/หิน และสัญลักษณ์ขวดยา แนวคิดที่นำมาประยุกต์ได้คืออ่านชนิดร้านจากภายนอก
- [Medieval Marketplace — LionCheater](https://www.planetminecraft.com/project/minecraft-medieval-marketplace-tutorial/): แหล่งภาพและบทสอนตลาดสำหรับตรวจการจัดกลุ่มแผงก่อนออกแบบใหม่
- [Medieval Madness — Minecraft.net / MythicalSausage](https://www.minecraft.net/en-us/article/medieval-madness): อ้างอิงการประยุกต์ trapdoor ในช่องเปิดและองค์ประกอบอาคาร

การเข้าถึงภาพเดี่ยวจาก static.planetminecraft.com ไม่สำเร็จในการดาวน์โหลดครั้งนี้ จึงไม่อ้างว่าตรวจภาพทุกมุมหรือมีไฟล์ต้นฉบับในโปรเจกต์ ลิงก์ด้านบนเปิดหน้าผลงานและภาพของผู้สร้างได้

## แนวทางเฉพาะร้าน — ข้อเสนอ ยังไม่ใช่แบบอนุมัติสร้าง

1. ร้านใหญ่: อาคารพ่อค้าฐานเดิม 25×23 หมุน 30° ใช้มวลหลักสูงร่วมปีกหน้าร้านเตี้ย ระเบียงและคานยื่น ช่องขายหลายช่วง โครงไม้เข้มและผนังอิฐอุ่น เน้นป้าย/ลังสินค้า
2. ร้านอาหาร: ฐานเดิม 17×15 มวลแนวนอน หน้าร้านเปิดกว้าง มีปีกครัวด้านหลัง ปล่องควัน กันสาดสีครีม/ส้ม และโต๊ะพัก ส่วนครัวต้องมีพื้นที่ใช้งานจริง
3. ร้านสมุนไพร: ฐานเดิม 17×17 หน้าจั่วไม่สมมาตร มุขกระจกด้านข้าง กระถางและชั้นสมุนไพร กันสาดเขียว หากเรือนเพาะไม่พอให้รายงานพื้นที่ขยาย ไม่ย่อขนาดห้องหรือบล็อก

รักษาน้ำพุตลาด แผง 6 จุด ถนนหลัก ทางเชื่อมโรงตีเหล็ก และพื้นที่ NPC/บริการ ต้องตรวจข้อมูลล่าสุดก่อนสร้าง กำหนดพื้นที่เดินหลังวางเสา/โต๊ะจริง ไม่ใช้ขนาดกรอบภายนอกแทนพื้นที่ภายใน

## ขั้นถัดไป

ทำมอคอัพร้านทั้งสามในมุมเทียบกัน พร้อมผังตำแหน่งและรูปตัดระดับ ใช้บล็อกที่ตรวจว่ามีจริง แล้วกำหนดขนาดช่องเปิด/ชายคา/ภายในก่อนขออนุมัติแพตช์แมพ งานสำรวจนี้ไม่เปลี่ยนโค้ด จึงไม่ต้อง compileJava และยังไม่ได้ทดสอบใน Minecraft
