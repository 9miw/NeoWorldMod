- สำรอง dialogs, quests, entities และทะเบียน UUID ก่อนแก้
- ตรวจ ID ว่างและความหมาย enum จากม็อดจริง ใช้ After=1 สำหรับส่งเควสก่อนหน้าแล้ว Active=3 สำหรับเป้าหมาย และ CanStart=6 กันรับซ้ำ
- ใช้ Dialog127–137 เพิ่มตัวเลือกในรากเดิม ไม่เปลี่ยนคำสั่งร้านค้า บริการวาร์ป หรือรางวัลเควส1–5

- คืนเฉพาะไฟล์ที่แก้จากสำรอง และลบเฉพาะไฟล์/UUIDที่งานนี้สร้างเมื่อจำเป็น ห้ามคืน region ทั้งไฟล์ทับความเปลี่ยนแปลงอื่น
