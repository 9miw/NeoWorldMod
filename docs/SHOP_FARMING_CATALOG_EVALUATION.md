# ร้านรับซื้อผลผลิต: รายการและข้อมูลประเมินเศรษฐกิจ

วันที่บันทึก: 20 ตุลาคม 2026 (Asia/Bangkok)

อัปเดตภายหลังในวันเดียวกัน: เพิ่มรับซื้อขนแกะครบทุกสีและของดรอปบางชนิด เพิ่มขายวัตถุดิบปรุงยา และสร้างร้านขาย ID 11–12 ดู [SHOP_MOB_TRADE_EXPANSION.md](SHOP_MOB_TRADE_EXPANSION.md) ตารางในไฟล์นี้เป็นประวัติชุดเริ่มต้น

## ขอบเขตและสถานะ

สร้างร้านที่เหลือตามกลุ่มที่ตกลงในบทสนทนา 6 ร้าน รวมสินค้าใหม่ 46 รายการ เป็นร้านรับซื้อจากผู้เล่นอย่างเดียว (`buy=0`) ใช้ Silver ต่อหนึ่งชิ้น รับซื้อไม่จำกัด ยังไม่เชื่อม NPC และยังไม่สร้าง Dialog ร้านเหล่านี้

ราคาทั้งหมดเป็นค่าตั้งต้นที่ผู้ช่วยกำหนดเพื่อเริ่มเก็บข้อมูล ยังไม่มีผลวัดรายรับจริงรองรับความสมดุล เอกสารเป็นภาพสถานะ ณ วันที่บันทึก ต้องตรวจสถานะเซิร์ฟเวอร์ก่อนเปลี่ยนข้อมูลครั้งถัดไป

ร้านเกษตร ID 4 มีบันทึกแยกใน [SHOP_AGRICULTURE_EVALUATION.md](SHOP_AGRICULTURE_EVALUATION.md) ร้านแร่ฟินน์และร้านอาหารมีอยู่เดิม ไม่ได้เปลี่ยนสินค้าในงานครั้งนี้ ร้านอีเทอร์ไม่ได้รับการเติมสินค้าเพราะยังไม่ได้กำหนดบทบาทสินค้า

## ขอบเขตสินค้าและเหตุผลราคา

- ร้านประมงรับซื้อปลาเป็นไอเทม ไม่ใช่ถังปลา ปลาค็อดและแซลมอนเป็นแบบดิบ ตั้งราคา 2–5 Silver ตามชนิด เป็นสมมติฐานเริ่มต้น ไม่ใช่ผลวัดความหายากบนเซิร์ฟเวอร์
- ร้านปศุสัตว์รับซื้อเนื้อดิบ ไม่ซ้ำกับอาหารปรุงสุกที่ร้านอาหารขาย ขนแกะรับเฉพาะสีขาว ยังไม่รวมอีก 15 สี
- ร้านไม้รับท่อนไม้ Overworld 8 ชนิดและต้นกล้า/ฝัก 8 ชนิด ไม่รวมไม้ลอกเปลือก ไม้แปรรูป ไม้ Nether หรือไผ่ รายการละ 1 Silver เพื่อเริ่มประเมินปริมาณฟาร์ม
- ร้านของมอนสเตอร์รวมถุงหมึกและถุงหมึกเรืองแสงเป็นกลุ่มดรอปจากม็อบ ชื่อร้านไม่ได้หมายความว่าทุกไอเทมมาจากม็อบที่โจมตีผู้เล่น
- ตาแมงมุมอยู่ร้านของมอนสเตอร์รายการเดียว ไม่ลงซ้ำร้านปรุงยา
- ร้านผึ้งรับขวดน้ำผึ้งทั้งขวด ต้องนับต้นทุนขวดแก้วด้วย ยังไม่ได้ทดสอบธุรกรรมว่าจะมีภาชนะคืนหรือไม่ จึงไม่รับรองว่าร้านคืนขวดเปล่า
- ไม่ได้เพิ่มสินค้าทุกชนิดที่ฟาร์มได้ใน Minecraft ชุดนี้ครอบคลุมร้านที่คุยไว้และรายการตั้งต้นสำหรับแต่ละร้าน

## การตรวจสอบที่ทำแล้ว

- ตรวจร้านเดิมและผู้เล่นออนไลน์ก่อนสร้าง มีร้าน ID 1–4 และ Owner ออนไลน์
- สำรอง Inventory และช่องที่เลือกของ Owner ใน command storage `neoworld:remaining_shops_backup` ก่อนใช้ช่องถือของเพิ่มสินค้า
- คอนโซลยืนยันสร้างร้าน ID 5–10 และเพิ่มสินค้าครบ 46 รายการ หมายเลข 26–71 ไม่พบคำสั่งเพิ่มสินค้าถูกปฏิเสธเรื่องราคา
- คำสั่งเพิ่มสินค้าผ่านการตรวจราคาข้ามร้านของระบบสำหรับ ItemStack และสกุลเงินเดียวกัน ไม่ใช่การตรวจสูตรคราฟต์หรือสมดุลเศรษฐกิจทั้งหมด
- คืนและตรวจ Inventory ตรงกับก่อนทำงาน: ช่อง 0 ไม้ NPC 1, ช่อง 1 พรมสีเทาอ่อน 1, ช่อง 2 ไม้แท่ง 2; ช่องที่เลือกเป็น 0
- เปิดหน้าร้านในเกมครบทั้ง 6 ร้าน ตรวจชื่อร้านและการแสดงรายการ สุ่มเห็นทูลทิปเนื้อกระต่าย 3, ท่อนไม้อะเคเซีย 1, ตาแมงมุม 2 และน้ำตาแกสต์ 8 Silver พร้อมสถานะไม่จำหน่าย
- สั่ง `save-all flush` สำเร็จ พบ `Saved the game` เวลา 21:08:35 ตามเวลาที่แสดงในคอนโซล
- ยังไม่ได้ทดลองขายจริง ตรวจการหักไอเทม/เพิ่มเงิน หรือทดสอบหลังรีสตาร์ต
- เป็นการตั้งค่าร้านผ่านคำสั่งและเขียนเอกสาร ไม่มีการเปลี่ยนโค้ด จึงไม่ได้คอมไพล์

## แนวทางประเมินในอนาคต

เก็บจำนวนที่ขายได้จริงต่อชั่วโมงและเงินที่ร้านจ่าย แยกการเล่นเริ่มต้น ฟาร์มกลาง และฟาร์มอัตโนมัติ บันทึกขนาดฟาร์มและระยะเวลาที่โหลดพื้นที่ ใช้สูตร `จำนวนขายต่อชั่วโมง × ราคารับซื้อ` แล้วเทียบกับร้านเกษตร ร้านแร่ และค่าอาหารของผู้เล่น

ติดตามเป็นพิเศษ: ฟาร์มมอนสเตอร์/เอ็นเดอร์แมน ฟาร์มขนแกะและไข่ ฟาร์มต้นไม้ ฟาร์มเบลซ และฟาร์มผึ้ง เพราะปริมาณขายอาจมากแม้ราคาต่อชิ้นต่ำ ระบบยังไม่มีโควตารายวัน จึงต้องประเมินจากผลผลิตและเงินเข้าสู่ระบบจริง

ก่อนเปลี่ยนราคาให้ตรวจการซื้อจากร้านอื่นแล้วนำมาขาย รวมถึงสูตรคราฟต์และแปรรูป การผ่านตัวตรวจราคาของระบบไม่ได้ยืนยันว่าไม่มีเส้นทางทำกำไรจากทุกสูตร

ก่อนถือว่าทดสอบครบ ให้ทดลองขายสินค้าทีละชนิดในจำนวน 1 และจำนวนที่เมนูรองรับ ตรวจยอดเงิน ไอเทม กรณีของไม่พอ คอมโพเนนต์พิเศษ และยืนยันว่าร้านไม่ขายสินค้าออกให้ผู้เล่น
