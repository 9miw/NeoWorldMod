# โครงสร้างโลกร่วม

## หน้าที่รับผิดชอบ

เอนจินใช้ซ้ำอยู่ใน `world.structure` รับผิดชอบคิวจับภาพเดียว เครื่องมือเลือก สแกน Structure Block แบบมีหมายเลข แบ่ง/โหลดเทมเพลต วาง ตรวจพื้นที่ทับซ้อน/NBT ก่อนวาง จองไฟล์ generated อัปเดตแบบมีเวอร์ชัน ยืนยันลบ เก็บไฟล์ย้อนหลัง และแค็ตตาล็อกแมปร่วม

แค็ตตาล็อกเป็น SavedData ของ Overworld ที่ `data/neoworld_structures.dat` ไฟล์ `.nbt` ที่สร้างคง ID และตำแหน่งเดิมในโลก ไม่แก้บล็อกต้นทางระหว่างจับภาพ คงออฟเซ็ตหลายชิ้นและเนมสเปซชัดเจน ไม่ย้ายเทมเพลตที่แพ็กมาทางกายภาพ

## คำสั่ง

ทุกคำสั่งด้านล่างต้องมี OP ระดับ 2 ใช้กิ่งคำสั่ง `world admin structure` ที่เทียบเท่าได้ด้วย คำสั่งโครงสร้าง Dungeon/PvP เดิมคงเป็นอะแดปเตอร์

```text
/neoworld world structure tool
/neoworld world structure pos1
/neoworld world structure pos2
/neoworld world structure selection
/neoworld world structure cancel
/neoworld world structure save shared_mine
/neoworld world structure scan other:maps/mine
/neoworld world structure list
/neoworld world structure update neoworld:structures/shared_mine
/neoworld world structure delete neoworld:structures/shared_mine
/neoworld world structure place neoworld:structures/shared_mine confirm
```

`tool` ให้แท่งไม้จับภาพ คลิกซ้ายเลือกมุมแรก คลิกขวาเลือกมุมสอง `save` เขียนหนึ่งชิ้นต่อทิก ไม่เกิน 512 ชิ้น/8,388,608 บล็อก แต่ละแกนแบ่งเป็นเทมเพลตมาตรฐาน 48 บล็อก ไม่เชื่อม Dungeon/PvP ให้ แท่งไม้เลือกแบบเก่ายังใช้ได้ คำสั่งทั้งสามตระกูลใช้การเลือกและคิวงานเดียวกัน ยกเลิกจากตระกูลใดก็ยกเลิกงานผู้เล่นนั้น

`scan` ให้เล็ง Structure Block ที่บันทึกหมายเลขลงท้าย `_01` ภายในแปดบล็อก อ่านบล็อกควบคุมเนมสเปซ/พรีฟิกซ์ตรงกันในรัศมี 256 แล้วเก็บตำแหน่งสัมพัทธ์ scan ไม่จับภาพเทมเพลตใหม่ หมายเลขต้องไม่ซ้ำ ต่อเนื่อง และไม่เกิน 512 พฤติกรรมสแกนเดิมอาจโหลดชังก์ในรัศมี จึงควรใช้ในพื้นที่ก่อสร้างที่เตรียมไว้แทนช่วงใช้งานหนาแน่น

`update` จับภาพรีวิชันใหม่ เก็บเลย์เอาต์เก่าใต้ ID แบ็กอัป และเชื่อมผู้ใช้แมปครบชุดใหม่ให้กลับเป็นยังไม่ผ่านตรวจสอบ/DRAFT การอ้างอิงบางส่วนและ Dungeon/PvP ที่ใช้งานขัดขวางการอัปเดต `delete` ต้องคลิกยืนยันภายใน 30 วินาทีโดยผู้เล่นเดิม และปฏิเสธไฟล์เทมเพลตที่เชื่อม/ใช้ร่วม/ไม่ว่าง ไฟล์ generated ย้ายเข้า `world_structure_backups` พร้อมการย้อนกลับ แทนลบถาวร
`place ... confirm` วางที่ตำแหน่งแอดมินปัจจุบันและอาจแทนบล็อก ต้องยืนยันชัดเจน คำสั่งวางทั่วไปนี้ไม่บังคับมาร์กเกอร์ DATA เฉพาะฟีเจอร์

## การตั้งชื่อและเชื่อมโยง

- ชื่อสั้น World ใหม่: `shared_mine` -> `neoworld:structures/shared_mine`
- ชื่อสั้น Dungeon เก่ายังหมายถึง `neoworld:dungeon/<name>`
- ชื่อสั้น PvP เก่ายังหมายถึง `neoworld:pvp/<name>`
- ไม่เขียน `namespace:path` เต็มใหม่ ใช้ ID เต็มเมื่อเชื่อมแมป World ใหม่กับฟีเจอร์เดิม โดยเฉพาะเมื่อมีชื่อสั้นในโฟลเดอร์เก่าด้วย

```text
/neoworld dungeon admin set silme structure neoworld:structures/shared_mine
/neoworld pvp admin set arena01 structure neoworld:structures/shared_mine
```

## การย้ายข้อมูลและระบบที่ใช้งาน

เมื่อเซิร์ฟเวอร์เริ่ม `WorldStructureIntegration` นำเข้าแค็ตตาล็อก Dungeon/PvP เก่าครั้งเดียว ตรวจข้อขัดแย้งโดยไม่ทับต้นฉบับทั้งคู่ และผูก API ข้อมูลเดิมกับแค็ตตาล็อกร่วม ไฟล์ฟีเจอร์ต้นฉบับคงเป็นแหล่งย้ายข้อมูล ตัวบ่งชี้ต้นทางที่บันทึกถาวรป้องกันแมปที่ลบกลับมาหลังรีสตาร์ต ID ขัดกันและมีชิ้นต่างกันทำให้หยุดย้ายพร้อมข้อผิดพลาดชัดเจน แกนหลักยังไม่ทำงานจนการเชื่อมระบบเริ่มสำเร็จ

`StructureConsumers.Consumer` ให้ฟีเจอร์ห้ามอัปเดต/ลบและรับคอลแบ็กเชื่อมใหม่ Dungeon คงข้อกำหนดมาร์กเกอร์ กฎสล็อต/โหมด เวฟ/บอส รางวัล และความพร้อม PvP คงมาร์กเกอร์ทีม ขอบเขตสนาม การตรวจสอบ การทยอยวางสนาม และกู้คืน ไม่แทนการวางเฉพาะทางแบบมีขอบเขตด้วยตัววางทั่วไปแบบซิงโครนัส รายการแค็ตตาล็อก PvP ไม่รวมแมปทั่วไปที่แทนภายในขอบเขตชิ้นสนามไม่ได้

ระบบเชื่อมใหม่ต้องลงทะเบียนตัวป้องกันก่อนเปิดใช้ และใช้บริการจับภาพสำหรับการเปลี่ยนข้อมูลที่ต้องตรวจ คลาสแค็ตตาล็อกเป็นที่เก็บข้อมูลดิบ ไม่ใช่ API อนุญาตสิทธิ์ คอลแบ็กเชื่อมใหม่ต้องไม่โยนข้อยกเว้นหลังตรวจล่วงหน้า หากล้มเหลวผิดคาดจะคงไฟล์และแบ็กอัปที่คอมมิตแล้ว พร้อมรายงานว่าต้องซ่อมการอ้างอิง นี่คือ SavedData ไม่ใช่ธุรกรรมฐานข้อมูลข้ามฟีเจอร์

## การตรวจสอบ

`compileJava` และรีเกรสชัน Dungeon capture/browser/overlap กับ PvP ครอบคลุมการบันทึก/โหลดแค็ตตาล็อกกลาง การย้ายครั้งเดียว ปฏิเสธข้อขัดแย้ง รองรับเนมสเปซเก่า เชื่อมระบบผู้ใช้ใหม่ แบ่งชิ้นมีขอบเขต และย้อนกลับการเก็บไฟล์ ยังไม่ยืนยันการย้ายบนเซิร์ฟเวอร์จริง สแกน Structure Block และวางในเกม สำรองโลกเซิร์ฟเวอร์เดิมก่อนใช้การย้ายข้อมูลนี้
