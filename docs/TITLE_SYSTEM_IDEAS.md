# แนวคิดระบบฉายา NeoWorld

ฉายาได้รับจากสิ่งที่ผู้เล่นทำจริงในเกม และเลือกแสดงเหนือชื่อได้ครั้งละ 1 ฉายา

## ฉายาทั่วไป

| ฉายา | เงื่อนไขได้รับ |
|---|---|
| นักเดินทาง | สำรวจครบ 5 พื้นที่ |
| นักขุดมือใหม่ | ขุดแร่ครบ 500 ก้อน |
| พ่อค้าประจำเมือง | ขายของสำเร็จ 50 ครั้ง |
| ผู้ล่ามอนสเตอร์ | กำจัดมอนสเตอร์ 1,000 ตัว |

## ฉายาหายาก

| ฉายา | เงื่อนไขได้รับ |
|---|---|
| ผู้พิชิตไร้บาดแผล | ชนะบอสโดยไม่รับความเสียหาย |
| ผู้ค้นพบความลับ | พบสถานที่ลับและผ่านบททดสอบ |
| ตำนานแห่งสนามรบ | ชนะกิจกรรม PvP ตามเงื่อนไขพิเศษ |
| ผู้โค่นราชัน | ชนะบอสระดับสูงครั้งแรกของเซิร์ฟเวอร์ |

## ฉายาไม่ดี / เชิงขำ

| ฉายา | เงื่อนไขได้รับ |
|---|---|
| นักนอนพื้น | ตายครบ 100 ครั้ง |
| กระเป๋ารั่ว | เสียเงินจากการตายสะสมถึงเกณฑ์ |
| มิตรแท้ของลาวา | ตกตายในลาวา 20 ครั้ง |
| ผู้แพ้ที่ไม่ยอมแพ้ | แพ้ประลองติดต่อกัน 10 ครั้ง |

## กติกาที่เสนอ

- ฉายาที่ปลดล็อกแล้วเก็บถาวร ยกเว้นฉายาแชมป์ที่เปลี่ยนตามฤดูกาล
- ฉายาไม่ดีให้เลือกใส่เอง ไม่บังคับแสดง
- แยกความหายากจากประเภท เช่น “ผู้รอดจากหายนะ” อาจเป็นฉายาหายากที่ได้จากเหตุการณ์โชคร้าย
- เริ่มจากของตกแต่ง ใช้สีและเอฟเฟกต์เล็กน้อย ส่วนโบนัสค่าสถานะพิจารณาภายหลัง
- หน้าเลือกฉายาแสดงชื่อ คำอธิบาย เงื่อนไข และความคืบหน้า ส่วนฉายาลับแสดงเป็น `???`
- ฉายาแต่ละชื่อควรมีเรื่องราว เช่น “ผู้แพ้ที่ไม่ยอมแพ้” พัฒนาต่อเป็น “วันที่ข้าชนะ” เมื่อกลับมาชนะประลองได้

เอกสารนี้เป็นแนวคิดเบื้องต้น เงื่อนไขที่ยังไม่ระบุตัวเลขหรือรายละเอียดต้องกำหนดก่อนนำไปพัฒนา
