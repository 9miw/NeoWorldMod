# การคืนเกราะที่เลเวลไม่ถึง

ข้อจำกัดเลเวลเดิมยังใช้เหมือนเดิม รวมถึง Data Component REQUIRED_LEVEL ที่มีผลก่อน config ไอเทม

เมื่อ server tick พบเกราะที่ผู้เล่นสวมไม่ได้ ระบบเก็บสำเนาใน Attachment `neoworld:under_level_armor` ก่อนถอดออก แล้วพยายามคืนเข้ากระเป๋า หากกระเป๋าเต็มหรือรับได้บางส่วน ส่วนที่เหลืออยู่ในช่องพัก ไม่โยนลงพื้น

ช่องพักใช้ ItemStack.CODEC และ copyOnDeath จึงรักษาจำนวนและ Data Components ผ่าน save/load และการเกิดใหม่โดยใช้วงจร Attachment เดิม เมื่อตัวละครยังมีชีวิต จะลองคืนทุก 5 ticks ไม่มีปุ่มหรือค่าธรรมเนียมในการรับคืน การใส่คืนกระเป๋าใช้วิธีรวมกอง/หาช่องว่างโดยตรง ไม่เรียก Inventory.add ที่ล้างของคงเหลือในโหมด Creative

ข้อจำกัด: การใส่เกราะผ่านช่อง inventory/คำสั่ง/ระบบภายนอกยังอาจสวมติดช่วงสั้นก่อน server tick ถอดออกตามพฤติกรรมเดิม งานนี้แก้การคืนของเมื่อกระเป๋าเต็ม ไม่ได้เปลี่ยนทุกเส้นทางสวมใส่เป็นการปฏิเสธก่อนใส่

ทดสอบด้วย ItemStack จริงและ registry fixture แบบ headless: สำเนาไม่เปลี่ยนตาม stack ต้นฉบับ, กระเป๋าเต็มไม่ทิ้งข้อมูล, บันทึก/อ่านคืนรักษาชื่อไอเทม, คืนบางส่วนรักษาจำนวนคงเหลือ และไม่คืนซ้ำหลังส่งครบ ยังไม่ได้ตรวจในเกมจริง
