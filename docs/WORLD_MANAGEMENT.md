# ระบบจัดการโลก

ระบบฝั่งเซิร์ฟเวอร์สำหรับย้ายผู้เล่นและรีมิติที่โหลดอยู่ โดยไม่ต้องปิดเซิร์ฟเวอร์ คำสั่งทั้งหมดใช้สิทธิ์แอดมินระดับ 2 หรือ คอนโซล และใช้ `/neow` แทน `/neoworld` ได้

## คำสั่ง

| คำสั่ง | การทำงาน |
| --- | --- |
| `/neoworld world` | แสดงวิธีใช้ |
| `/neoworld world admin list` | แสดงโลกที่โหลดอยู่ โลกที่เคยตั้งรี รอบเวลา และสถานะรี |
| `/neoworld world admin import check <โฟลเดอร์>` | ตรวจ เซฟ ต้นทาง เวอร์ชัน ตัวสร้างโลก ขนาด และ ส่วนหัว ของ รีเจียน |
| `/neoworld world admin import add <โฟลเดอร์> <ชื่อโลก>` | คัดลอกโลก ติดตั้ง ดาต้าแพ็ก และโหลดเข้าเกมทันที ไม่ต้องรีสตาร์ต |
| `/neoworld world admin load <โลก>` | โหลดมิติเข้าสู่เซิร์ฟเวอร์ทันทีโดยไม่ต้องรีสตาร์ต |
| `/neoworld world admin unload <โลก>` | เข้าคิว ถอนโหลด ย้ายผู้เล่นไปจุดปลอดภัย บันทึกข้อมูล แล้วระบายงาน ชังก์ ข้ามหลาย ทิก ก่อนปิดไฟล์ |
| `/neoworld world admin tp <ผู้เล่น> <โลก> [x y z \| random [รัศมี]]` | ย้ายผู้เล่นไปโลก (ไม่ระบุพิกัดจะไปจุดล่าสุดหรือจุดเกิด) หรือสุ่มจุดด้วย `random` รองรับพิกัด `~` และ `^` |
| `/neoworld world admin random <ผู้เล่น> <โลก> [รัศมี]` | ค้นหาจุดสุ่มที่มีพื้นยืนและพื้นที่ว่างก่อนย้ายผู้เล่น (คำสั่งย่อของ `tp ... random`) |
| `/neoworld world admin reset add <โลก> <วัน>` | เพิ่มหรือเปลี่ยนรอบรีอัตโนมัติ เริ่มนับรอบใหม่ทันที |
| `/neoworld world admin reset remove <โลก>` | ยกเลิกรีอัตโนมัติ โดยไม่ลบโลกหรือประวัติรี |
| `/neoworld world admin reset now <โลก> confirm` | เข้าคิวรีทันที แม้โลกนั้นไม่ได้ตั้งรีอัตโนมัติ |

`<ผู้เล่น>` ใช้ชื่อผู้เล่นหรือ ซีเล็กเตอร์ เช่น `@a` และ `@s` ได้ `<โลก>` ใช้ชื่อมิติเต็ม เช่น `neoworld:resource_world`, `neoworld:build_world`, `minecraft:the_nether`, `minecraft:the_end` มีคำแนะนำชื่อโลกขณะพิมพ์

ตัวอย่าง:

```text
/neoworld world admin tp @s neoworld:small_dungeon
/neoworld world admin tp Miw neoworld:build_world 100 80 200
/neoworld world admin tp @s neoworld:resource_world random
/neoworld world admin tp @a neoworld:resource_world random 2500
/neoworld world admin random Miw neoworld:resource_world
/neoworld world admin random @a minecraft:the_nether 500
/neoworld world admin reset add neoworld:resource_world 7
/neoworld world admin reset add minecraft:the_nether 14
/neoworld world admin reset now neoworld:resource_world confirm
/neoworld world admin reset remove minecraft:the_nether
```

รอบรีตั้งได้ 1–3650 วันตามเวลาจริง ระบบจำเวลาหลังรีสตาร์ต หากปิดเซิร์ฟเวอร์เลยกำหนดจะเข้าคิวรีหลังเปิดอีกครั้ง หากสั่งรีด้วยมือในโลกที่ตั้งรีอัตโนมัติ รอบถัดไปจะเริ่มนับจากการรีสำเร็จ คำสั่ง remove ไม่ยกเลิกงานที่เข้าคิวหรือกำลังรีอยู่

## การย้ายผู้เล่น

### นำเข้าโลกภายนอก

รองรับ Overworld จากโฟลเดอร์ เซฟ ของ Minecraft Java เวอร์ชันปัจจุบันและเวอร์ชันเก่าที่ DataFixer ของเซิร์ฟเวอร์สามารถอัปเกรด เมทาดาทา และอ่าน ตัวสร้างโลก ได้ โลก DataVersion 3700 ใช้คำสั่งปกติได้ โดย เมทาดาทา ถูกแปลงบนสำเนาในหน่วยความจำ และ ชังก์ เก่าจะอัปเกรดเมื่อ Minecraft โหลด ไม่แก้ `level.dat` ต้นทาง ไม่รองรับ ZIP, Bedrock หรือการเลือก Nether/End จากต้นทาง วางสำเนาโลกที่ปิดแล้วใน `<server>/world-imports/lobby/` โดยภายในมี `level.dat` และ `region/` ชื่อโฟลเดอร์ใช้ตัวอักษรอังกฤษ ตัวเลข `_` หรือ `-` ส่วนชื่อมิติใช้ `namespace:name` ด้วย a-z, 0-9, `_` หรือ `-` ไม่ใช้ เนมสเปซ `minecraft` และไม่ใช้ชื่อที่มีอยู่แล้ว

```text
/neoworld world admin import check lobby
/neoworld world admin import add lobby neoworld:lobby
```

โลกใหม่กว่าเซิร์ฟเวอร์เปิดได้เฉพาะโหมดทดลองสำหรับ **Java 1.21.2–1.21.3** ต้องระบุ `experimental` ชัดเจนทั้งตอน check และ add:

```text
/neoworld world admin import check lobby experimental
/neoworld world admin import add lobby neoworld:lobby experimental
```

`check` ตรวจ เมทาดาทา, ตัวสร้างโลก และ ส่วนหัว ของ รีเจียน เท่านั้น ยังไม่ลองแปลงทุก ชังก์ ส่วน `add ... experimental` ทำงานบนสำเนาใน พื้นที่พักงาน ตรวจโครงสร้างและข้อมูล พาเลตต์ ของแต่ละ ชังก์ แทนบล็อก/สถานะบล็อกที่ไม่รองรับเป็นอากาศ จัด พาเลตต์ และ ข้อมูลบีบอัดแบบแพ็ก ใหม่ แทน ไบโอม ที่ไม่รู้จักด้วย ไบโอมทุ่งราบ และตัด บล็อกเอนทิตี หรือกองไอเทมที่ เป้าหมาย อ่านไม่ได้ ไม่คัดลอก เอนทิตี/POI จากโลกใหม่ ข้อมูลแสง/แผนที่ความสูง จะคำนวณใหม่ และตัด โครงสร้าง, ทิกที่นัดหมาย, ข้อมูลสร้าง ภูมิประเทศ บางส่วน และข้อมูล จุดเกิด ของ บล็อกสร้างมอนสเตอร์ ที่แปลงข้ามเวอร์ชันไม่ได้ออก

ชังก์ ที่โครงสร้างหรือเวอร์ชันไม่รองรับจะไม่ถูกเขียนลงโลกรอบใหม่ หากไม่มี ชังก์ ที่แปลงได้จะไม่ติดตั้งโลก ช่องที่ถูกข้ามอาจถูก Minecraft สร้างภูมิประเทศใหม่เมื่อโหลด จึงไม่รับประกันว่าแผนที่จะคงเดิมทั้งหมด

รายงานอยู่ใน `<save>/dimensions/<namespace>/<name>/neoworld-import-conversion-report.json` มีจำนวน ชังก์ ที่แปลง/ข้าม บล็อกที่ถูกแทนอากาศ รายการ ไบโอม พาเลตต์ ที่เปลี่ยน บล็อกเอนทิตี/กองไอเทม/โครงสร้าง ที่ลบ และจำนวนฟิลด์ `SpawnData`/`SpawnPotentials` ของ บล็อกสร้างมอนสเตอร์ ที่ตัดออก (`removedSpawnerDataFields`) พร้อมเหตุผลของ ชังก์ ที่ข้ามสูงสุด 256 รายการ ต้นทางไม่ถูกแก้ไข

การ ถอนโหลด จะปิดการเข้าโลกตั้งแต่เข้าคิว ประมวลผลทีละโลก และไม่ให้ โหลด/รีโลกเดียวกันระหว่าง ถอนโหลด แจ้งสำเร็จหลังไม่มีงาน ชังก์ ค้างและปิดไฟล์เสร็จแล้ว หากระบายงานไม่สำเร็จภายใน 60 วินาที หรือการย้ายผู้เล่น/บันทึก/ปิดไฟล์ล้มเหลว จะรายงานข้อผิดพลาดและล็อกโลกไว้ ไฟล์ของโลกที่ถอนออกแต่ยังปิดไม่ได้จะอยู่ในรายการรอปิดตอนหยุดเซิร์ฟเวอร์ ให้ตรวจ ล็อก และแก้สาเหตุก่อนรีสตาร์ต โลกที่ ถอนโหลด อยู่จะยังไม่เริ่มงานรีอัตโนมัติจนกว่าโหลดกลับ

การตรวจและคัดลอกทำบนคิวไฟล์แยกจาก เธรดเซิร์ฟเวอร์ รับครั้งละหนึ่งงาน เมื่อคัดลอกและสร้าง ดาต้าแพ็ก สำเร็จ ระบบจะโหลดโลกเข้าสู่เซิร์ฟเวอร์ทันทีโดยไม่ต้องรีสตาร์ต จากนั้นดู `/neoworld world admin list` และใช้คำสั่ง tp เข้าไปได้ทันที โดยเลือกพิกัดตามจุดเกิดต้นทางที่คำสั่ง check รายงาน หรือใช้ `/neoworld world admin unload <ชื่อโลก>` หากต้องการถอดโลกออกจากหน่วยความจำ และ `/neoworld world admin load <ชื่อโลก>` หากต้องการโหลดกลับเข้ามา การตรวจ ส่วนหัว ไม่ได้ตรวจเนื้อหาบล็อกทุก ชังก์ จึงยังต้องใช้ม็อดบล็อก/ไอเทมให้ตรงกับต้นทาง

สำหรับชื่อ `neoworld:lobby` ไฟล์ที่ใช้งานจริงอยู่ใน `<save>/dimensions/neoworld/lobby/` และมี ดาต้าแพ็ก ลงทะเบียนมิติใน `<save>/datapacks/neoworld-import-<UUID>/` ชื่อ UUID คำนวณจากชื่อมิติให้คงที่ ต้นทางยังอยู่ตามเดิม ไม่มีโฟลเดอร์ เทมเพลต เพิ่ม และไม่เขียนทับไฟล์โลกหรือ ดาต้าแพ็ก ที่มีอยู่ ใช้ `<save>/neoworld/import-staging/` เป็นพื้นที่ชั่วคราวระหว่างติดตั้ง หากงานล้มเหลวอาจมีไฟล์ค้างในพื้นที่นี้ ให้ตรวจ ล็อก ก่อนจัดการไฟล์

คัดลอกเฉพาะไฟล์ `.mca`/`.mcc` ใน `region`, `entities`, `poi` พร้อมข้อมูลอ้างอิงการนำเข้า `neoworld-import.json` ไม่คัดลอก `playerdata`, `level.dat`, สิทธิ์แอดมิน, กฎเกม, สกอร์บอร์ด, แฟ้ม ไอเทมแผนที่ ส่วนกลาง หรือ ดาต้าแพ็ก ของต้นทาง จึงไม่มีการแทนข้อมูลผู้เล่นปัจจุบัน ต้องติดตั้ง dependency ที่จำเป็นไว้ก่อนนำเข้า

ภูมิประเทศใน ชังก์ ที่คัดลอกมาคงเดิม แต่ ชังก์ ที่สร้างเพิ่มใช้ ตัวสร้างโลก ต้นทางกับ ซีด หลักของเซิร์ฟเวอร์ปัจจุบัน อาจเกิดรอยต่อกับแผนที่เดิม รุ่นนี้ยังไม่ตั้งจุดเกิดหรือ ขอบเขตโลก แยกให้อัตโนมัติ หากสั่งรีโลกนำเข้าด้วยคำสั่งรีเดิม จะสร้างภูมิประเทศใหม่ ไม่คืนสิ่งปลูกสร้างต้นฉบับ เนื่องจากไม่ได้เก็บ เทมเพลต

คำสั่ง tp ตรวจขอบเขตและความสูงของโลก แต่ใช้พิกัดที่แอดมินระบุโดยตรง แอดมินต้องเลือกพื้นที่ยืนที่เหมาะสม

คำสั่ง random สุ่มในกรอบสี่เหลี่ยม ±รัศมีรอบศูนย์กลาง ขอบเขตโลก และจำกัดให้อยู่ภายใน border ค่าเริ่มต้น 1000 บล็อก ตั้งได้ 1–10000 บล็อก ทำทีละงานทั้งเซิร์ฟเวอร์ โดยสุ่มตรวจ ชังก์ ที่โหลดอยู่ก่อน 16 ตำแหน่ง หากไม่พบจึงขอโหลดได้ไม่เกิน 16 ตำแหน่ง เว้นการขอโหลดอย่างน้อย 20 ทิก และรอคำขอเดิมเสร็จก่อนขอครั้งต่อไป แต่ละงานมีเวลา 2 นาทีเริ่มเมื่อถึงหัวคิว โดยไม่รอบน เธรดเซิร์ฟเวอร์ รองรับคิวผู้เล่นสูงสุด 32 คน มีคำสั่งสุ่มค้างได้หนึ่งคำสั่งต่อผู้เล่น การสร้าง ชังก์ ใหม่และการโหลดพื้นที่รอบผู้เล่นหลังย้ายยังใช้ทรัพยากรเซิร์ฟเวอร์

จุดสุ่มต้องมีพื้นแข็งและช่องอากาศสองบล็อก หลีกเลี่ยงพื้นลาวา น้ำ magma campfire cactus และ powder snow สำหรับโลกที่มีเพดาน เช่น Nether จะค้นหาพื้นที่ด้านล่างเพดาน หากไม่พบจุดที่ปลอดภัยจะรายงานความล้มเหลวแทนการย้ายผู้เล่น

## การรีโลก

ข้อความเตือนก่อนรีและเริ่มรีส่งเฉพาะผู้เล่นที่อยู่ในมิตินั้น โดยใช้คำนำหน้า `[จัดการโลก]` และไม่แสดงชื่อโลก เช่น `[จัดการโลก] โลกนี้จะรีเซ็ตในอีก 5 นาที กรุณาเก็บของและออกจากโลก` ช่วง 10 → 1 วินาทีใช้ข้อความสั้นโดยไม่มีคำเตือนเก็บของซ้ำ เมื่อรีสำเร็จจะแจ้งเฉพาะผู้เล่นที่ระบบย้ายออกและยังออนไลน์อยู่ หากรีล้มเหลวจะแจ้งผู้เล่นที่ยังอยู่ในโลกนั้นและผู้เล่นที่ถูกย้ายออก ไม่ประกาศไปยังผู้เล่นอื่น ชื่อโลกยังแสดงในคำสั่งแอดมินและ ล็อก เพื่อระบุโลกที่จัดการ

รองรับมิติที่โหลดด้วย `ServerLevel` ปกติ รวมถึงมิติ NeoWorld, Nether และ End ไม่อนุญาตรี Overworld หลักขณะเซิร์ฟเวอร์เปิดอยู่ หรือโลกที่ม็อดอื่นใช้คลาสโหลดโลกเฉพาะ เส้นทางไฟล์โลกต้องอยู่ภายใน เซฟ ไม่เป็น ลิงก์สัญลักษณ์ และไม่ซ้อนกับไฟล์ของอีกมิติ

ก่อนถึงรอบรีอัตโนมัติ ระบบประกาศเตือนที่ 5 นาที, 3 นาที, 30 วินาที และนับถอยหลัง 10 → 1 วินาที แยกตามโลกและไม่ประกาศช่วงเดิมซ้ำในรอบเดียวกันระหว่างเซิร์ฟเวอร์รัน หากเซิร์ฟเวอร์หยุดหรือค้างข้ามช่วงเวลา จะประกาศช่วงปัจจุบันโดยไม่ไล่ส่งข้อความย้อนหลัง คำสั่งรีทันทีไม่รอช่วงแจ้งเตือน เมื่อเข้าคิวรีจะปิดการเข้าโลกนั้น งานรีหลายโลกทำทีละโลก จากนั้นย้ายผู้เล่นไปจุดกลับที่ปลอดภัยนอกโลกที่จัดการรี หรือไปจุดเกิด Overworld บันทึกผู้เล่น ถอนโลกออกจากรายการที่ ทิก ระบายงาน ชังก์ ข้ามหลาย ทิก ก่อนปิดไฟล์และย้ายโลกเก่าเป็น แบ็กอัป แล้วสร้างใหม่ด้วย ตัวสร้างโลก และ ซีด เดิม Nether เก็บไฟล์ใน `DIM-1` และ End ใน `DIM1`; การรี End เริ่มข้อมูล Ender Dragon ใหม่ด้วย

บล็อก สิ่งปลูกสร้าง กล่องเก็บของ และ เอนทิตี ในโลกที่รีจะเริ่มใหม่ ของในตัวผู้เล่นยังอยู่ ผู้เล่นออฟไลน์ที่เข้ารุ่นโลกเก่าจะถูกส่งกลับเมื่อเข้าเกมหรือเกิดใหม่ ระบบเก็บประวัติรุ่นโลกไว้แม้ยกเลิกรีอัตโนมัติแล้ว เพื่อให้ยังตรวจพิกัดเก่าของผู้เล่นได้

ถ้าย้ายผู้เล่นออกไม่ได้ หรือระบาย ชังก์ ไม่สำเร็จภายใน 60 วินาที จะหยุดรีและล็อกการเข้าโลกนั้น พร้อมบันทึกข้อผิดพลาดใน ล็อก ไม่ย้ายไฟล์โลกที่ยังเปิดอยู่ หากโลกถูกถอนจากรายการแล้วแต่รีไม่สำเร็จ จะปิดไฟล์ที่ค้างเมื่อหยุดเซิร์ฟเวอร์ ให้แก้สาเหตุก่อนรีสตาร์ต งานที่ค้างถูกบันทึกไว้และจะดำเนินต่อหลังเปิดเซิร์ฟเวอร์

## ข้อมูลและ แบ็กอัป

### คอนฟิก ข้อความฝั่งเซิร์ฟเวอร์

หลังเปิดเซิร์ฟเวอร์ด้วยม็อดรุ่นนี้ ไฟล์จะถูกสร้างใน `config/neoworld/world-messages.toml` เป็นคอนฟิกฝั่งเซิร์ฟเวอร์ของ NeoForge คำนำหน้าจะถูกเติมให้อัตโนมัติ และ `{seconds}` ใน countdown จะถูกแทนด้วยเลข 10 ถึง 1 ตั้งข้อความใดเป็น `""` เพื่อปิดเฉพาะข้อความนั้น โดยไม่ปิดการรีโลก การกำหนดผู้รับยังเหมือนเดิม

```toml
[messages]
prefix = "[จัดการโลก] "
warning5Minutes = "โลกนี้จะรีเซ็ตในอีก 5 นาที กรุณาเก็บของและออกจากโลก"
warning3Minutes = "โลกนี้จะรีเซ็ตในอีก 3 นาที กรุณาเก็บของและออกจากโลก"
warning30Seconds = "โลกนี้จะรีเซ็ตในอีก 30 วินาที กรุณาเก็บของและออกจากโลก"
countdown = "โลกนี้จะรีเซ็ตในอีก {seconds} วินาที"
preparing = "เตรียมรีโลกนี้ กรุณาเก็บของและออกจากโลก"
starting = "กำลังรีโลกนี้ ย้ายผู้เล่นออกจากโลก"
success = "รีโลกเรียบร้อยแล้ว สามารถกลับเข้าได้"
failure = "รีโลกไม่สำเร็จ ปิดการเข้าโลกชั่วคราว กรุณาแจ้งแอดมิน"
```

- ข้อมูลระบบอยู่ใน `<save>/neoworld/world-management.json` แยกจากมิติที่รี ไม่ใช้ฐานข้อมูลรวมระหว่างเซิร์ฟเวอร์ และแทนไฟล์แบบ อะตอมมิก
- เมื่อใช้ระบบใหม่ครั้งแรก จะย้ายเวลาและจุดกลับจาก `resource-world.json` เดิม หากมี โดยเก็บไฟล์เดิมไว้ หากเป็น เซฟ ใหม่ โลกทรัพยากรที่มีอยู่จะตั้งรีทุก 7 วันเป็นค่าเริ่มต้น
- โลกเก่าอยู่ข้างโฟลเดอร์มิติ เช่น `dimensions/neoworld/resource_world-backup-<timestamp>`, `DIM-1-backup-<timestamp>` หรือ `DIM1-backup-<timestamp>` ไม่มีการลบ แบ็กอัป อัตโนมัติ แอดมินต้องจัดการพื้นที่เก็บตามต้องการ
- การบันทึกหรือปิดไฟล์จำนวนมากอาจทำให้ ทิก ช้าชั่วคราว ม็อดที่เก็บข้อมูลโลกเพิ่มเติมนอกโฟลเดอร์มิติอาจต้องมีกลไกรีของตัวเอง

## การตรวจบนเซิร์ฟเวอร์ทดสอบ

ตรวจตัวแปลงโดยไม่เปิดเกมด้วย `.\gradlew.bat compileJava worldImportCompatibilityRegression` ครอบคลุม DataFixer จริงสำหรับ เมทาดาทา DataVersion 3700 → 3955 (จุดเกิด ชื่อโลก ซีด และ ตัวสร้างโลก), การไม่แก้ต้นทาง, นโยบายเวอร์ชันเก่า/ปัจจุบัน/ใหม่กว่า, พาเลตต์ หลายขนาด, การแทนบล็อกและนับจำนวน, การลบข้อมูล คลัง/บล็อกสร้างมอนสเตอร์ และรายงานจำนวน, รวมถึงอ่าน–เขียน รีเจียน จริงและข้าม ชังก์ ที่โครงสร้างไม่รองรับ ชุดนี้ไม่ทดแทนการทดสอบ ถอนโหลด และการเข้าโลกจากไคลเอนต์จริง

ยังต้องทดสอบก่อนใช้กับ เซฟ จริง: สิทธิ์ผู้เล่นทั่วไป/แอดมิน/คอนโซล, ชื่อผู้เล่นและ ซีเล็กเตอร์, tp และสุ่มใน Overworld/Nether/End/มิติ NeoWorld, เพิ่ม–เปลี่ยน–ยกเลิกรอบหลายโลก, รีด้วยมือโดยไม่เพิ่มรอบก่อน, รีระหว่างมีผู้เล่นและ ชังก์ ที่โหลดอยู่, ผู้เล่นออฟไลน์กลับหลังรี, การย้ายข้อมูลระบบเดิม, และรีสตาร์ตระหว่างรี ตรวจว่าโลกรอบใหม่ไม่มีบล็อกทดสอบเดิม แต่โลกอื่นและของในตัวผู้เล่นยังอยู่

ตรวจแยกกรณีหลายโลกครบกำหนดพร้อมกัน, ไม่พบจุดกลับที่ปลอดภัย, และการเขียนข้อมูลล้มเหลว โดยต้องไม่ประกาศว่ารีสำเร็จก่อนบันทึกสถานะเสร็จ
