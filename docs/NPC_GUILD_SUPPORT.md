## วาเลน

### 121 ทักทาย

ยินดีที่ได้พบ @p ข้าคือวาเลน นักผจญภัยที่แวะมาพักระหว่างการเดินทาง หากอยากแลกเปลี่ยนเรื่องเตรียมตัว ข้ายินดีคุยด้วย

- เจ้ารับฝึกหรือแจกอุปกรณ์ไหม? → Dialog123

- กลับไปถามเรื่องอื่น → Dialog121
- ไว้คุยกันใหม่ → ปิดบทสนทนา
