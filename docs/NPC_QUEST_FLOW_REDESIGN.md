# ออกแบบลำดับเควสต์ใหม่ — ทำครบแล้วจบทันที

วันที่2026-10-27 สถานะ: แบบเสนอ ยังไม่ติดตั้ง ข้อมูลอ้างอิงตรวจจากเซิร์ฟเวอร์จริง

## หลักการ

- ทุกเควสต์สำเร็จเมื่อทำเป้าหมายครบ ไม่ต้องปิดบทสนทนาแล้วคุยซ้ำ ไม่ต้องกลับไปกดส่งกับNPC
- รับขั้นถัดไปอัตโนมัติเมื่อส่งมอบรางวัลสำเร็จ คงIDและประวัติผู้เล่นเดิม ไม่ล้างเควสต์หรือแจกชุดเริ่มต้นซ้ำ
- Locationใช้การเดินถึงWaypoint พูดคุยใช้การเปิดหัวข้อเป้าหมายครั้งเดียว ล่าใช้ยอดหลังรับขั้นนั้น
- งานตรวจจำนวนไอเทมเสนอให้LeaveItems=true ของยังเป็นของผู้เล่น ไม่หักของทันทีที่เก็บครบ ต้องเปลี่ยนคำว่าส่งของ/บริจาคให้ตรงความหมายใหม่
- แสดงเป้าหมายเดียวที่ควรทำต่อในข้อความ ไม่บังคับคุยNPCตัวประกอบ ไม่เพิ่มการวิ่งรับทราบข้อความที่ไม่จำเป็น
- ระบบตรวจLocationกับระบบนำทางเป็นคนละส่วน ต้องตรวจการผูกนำทางจริงก่อนอ้างว่ามีลูกศรหรือเปลี่ยนเป้าหมายให้อัตโนมัติ

## สิ่งที่พบจริงและต้องแก้

Quest5,6,13เป็นInstantอยู่แล้ว ส่วน1–4และ7–12ยังเป็นNpc completion ณเวลาตรวจ มีข้อความพูดถึงการคุยซ้ำ/ปิดหน้าต่างในDialog16,17,19,20,22,23,50,55,58,62,127,128,132,134,135 ต้องอ่านบริบทก่อนแก้ เพราะบางประโยคอาจไม่เกี่ยวกับการส่งงาน

เปลี่ยนเฉพาะฟิลด์completionและข้อความที่เกี่ยวข้อง คงรางวัล เงื่อนไขรับครั้งเดียว ID และเส้นทางเดิม เพิ่มLeaveItems=trueเฉพาะงานรวบรวมที่เปลี่ยนความหมายตามแบบ ไม่ใช้คำสั่งล้าง/finishให้ผู้เล่นเพื่อย้ายสถานะ

## การตรวจที่ต้องทำก่อนรายงานใช้งาน

- สำรองข้อมูลล่าสุดและตรวจความเปลี่ยนแปลงที่ผู้ใช้แก้เองก่อนติดตั้ง
- ตรวจการจบInstantของItem/Dialog/Kill/Locationจากม็อดรุ่นจริง รวมถึงกรณีมีของครบอยู่ก่อนเริ่มขั้น
- ตรวจว่ารางวัลไม่ออกซ้ำ การต่อขั้นเกิดครั้งเดียว ของไม่ถูกยึด และเงื่อนไขเริ่มชุดประจำวันยังถูกต้อง
- ตรวจหรือระบุข้อจำกัดกรณีกระเป๋าเต็มและกรณีเปิดบทสนทนาที่เคยอ่านแล้ว ไม่ยืนยันจากการดูฟิลด์เพียงอย่างเดียว
- ทดสอบเฉพาะกลไกที่เปลี่ยนเมื่อจำเป็น ไม่จำเป็นต้องเดินทุกเควสต์ใหม่ทั้งชุด และไม่แตะบัญชีผู้เล่นจริงโดยไม่มีเหตุจำเป็น
