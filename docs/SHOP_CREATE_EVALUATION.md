## เหตุผลและข้อจำกัดการประเมิน

ขายเครื่องมือและชิ้นส่วนเริ่มต้นเพื่ออำนวยความสะดวก ให้ผู้เล่นผลิตสินค้ามาขายแข่งได้ ไม่ขาย Andesite Alloy, Brass Ingot, Electron Tube, Precision Mechanism, Blaze Burner ที่จับเบลซแล้ว หรือเครื่องจักรขั้นสูงในชุดนี้

ตรวจสูตร Create ที่เกี่ยวข้องในไฟล์มอดจริง: เพลาคราฟต์จาก Andesite Alloy, เฟืองใช้เพลากับไม้, กังหันใช้เพลากับไม้, สายพานใช้สาหร่ายแห้ง, ประแจและแว่นใช้แผ่นทองร่วมกับวัสดุอื่น ราคาที่ตั้งเป็นราคาชิ้นส่วนสำเร็จรูป ไม่ใช่ต้นทุนวัตถุดิบที่คำนวณครบทุกสูตร

ร้านนี้ไม่รับซื้อคืน และคำสั่งเพิ่มผ่านการตรวจราคาข้ามร้านของระบบครบ 7 รายการ แต่ไม่ได้พิสูจน์ว่าไม่มีเส้นทางแปรรูปทำกำไรในทุกมอด ต้องติดตามเวลาหาเงินของผู้เล่น ต้นทุนผลิตจริง และผลต่อการขายของช่างผู้เล่น

## การตรวจสอบ

- ตรวจรายชื่อร้านจริงก่อนสร้าง มี ID 1–12 ยังไม่มีร้าน Create
- คอนโซลยืนยันสร้าง ID 13 และเพิ่มสินค้า #102–108 ครบ
- สำรอง Inventory และช่องที่เลือกของ Owner ใน command storage `neoworld:create_shop_backup`
- ใช้ช่องถือของเพิ่มสินค้า แล้วคืนไม้ NPC; ตรวจ Inventory และช่องที่เลือกตรงกับก่อนทำงาน รวมข้อมูลพิเศษของไอเทมอื่น
- สั่งเปิดหน้าร้านให้ Owner ด้วย `neow shop admin open Owner 13`; ต้องอ้างอิงผลคอนโซลประกอบ ไม่ถือว่าได้ตรวจภาพหน้าร้าน
- สั่ง `save-all flush` และคอนโซลยืนยัน `Saved the game` เวลา 00:56:04 วันที่ 26 ตุลาคม 2026
- ยังไม่ได้ทดลองธุรกรรมซื้อจริงหรือตรวจภาพในเกม และยังไม่ได้ทดสอบหลังรีสตาร์ต
- ไม่มีการแก้โค้ด ไม่ต้องคอมไพล์
