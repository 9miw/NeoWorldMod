# Combat Logout

ผู้ใช้ยืนยันแนวทาง Combat Logout: ติดการต่อสู้ 60 วินาทีหลังทำ/รับความเสียหายจากผู้เล่น และหากออกเกมระหว่างนั้นให้ตัวละครอยู่ต่อ 60 วินาที ออกเกมปกติหายตามเดิม ยกเว้นสนาม PvP

## วิธีดำเนินการ
- เก็บ ServerPlayer ตัวจริงไว้ในโลกเมื่อขาดการเชื่อมต่อ ไม่สร้างสำเนากระเป๋า/Attachment/entity จึงใช้ความเสียหาย การตาย เงิน และไอเทมเดิม
- tick ตัวละครฝั่งเซิร์ฟเวอร์ขณะไม่มี network listener; ปิดเมนูและยกเลิก trade/คิว PvP ทันที และไม่สะสมเวลาลดบาปขณะออกเกม
- ตัวละครยังถูกฆ่าได้ คิวตายของ Killer คิดโทษครั้งเดียว ก่อนนำตัวละครออกและบันทึกข้อมูล
- reconnect: ให้ผ่านการตรวจบัญชี/ban/whitelist ตามเดิม ก่อนเข้าโลกบันทึกและนำตัวที่ค้างออก แล้วโหลดสถานะล่าสุดเพียงชุดเดียว; ไม่สร้างตัวซ้ำระหว่าง handshake
- เวลากลับเข้าเกมต้องคงระยะเสี่ยงที่ยังเหลือไว้ เพื่อไม่ให้ reconnect แล้วออกทันทีเพื่อหลบตัวค้าง
- ตอน shutdown ปิดระบบ retention ก่อนบันทึก/นำตัวค้างออก ไม่ค้างรอ 60 วินาที ไม่สร้าง ghost หลัง restart
- ใช้ actionbar เตือน combat timer ไม่มีหน้าจอ/PNG ใหม่

## ทางเลือก
เลือกเก็บตัวจริงเพราะคงระบบ death/drop/Epic Fight และ Attachment เดิม ตัวแทน NPC ต้องเพิ่มการย้ายไอเทม/สถานะและการกู้คืนที่เสี่ยงต่อข้อมูลซ้ำ จึงไม่เลือก

## การตรวจรับ
ทดสอบเวลาและ transition, การต่ออายุ tag, อายุ body ไม่ต่อจากการถูกตีซ้ำ, reconnect ครั้งเดียว, ขอบเขต mixin ตรงกับ NeoForge 21.1.248; compileJava และ Killer/Profile/PvP/Trade/Economy regression checks ต้องผ่าน การเล่นจริงสอง client ยังต้องตรวจแยก
