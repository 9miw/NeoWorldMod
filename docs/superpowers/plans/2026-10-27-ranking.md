# NeoWorld Ranking Implementation Plan

> **For agentic workers:** Use executing-plans inline, task by task. Preserve unrelated checkout changes; no automatic commits.

**Goal:** Implement approved ranking design A with PvP, Lv./EXP and silver categories.

**Architecture:** Server-only asynchronous saved-player scan merged with live attachments; immutable ranking records, bounded request/response payloads and a correlated client screen. Existing PvP repository remains authoritative.

**Tech Stack:** Java 21, NeoForge 1.21.1, existing PNG widgets and bitmap fonts.

**Spec:** `docs/gui/ranking/DESIGN.md`

## Global Constraints
- No ESC menu edits. No full build. Run compileJava after code changes.
- Window reference 1280x720, independent of GUI Scale. Dynamic data stays outside PNGs.

## Review Focus
- Equal levels with unequal EXP; long silver values; stable exact ties.
- Personal player outside top ten and fewer than three eligible players.
- Offline files, live overrides, corrupt file and unavailable database.
- Stale responses after category change, retry/timeout and rate limiting.
- Thai clipping and hitboxes at actual scaled window dimensions.
