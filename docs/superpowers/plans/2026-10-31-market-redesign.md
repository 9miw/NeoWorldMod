# Market Redesign Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task after approval of the concrete code/map changes. No subagent required.

**Goal:** ปรับตลาดเดิมตามมอคอัพที่ยืนยัน ให้ร้านสามหลังต่างบุคลิก มีพื้นที่ใช้งาน และคงถนน/น้ำพุ/จุดบริการ

**Architecture:** แพตช์โลกเดิมโดย semantic delta เฉพาะพื้นที่ที่อนุมัติ ใช้ NBT helpers เดิม ตรวจ hash ก่อนเขียน ไม่รัน generator ทั้งโลก สร้าง editor และ verifier แยกกัน

**Tech Stack:** Node.js, typed NBT, Minecraft Java 1.21.1, existing textured viewer, Gradle compileJava

**Spec:** docs/maps/zone04-market-concept-20261031.md และภาพ .png ชื่อเดียวกัน ภาพรวมเป็นหลักเมื่อภาพย่อยขัดกัน

## Global Constraints

- โลกเดียว maps/starter_sky_land_spawn_v1; local only ห้ามdeployในงานนี้
- พื้นชั้นล่างY103 ผู้เล่นยืน104 ขนาดแกน25×23หมุน30°,17×15,17×17 ไม่ลด
- รักษาโซนอื่น น้ำพุ95/104/224 ถนนตะวันออก ทางไปโรงตีเหล็ก และป้าย/จุดบริการที่ตรวจพบ
- สำรองนอกmapsและตรวจhashก่อนapply; baselineสำรวจ152512fe1a9ff21ea293a464c56af061565732e1299adc019105c77dc27af09b หากเปลี่ยนต้องสำรวจใหม่
- โค้ดใหม่ต้องได้รับอนุมัติก่อนสร้าง และหลังเปลี่ยนรัน .\gradlew.bat compileJava ไม่full build

## Review Focus

- ภาพย่อยร้านสมุนไพรสูงกว่าภาพรวม: ใช้ภาพรวมกำหนดลำดับสูงต่ำ
- ทางเชื่อมโรงตีเหล็กอยู่ระหว่างร้านอาหารกับสมุนไพร: ห้ามมุข/โครงเสารุกช่องทาง
- ร้านใหญ่หมุน30°: ตรวจกรอบโลกของชายคาจากการ raster จริง ไม่ใช้เพียงขนาดแกน
- บ้านเก่ามีส่วนหลังคาพ้นกรอบผนัง: ลบเฉพาะองค์ประกอบเดิมที่ระบุ ห้ามล้างกรอบสี่เหลี่ยมทับต้นไม้และเสา
- NPCฝั่งserverอาจไม่มีในlocal: สำรวจตำแหน่งบริการอ่านอย่างเดียวก่อนกำหนดเฟอร์นิเจอร์ ไม่อ้างNPCปลอดภัยจากข้อมูลlocalเพียงชุดเดียว
