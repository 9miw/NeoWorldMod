# Loot Box Implementation Plan

> Execute inline in the current checkout. Preserve unrelated work. User has confirmed implementation of animation option 2.

**Goal:** A purchasable, right-click loot box with server-owned rewards and an opening-chest animation.

**Architecture:** Registered item delegates to a server service. A vanilla loot table supplies one reward stack; inventory planning validates consumption and delivery before mutation. A server-to-client payload starts a cosmetic screen with no reward-claim action.

**Tech Stack:** Existing Minecraft 1.21.1 / NeoForge Java 21 project and shared NeoWorld GUI.

**Spec:** `docs/superpowers/specs/2026-11-01-loot-box-design.md`

## Review Focus

Full inventory must not consume a box. A last box may free a usable slot. Offhand boxes do not free a main-inventory slot. Component differences must prevent merging. Closing/disconnecting must not cause loss or a second grant.
