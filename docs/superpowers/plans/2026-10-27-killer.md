# Killer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เพิ่มระบบบาปสะสม หัวแดง สิทธิ์ป้องกันตัว และค่าตายตามแบบที่ยืนยัน

**Architecture:** แยกกติกา Java ล้วนออกจาก event ของ NeoForge เก็บข้อมูลถาวรใน Attachment แยกจากเงิน ซิงค์สถานะจากเซิร์ฟเวอร์สำหรับชื่อและโปรไฟล์

**Tech Stack:** Java, NeoForge ตามเวอร์ชันเดิมของโครงการ, Gradle regressionTest source set

**Spec:** `docs/superpowers/specs/2026-10-27-killer-design.md`

## Global Constraints
- ไม่มีเขตปลอดภัย; ลดบาป 10 ทุก 10 นาทีที่ออนไลน์
- บาปต่อการฆ่า 100; สิทธิ์สวน 60 วินาที; เครดิตสิ่งแวดล้อม 30 วินาที
- ค่าตาย Silver 5% สูงสุด 1,000 ปัดลง; ไม่แตะเงินสกุลอื่น
- ไม่แก้การเปลี่ยนแปลงเดิมของผู้ใช้ ไม่ commit/push โดยอัตโนมัติ
- ก่อนแก้โค้ดอ่าน skill ที่เกี่ยวข้อง: neoworld-persistence, neoworld-network, neoworld-gui, test-driven-development และ docs/gui/NEOWORLD_GUI_STYLE.md
- หลังแต่ละชุดแก้โค้ดรัน `.\gradlew.bat compileJava`; ไม่รัน full build

## Review Focus
- การสวนกลับไม่สลับผู้เริ่มโจมตี: ทดสอบในงาน 1
- ความตายที่ถูกยกเลิกหรือสนามย้ายผู้เล่นออกก่อน handler: ทดสอบในงาน 2
- เวลา/บาปหายเมื่อ clone และ logout: ทดสอบในงาน 2

- เงินน้อยมากและยอด long สูงสุด: ทดสอบในงาน 1 และ 2

**Interfaces:** `KillerRules.deathPenalty(long silver): long`, `KillerRules.isRed(int sin): boolean`, `KillerRules.addKillSin(int sin): int`; `KillerCombatTracker.recordDamage(UUID attacker, UUID victim, long tick): void`, `canDefend(UUID defender, UUID attacker, long tick): boolean`, `lastAttacker(UUID victim, long tick): Optional<UUID>`, `clear(UUID player): void`.

- [x] เขียน regression assertions ก่อน: penalty(19)=0, penalty(20)=1, penalty(20000)=1000, penalty(Long.MAX_VALUE)=1000; บาป 0+100=100 และไม่ overflow

- [x] รัน `.\gradlew.bat killerRegressionTest` ให้เห็น failure จากกติกาที่ยังไม่มี แล้วเขียน implementation ให้ผ่าน
