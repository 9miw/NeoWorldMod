# เสียงตอบสนองของดันเจี้ยน

เซิร์ฟเวอร์ส่งเสียงเหตุการณ์แบบส่วนตัวผ่านการแจ้งเสียง Vanilla ในหมวด PLAYERS ผู้เล่นปรับระดับเสียง Master / Players ได้ ไม่มีแอสเซ็ตเสียง แพ็กเก็ตกำหนดเอง เอนทิตีพลุจริง หรือความเสียหายเพิ่ม เสียงคลิก Vanilla เดิมของ NeoButton คงเดิมและไม่เล่นคลิกซ้ำ

| เหตุการณ์ | เสียง Vanilla |
| --- | --- |
| สร้างห้องโซโล/ปาร์ตี้ | เก็บลูกแก้วประสบการณ์ |
| เข้าร่วมห้อง | เสียง chime ของ Note Block |
| พร้อม / ยกเลิก | pling เสียงสูง / bass เสียงต่ำ |
| ห้องเต็มและทุกคนพร้อม | chime สูงขึ้น แทนเสียงพร้อมธรรมดา |
| เข้าสำเร็จหลังเทเลพอร์ต | เติมกรอบประตู End |
| เกิดเวฟสำเร็จ | ระฆังสั้น |
| เกิดบอสสำเร็จ | มังกรคำรามเบา ๆ |
| ชนะ | ยิงพลุ ระเบิดพลุสองครั้งตามเวลา แล้ว chime (ทิก 0/6/12/18) |
| แพ้ / หมดเวลา / รันล้มเหลว | bass เสียงต่ำ |

เล่นเสียงเฉพาะเมื่อสถานะเปลี่ยนจริง ไม่เล่นจากการโพลหรือซิงก์ข้อมูลห้อง แต่ละห้องและเสียงมีคูลดาวน์ห้าทิก ป้องกันการสลับพร้อมถี่ ๆ เสียงระหว่างรันไม่ส่งให้ผู้เล่นที่กลับแล้วหรืออยู่นอกมิติรัน
เสียงชัยชนะที่หน่วงไว้ต้องตรวจว่าห้อง รันที่ใช้งาน สมาชิก และมิติยังตรงกัน การออกห้อง ออกจากเกม หรือล้างงานยกเลิกเสียงที่เหลือ ผลลัพธ์ถูกทำเครื่องหมายครั้งเดียวต่อรัน เพื่อไม่ให้เฟสรางวัลที่หมดเวลาภายหลังเล่นเสียงแพ้ขัดกัน คิวทำงานทุกทิกแม้ไม่มีรัน และล้างคูลดาวน์ของห้องที่หมดอายุ

เสียงชุดแรกนี้ไม่เพิ่มบี๊บนับถอยหลัง เตือนเวลาเหลือน้อย เอฟเฟกต์ตาย/ออก การแจ้งล้มเหลวเฉพาะ หรือเสียงหีบ ส่วนเหล่านี้คงพฤติกรรม Vanilla หรือระบบปัจจุบันโดยไม่ซ้อนเอฟเฟกต์

การตรวจสอบ: compileJava และ dungeonBrowserRegressionTest ครอบคลุมรีซอร์สเสียง เวลาและลำดับ ระดับเสียงเบา ระดับเสียงสูงต่ำของสถานะพร้อมที่ต่างกัน และค่าของแผนที่ผ่านการตรวจสอบ สมดุลเสียงจริง การค้นหารีซอร์ส Vanilla และผู้รับ/เวลาของหลายผู้เล่นยังต้องทดสอบฟังในเกม ยังไม่มีการยืนยันเสียงในเกม
