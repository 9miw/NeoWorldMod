# แผนพัฒนาเซิร์ฟเวอร์ NeoWorld
เอกสารนี้สรุปสถานะระบบเซิร์ฟเวอร์จากโค้ดปัจจุบัน และจัดลำดับงานที่ควรทำต่อเพื่อไปสู่เซิร์ฟเวอร์ MMORPG x เซอร์ไววัล ที่เปิดทดสอบได้จริง

## สถานะระบบตอนนี้

### พร้อมใช้งานในม็อด

- ระบบเลเวลผู้เล่น 1-100 พร้อม EXP, การเลเวลอัป, เอฟเฟกต์เสียง/อนุภาค และการซิงค์ HUD
- ระบบบันทึกข้อมูลผู้เล่นด้วย NeoForge Data Attachments เช่น เลเวล, EXP และยอดเงิน
- ระบบเงิน 2 สกุล: Silver และ Diamond
- ฝากเหรียญอัตโนมัติเมื่อเก็บจากพื้นหรือมีเหรียญในกระเป๋า เซอร์ไววัล
- ป้องกันยอดเงินล้นเพดาน `long` และปฏิเสธธุรกรรมผิดปกติ
- HUD แสดงเลเวล, EXP และยอดเงินฝั่ง ไคลเอนต์
- คำสั่ง `/neoworld`, `/neow`, `/level`, `/eco` และ `/economy`
- สิทธิ์ ผ่าน NeoForge Permission API รองรับ ตัวจัดการสิทธิ์ เช่น LuckPerms และ ค่าทดแทน เป็น ระดับ OP
- เชื่อม Custom NPCs Availability ให้ใช้เลเวล NeoWorld แทน เลเวล EXP ของ Vanilla
- เชื่อมร้านค้า Custom NPCs ให้จ่ายด้วยยอดเงินในระบบ เศรษฐกิจ แทนการใช้ไอเทมเหรียญในกระเป๋า
- มี การทดสอบรีเกรสชัน ครอบคลุมกรณีเงินล้น, การคิดราคาร้านค้า 2 ช่อง และการบันทึกข้อมูลหลัก

### พร้อมเป็นฐาน แต่ยังต้องทดสอบในเกมจริง

- GUI/HUD ฝั่ง ไคลเอนต์ บนหน้าจอหลายขนาด
- Mixin กับ Custom NPCs รุ่นจริงทั้ง ไคลเอนต์ และ เซิร์ฟเวอร์
- การปฏิเสธ/อนุญาตสิทธิ์ ผ่าน LuckPerms
- การซิงค์ข้อมูลหลังออกเกม เข้าใหม่ ตาย และเปลี่ยนมิติ
- การวางร้านค้าราคาหลายช่องและหลายสกุลใน Custom NPCs

### ยังไม่เปิดใช้งาน

- EXP จากการฆ่ามอนสเตอร์ เควสต์ ดันเจี้ยน และบอส
- เงินดรอปจากมอนสเตอร์หรือกิจกรรม
- การปรับแอตทริบิวต์ Epic Fight ตามเลเวล
- การจำกัดอาวุธ ชุดเกราะ และสกิลตามเลเวล
- ระบบโซน, เขตปลอดภัย, เขตป่า, ดันเจี้ยน และ เรด
- ระบบ โพรเทกต์ที่ดิน / การป้องกัน / อาณาเขต PvP
- ตลาดผู้เล่น, ภาษี, ช่องทางดูดเงินออกจากระบบ และ บทลงโทษเมื่อตาย
- เควสต์หลัก, เควสต์รายวัน, ความก้าวหน้า NPC และ ตารางรางวัล
- การตั้งค่า สมดุล ผ่าน คอนฟิก ภายนอกสำหรับทีมดูแลเซิร์ฟเวอร์

## แผนพัฒนา ต่อไป

### ระยะ 0: ทำระบบหลักให้เสถียร ก่อนเปิดให้ทีมลอง

เป้าหมาย: ทำให้ระบบที่มีแล้วไม่พังเมื่อใช้จริงบนเซิร์ฟเวอร์

- ทดสอบ บิลด์ ด้วย JDK 21 และ NeoForge 1.21.1
- ทดสอบ ไคลเอนต์ + เซิร์ฟเวอร์แยก พร้อม Custom NPCs รุ่นที่กำหนด
- ตรวจ ฝากเงินอัตโนมัติ เมื่อยอดเงินเต็ม ต้องไม่ทำให้เหรียญหาย
- ตรวจร้านค้า NPC กรณีราคาปกติ, ราคาติดลบ, ราคาล้น และสองช่องสกุลเดียวกัน
- ตรวจ LuckPerms สำหรับคำสั่งผู้เล่นและคำสั่งผู้ดูแล
- เขียน รายการตรวจสอบ สำหรับทีมทดสอบในเกมจริง

ผลลัพธ์ที่ต้องได้: ไฟล์ JAR ใช้บนเซิร์ฟเวอร์ทดสอบได้ และระบบเลเวล/เงิน/ร้านค้าพื้นฐานเชื่อถือได้

### ระยะ 1: วงจรความก้าวหน้าของผู้เล่น

เป้าหมาย: ให้ผู้เล่นมีเหตุผลในการเก็บเลเวล

- เพิ่ม รางวัล EXP จากมอนสเตอร์
- เพิ่ม รางวัล EXP จากคำสั่ง/ระบบเควสต์ของ Custom NPCs
- เพิ่มตาราง EXP ตามชนิดมอนสเตอร์และระดับพื้นที่
- เพิ่มข้อความ/Actionbar เมื่อได้รับ EXP
- เพิ่ม คอนฟิก สำหรับปรับสูตร EXP และ เลเวลสูงสุด โดยไม่ต้องแก้โค้ด
- เพิ่ม คำสั่ง สำหรับตรวจ/รีเซ็ต ความก้าวหน้า ในช่วงทดสอบ

ผลลัพธ์ที่ต้องได้: ผู้เล่นเล่น PvE หรือทำเควสต์แล้วเลเวลเพิ่มได้จริงโดยไม่ต้องให้แอดมินเพิ่ม EXP เอง

### ระยะ 2: วงจรเกมเพลย์เศรษฐกิจ

เป้าหมาย: ทำให้เงินมีที่มาและที่ใช้ ไม่เฟ้อเร็วเกินไป

- เพิ่ม รางวัลเหรียญ/เงิน จากมอนสเตอร์, เควสต์ และดันเจี้ยน
- กำหนด อัตรา เงินตามโซนและระดับความยาก
- เพิ่ม ช่องทางดูดเงินออกจากระบบ เช่น ค่า เทเลพอร์ต, ค่าซ่อม, ค่าธรรมเนียมตลาด, ค่าเข้า ดันเจี้ยน
- เพิ่ม ล็อก ธุรกรรมสำคัญสำหรับตรวจ ช่องโหว่
- เพิ่ม คำสั่ง/เครื่องมือแอดมิน สำหรับดูยอดรวมเศรษฐกิจเบื้องต้น
- ทำ ตารางสมดุล สำหรับรายรับ/รายจ่ายต่อชั่วโมงของผู้เล่น

ผลลัพธ์ที่ต้องได้: ผู้เล่นหาเงินและใช้เงินวนในระบบได้ โดยทีมแอดมินมีเครื่องมือตรวจเงินเฟ้อ

### ระยะ 3: เชื่อมระบบ Epic Fight

เป้าหมาย: เชื่อมเลเวลกับพลังต่อสู้แบบ แอ็กชัน RPG

- เพิ่ม การปรับแอตทริบิวต์ตามระดับ ตามเลเวล เช่น stamina, การฟื้นฟูสตามินา, เกราะต้านชะงัก และ พลังชีวิตสูงสุด
- จำกัดอาวุธ/ชุดเกราะตามเลเวลขั้นต่ำ
- เพิ่ม ทูลทิป บอกเลเวลที่ต้องการเมื่อถือหรือชี้ไอเทม
- ป้องกันการใช้อาวุธที่เลเวลไม่ถึงใน การต่อสู้ จริง
- วางตารางปลดล็อก ช่องสกิล หรือ หนังสือสกิล ตามช่วงเลเวล
- ทดสอบ สมดุล กับ Epic Fight ใน PvE และ PvP

ผลลัพธ์ที่ต้องได้: เลเวลส่งผลต่อ การต่อสู้ อย่างชัดเจน แต่ไม่ทำให้ผู้เล่นใหม่สู้ไม่ได้เลย

### ระยะ 4: โซนโลกและกติกาเอาชีวิตรอด

เป้าหมาย: แยกพื้นที่ถาวรของผู้เล่นออกจากพื้นที่ฟาร์มทรัพยากรที่รีเซ็ตได้

เซิร์ฟเวอร์มี 2 โลกหลัก:

1. **โลกสร้างบ้าน (โลกบ้าน)**
   - เป็นโลกถาวรสำหรับเมืองหลัก บ้านผู้เล่น ฟาร์ม ร้านค้า และโรงงาน Create
   - มี เขตปลอดภัย ที่จุดเกิด และพื้นที่ โพรเทกต์ที่ดิน สำหรับผู้เล่น
   - ปิดหรือจำกัด PvP พร้อมระบบป้องกันการขโมยและทำลายสิ่งปลูกสร้าง
   - ไม่รีเซ็ตโลก ยกเว้นมีการประกาศย้ายหรือซ่อมแผนที่เป็นกรณีพิเศษ
   - จำกัดทรัพยากรหายากและการเกิดมอนสเตอร์ที่ให้รางวัลสูง เพื่อลดการขุดทำลายภูมิประเทศ

2. **โลกหาของ (โลกทรัพยากร)**
   - ใช้ขุดแร่ ตัดไม้ ล่ามอนสเตอร์ หาไอเทมหายาก และวางทางเข้าดันเจี้ยน
   - แบ่งความยากเป็น เขตชายแดน / ป่าอันตราย / ดันเจี้ยน / เขตสงคราม
   - เพิ่ม การปรับระดับมอนสเตอร์, ตารางเกิด และ ระดับทรัพยากร ตามระยะหรือโซน
   - เปิด PvP เฉพาะโซนที่กำหนด และไม่อนุญาตให้ โพรเทกต์ที่ดิน ถาวร
   - รีเซ็ตตามรอบที่ประกาศล่วงหน้า โดยต้องย้ายไอเทมกลับโลกสร้างบ้านก่อนวันรีเซ็ต

- ทำ พอร์ทัล หรือ ฮับเทเลพอร์ต เชื่อมสองโลก และกำหนดจุดกลับที่ปลอดภัย
- กำหนดรายการไอเทมที่ห้ามนำข้ามโลก หากจำเป็นต่อการควบคุมเศรษฐกิจ
- ทดสอบข้อมูลผู้เล่น เงิน เลเวล และ คลัง เมื่อเดินทางข้ามโลก

ผลลัพธ์ที่ต้องได้: สิ่งปลูกสร้างของผู้เล่นปลอดภัยในโลกถาวร ขณะที่โลกหาของสามารถรีเซ็ตเพื่อเติมทรัพยากรและคอนเทนต์ได้

### ระยะ 5: เควสต์ ดันเจี้ยน และคอนเทนต์บอส

เป้าหมาย: สร้างคอนเทนต์หลักสำหรับเล่นเป็นปาร์ตี้

- ทำเควสต์เริ่มต้นสอนระบบเลเวล เงิน ร้านค้า และพื้นที่
- ทำ เควสต์รายวัน/รายสัปดาห์ สำหรับวนเล่น
- สร้าง ดันเจี้ยน tier แรกสำหรับ Lv. 10-20
- เพิ่ม ตารางรางวัลบอส แยก EXP, เงิน, วัตถุดิบ และ หนังสือสกิล
- เพิ่ม คูลดาวน์ หรือ ค่าเข้า เพื่อคุมการฟาร์ม
- ทำรอบทดสอบ สมดุล กับปาร์ตี้ 3-5 คน

ผลลัพธ์ที่ต้องได้: มี วงจรเกมเพลย์ หลักครบ เล่นคนเดียวได้ และมีเหตุผลให้รวมปาร์ตี้

### ระยะ 6: ตลาด กิลด์ และช่วงท้ายเกม

เป้าหมาย: รองรับสังคมผู้เล่นและเศรษฐกิจระยะยาว

- เพิ่มตลาดผู้เล่นหรือ โรงประมูล
- เพิ่มภาษีซื้อขายและราคาค่าธรรมเนียมตามมูลค่า
- วางระบบ กิลด์/แคลน และสิทธิ์พื้นที่
- ทำ อาณาเขต PvP หรือ รางวัลเขตสงคราม
- เพิ่ม ช่วงท้ายเกม ดันเจี้ยน/เรด และ วัตถุดิบหายาก
- เพิ่ม กระดานอันดับ เศรษฐกิจ เลเวล และ การผ่านดันเจี้ยน

ผลลัพธ์ที่ต้องได้: ผู้เล่นมีเป้าหมายระยะยาวนอกเหนือจากการเก็บเลเวล

### ระยะ 7: อัลฟา เบตา และเปิดจริง

เป้าหมาย: เปิดทดสอบเป็นรอบโดยลดความเสี่ยงก่อนเปิดจริง

- อัลฟาแบบปิด: ทีมงานและผู้เล่นกลุ่มเล็ก ทดสอบระบบหลักและ บั๊ก ร้ายแรง
- อัลฟาปรับสมดุล: ปรับ EXP, เงิน, อัตราดรอป, ความยากดันเจี้ยน และ ช่องทางดูดเงินออกจากระบบ
- เบตาแบบเปิด: เปิดผู้เล่นมากขึ้นเพื่อทดสอบ ประสิทธิภาพ และ เศรษฐกิจ จริง
- ตัดสินใจล้างหรือคงข้อมูล: ตัดสินใจจากความเสถียรและ ช่องโหว่ ที่พบ
- เปิดจริงซีซัน 1: เปิดจริงพร้อม บันทึกการเปลี่ยนแปลง, คู่มือกติกา และคู่มือเริ่มเล่น

ผลลัพธ์ที่ต้องได้: เซิร์ฟเวอร์เปิดได้แบบมีแผน ย้อนกลับ, แบ็กอัป และทีมดูแลพร้อมรับปัญหา

## ลำดับความสำคัญแนะนำ

1. ทำ ระยะ 0 ให้จบก่อน เพราะเป็นฐานของทุกระบบ
2. ต่อด้วย ระยะ 1 และ ระยะ 2 เพื่อให้ผู้เล่นมี วงจร พื้นฐาน: เล่น ได้ EXP ได้เงิน ใช้เงิน
3. ทำ ระยะ 3 หลัง วงจร พื้นฐานนิ่ง เพราะ สมดุลการต่อสู้ ต้องอิงค่า EXP และเงิน
4. ทำ ระยะ 4-5 เพื่อสร้างโลกและคอนเทนต์จริง
5. ทำ ระยะ 6-7 เมื่อระบบหลักเริ่มนิ่งและมีทีมทดสอบ

## หมุดหมาย สำหรับรอบถัดไป

เป้าหมายที่ควรทำทันทีในรอบพัฒนาถัดไป:

- เพิ่ม EXP จากการฆ่ามอนสเตอร์
- เพิ่ม คอนฟิกรางวัล พื้นฐาน
- เพิ่ม เงินดรอป หรือ รางวัล จากมอนสเตอร์แบบควบคุมได้
- เพิ่ม รายการตรวจสอบ ทดสอบ เซิร์ฟเวอร์แยก
- ทดสอบ Custom NPCs shop + LuckPerms ในเกมจริง
