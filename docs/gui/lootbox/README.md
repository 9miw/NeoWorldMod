ผู้ใช้ยืนยันให้ทำกล่องสั่น → แสงลอด → ฝาเปิด → ไอเทมลอยขึ้น ระยะเวลารวม 3.6 วินาที เก็บแบบ 1 รูเล็ตแนวนอนและแบบ 3 การ์ดพลิกไว้ต่อยอด ยังไม่สร้างสองแบบนั้น

## ทดสอบ

### เอฟเฟกต์และเปิดอัตโนมัติ

- ปุ่ม “เอฟเฟกต์: เปิด/ปิด” จำค่าในไฟล์ฝั่งไคลเอนต์ `config/neoworld/loot-box-client.properties` และโหลดกลับเมื่อเปิดเกม ปิดแล้วแสดงรางวัลทันที หีบอยู่ในสถานะเปิดค้าง ไม่มีเสียง แสง พลุ หรือการสั่น หากปิดระหว่างเล่นเสียงจะหยุดเฉพาะเสียงของหน้าจอนี้
- ช่องจำนวนและปุ่ม “เปิดเพิ่มอัตโนมัติ” เปิด **เพิ่มจากกล่องแรกที่ใช้ไปแล้ว** 1–64 ใบ เปิดเอฟเฟกต์ใช้ 80 ticks ต่อใบ ส่วนปิดเอฟเฟกต์ใช้ 4 ticks ต่อใบ (ประมาณ 5 กล่อง/วินาทีที่ 20 TPS) คูลดาวน์เดิมของกล่องแรกถูกปรับเป็น 4 ticks เมื่อเริ่มออโต้แบบเร็ว ทุกใบยังตรวจพื้นที่และแลกรางวัลผ่านเซิร์ฟเวอร์ ระหว่างออโต้ปุ่มเอฟเฟกต์จะปิดใช้ ให้หยุดก่อนเปลี่ยนโหมด
- ปุ่ม “หยุด” หรือปิดหน้าจอหยุดการเปิดต่อ รางวัลที่รับไปแล้วคงอยู่ เซิร์ฟเวอร์หยุดเมื่อมือ/ช่อง/ชนิดกล่องเปลี่ยน กล่องหมด กระเป๋าไม่พอ ผู้เล่นตาย ออกเกม หรือเปิด container อื่น ไม่หยิบกล่องจากช่องอื่นมาแทนโดยอัตโนมัติ
- ใช้ token จากผลเปิดล่าสุดเพื่อเริ่มงาน เซิร์ฟเวอร์ตรวจไอเทมและสุ่ม/แลกทีละใบผ่าน service เดิม ไม่มีการหักกล่องล่วงหน้าทั้งชุด คำขอเริ่มซ้ำไม่เพิ่มจำนวนงานเดิม ผลอัตโนมัติที่มาถึงหลังปิดหน้าจอไม่เปิดหน้าจอกลับ
- ใช้หน้าจอเดิมอัปเดตรางวัลต่อเนื่อง มีช่องจำนวน ปุ่มเอฟเฟกต์ ปุ่มเปิดเพิ่ม/จำนวนที่เหลือ และปุ่มหยุด ไม่มีกรอบหรือป้ายหัวข้อใหม่

การตรวจล่าสุด: `compileJava lootBoxRegressionTest lootBoxConfigurationRegressionTest lootBoxAutoRegressionTest processResources` ผ่าน; 234 rules/inventory + 37 config/packet + 11 auto/preferences checks รวม 282 ข้อ ยังไม่ได้ทดสอบ UI/เสียง/การหยุดอัตโนมัติกับผู้เล่นจริงในเกม

### ตั้งค่าด้วยกล่องที่ถือ (แอดมิน permission level 2)

1. ถือกล่องใหม่ (`/give @s neoworld:loot_box 1`) แล้วใช้ `/neow lootbox create` เพื่อผูกชุดรางวัลใหม่กับกล่องนั้น รหัสภายในสร้างอัตโนมัติ ไม่ต้องพิมพ์ ID
2. ย้ายกล่องไป **มือรอง** ถือไอเทมรางวัลพร้อมจำนวนที่ต้องการใน **มือหลัก** แล้วใช้ `/neow lootbox add 10` บันทึกไอเทม จำนวน ชื่อ enchant และ components เดิม เลข 10 คือน้ำหนักสุ่ม
3. ทำข้อ 2 กับไอเทมต่างกันจนครบ 8 รายการ แล้วใช้ `/neow lootbox count 3` กล่องอยู่มือหลักหรือมือรองก็ได้ จะได้รับ 3 รายการไม่ซ้ำต่อกล่อง
4. `/neow lootbox list` ดูรางวัลและจำนวนที่ได้รับของกล่องที่ถือ, `/neow lootbox remove 2` ลบรางวัลลำดับ 2 (เริ่มนับจาก 1)
5. ถือกล่องที่ตั้งค่าแล้ว ใช้ `/neow lootbox give @s 16` เพื่อคัดลอกกล่องชนิดนั้น 16 ใบ จำนวนกล่องที่ถือไม่ถูกหัก หากกระเป๋าผู้รับเต็ม ของที่เหลือจะวางข้างตัวผู้รับ

คำสั่งตั้งค่าไม่ใช้ `<id>` อีกต่อไป หากถือกล่องที่ตั้งค่าไว้ทั้งสองมือ `count/list/remove/give` เลือกมือหลักก่อน ส่วน `add` ใช้กล่องมือรองเสมอ การแก้ชุดรางวัลมีผลกับทุกกล่องชนิดเดียวกัน รวมถึงสินค้าที่ลงร้านไว้แล้ว ไม่สร้างรายการขายหรือราคาอัตโนมัติ

น้ำหนักอยู่ระหว่าง 0–100 **ไม่ใช่เปอร์เซ็นต์รับประกัน** น้ำหนักเท่ากันสุ่มเท่ากัน; 0 ปิดรายการ สุ่มแบบถ่วงน้ำหนักโดยนำรายการที่เลือกแล้วออกจากการเลือกครั้งถัดไป สูงสุด 9 รายการในชุดรางวัล และห้ามซ้ำทั้งชนิดไอเทม+components ค่า `count` เริ่มต้น 1 และต้องไม่เกินรายการที่น้ำหนักมากกว่า 0 ถ้าลบรางวัลจนเหลือน้อยกว่าค่าที่ตั้งไว้ กล่องจะเปิดไม่ได้จนแก้ค่า/เพิ่มรายการ

ก่อนสุ่มต้องมีช่องว่างในกระเป๋าหลักเท่าจำนวน `count` (กล่องใบสุดท้ายในมือหลักนับเป็นหนึ่งช่องได้) จึงไม่สามารถจัด stack เพื่อกรองผลที่ไม่ต้องการ รางวัลทั้งหมดกับการหักหนึ่งกล่องเป็นการแลกครั้งเดียว แสดงผลรางวัลเป็นกริดสูงสุด 3 × 3 และดู tooltip หลังแอนิเมชันจบได้

บันทึกชุดรางวัลและจำนวนที่สุ่มใน `<world>/data/neoworld_loot_boxes.dat` พร้อม world save/clean shutdown ตามปกติ ใช้ `/save-all flush` หากต้องการสั่งบันทึกโลกทันที ID บนไอเทมเป็น Data Component ที่บันทึกและ sync กับไคลเอนต์ จึงแยกชนิดกล่องและขายผ่านร้านเดิมได้ ข้อมูลรูปแบบเก่าโหลดด้วย count=1 ข้อมูลเสียหายจะถูกบล็อกการตั้งค่า/เปิดโดยเก็บต้นฉบับไว้

### กล่องทดสอบเก่าที่ไม่มีการตั้งค่า

1. `/give @s neoworld:loot_box 16` หรือหยิบจาก Creative ของ NeoWorld
2. ถือกล่องแล้วคลิกขวา (ใช้มือรองได้) เปิดซ้ำได้หลังคูลดาวน์ 4 วินาที
3. รางวัลทดสอบที่ผู้ใช้อนุญาต: เหล็ก 3 ชิ้น 60%, ทอง 2 ชิ้น 30%, เพชร 1 ชิ้น 10% ปรับด้วย datapack ที่ `data/neoworld/loot_table/loot_boxes/basic.json` แล้ว `/reload` แต่ละผลต้องเป็นหนึ่ง stack ที่ไม่เกินขนาด stack
4. เพิ่มเข้าร้านเดิม: ถือกล่องหนึ่งชิ้น แล้วใช้ `/neow shop admin add <shop-id> <buy> <sell> silver กล่องสุ่ม` โดยระบุราคาเอง ค่า 0 หมายถึงปิดการซื้อ/ขายฝั่งนั้นตามกฎร้านเดิม ตรวจ `/neow shop admin list` เพื่อหา ID ไม่สร้างร้าน/รายการขาย/ราคาจริงอัตโนมัติ

เซิร์ฟเวอร์สุ่มและแลกกล่องกับรางวัลก่อนส่งแอนิเมชัน ไม่มี packet กดรับของ ปิดหน้าจอหรือออกเกมระหว่างแอนิเมชันจึงไม่ยกเลิกรางวัลที่ได้รับแล้ว กระเป๋าเต็มหรือ table ให้ผลไม่ถูกต้องจะไม่หักกล่อง กล่องใบสุดท้ายในมือหลักเปิดช่องว่างให้รางวัลได้ ส่วนมือรองไม่เปิดช่องในกระเป๋าหลัก Creative ใช้กล่องหนึ่งใบเช่นเดียวกัน

กล่องเก่าที่ไม่มี component ชุดรางวัลยังใช้ datapack หนึ่งรางวัล/หนึ่งช่องว่างเดิม กล่องที่ตั้งค่าด้วยคำสั่งใช้จำนวนช่องตาม `count` ด้านบน
