# เส้นแสงนำทางเควสต์

ภาพที่ผู้ใช้ยืนยัน: `quest-light-ribbon-approved.png` เป็นภาพจำลอง ไม่ใช่ screenshot ของเกม

เปลี่ยนฝุ่นจุดเดิมเป็นเส้นต่อเนื่องแกนขาว ขอบฟ้าอมเขียว แสงไหลไปข้างหน้า และวงแหวนปลายทาง ปรับตามพื้นและบันได ใช้ depth test เพื่อไม่ให้เห็นทะลุสิ่งกีดขวาง และเห็นเฉพาะเจ้าของเควสต์

## แผนลงโค้ด

1. ทดสอบ geometry ของแถบแสง การปิดวงแหวน ทิศ pulse และ codec ข้อมูลที่มีขอบเขต
2. เซิร์ฟเวอร์ส่งกราฟครั้งแรกและ delta เมื่อจุด/เส้นเชื่อมเปลี่ยน พร้อมเป้าหมายที่เซิร์ฟเวอร์เลือกตามเควสต์ Client เลือกทางและสร้างจุดภาพเอง จำกัด 128 จุดทางและ 49 จุดวงแหวนใน view ใกล้ตัว
3. client วาด unlit color quads สามชั้น (halo/mid/core) พร้อม pulse ตามระยะทางจริง ไม่ใช้ post-processing bloom หรือ dynamic block lighting
4. ล้างเป้าหมายเมื่อหยุด/จบเควสต์ ล้าง cache เมื่อ disconnect ซ่อนภาพระหว่างอยู่ผิดมิติ ตาย หรือเป็นผู้ชม ไม่มี timeout 2 วินาทีหรือ heartbeat จุดเส้นแสง
5. ตรวจ compileJava, questNavigationRegressionTest และ regressionTest แล้วตรวจภาพจริงในเกมเมื่อทำได้

การวาดอยู่ฝั่ง client แยกจากสถานะเควสต์และ SavedData เดิม ไม่มีการวางหรือแก้บล็อกในแมป งานแก้ทางและโหมด preview ของแอดมินยังใช้จุดสีทองเดิม

## ผลการลงโค้ด

- Graph reset/delta ส่งเฉพาะตอนเข้าเกมหรือกราฟเปลี่ยน เป้าหมายส่งเฉพาะเมื่อค่าเปลี่ยน Client คำนวณทางและจุดภาพภายใน 24 บล็อกด้วย NavigationWalk บน chunk ที่โหลดจริง
- เส้นอยู่เหนือพื้น .15 บล็อก ชั้น halo/mid/core ใช้ half-width .22/.085/.027 บล็อก วงแหวนรัศมี .75 บล็อก มีเส้นแสงไหลความเร็ว 2.5 บล็อก/วินาที และวงแหวนหายใจช้า ๆ
- unlit shader รักษาความสว่างโดยไม่ใช้ block light, depth test ป้องกันมองทะลุบล็อก และไม่เขียน depth เพื่อให้ชั้นแกนไม่ถูก halo บัง
- client ล้างกราฟ/เป้าหมายเมื่อ disconnect ซ่อนภาพเมื่ออยู่ต่างมิติ ตาย หรือเป็นผู้ชม และรับ clear target จากเซิร์ฟเวอร์เมื่อหยุด/จบเควสต์ เป้าหมายไม่หมดอายุตามเวลา
- ช่วงต่างระดับมากกว่า .2 บล็อกแยกเป็นแนวตั้ง/แนวนอน โดยขึ้นก่อนข้ามขั้นและลงหลังข้ามขั้น เพื่อลดปัญหาเส้นเฉียงจมเข้า tread; ตรวจ geometry ของ riser เพิ่มแล้ว ยังต้องตรวจภาพบันไดจริงในเกม
- Network protocol 32: client และ server ต้องใช้โค้ดรุ่นเดียวกันสำหรับ payload ใหม่
- ทดสอบ geometry/pulse, graph reset/delta codec และ atomic cache, goal/clear codec, malformed counts, chunk-corridor probing และ policy เลือกเส้นทางเดิม พร้อม compileJava และ regression tests ผ่าน ยังไม่ได้ทดสอบ multiplayer จริง shader อื่น Fabulous และรูปลักษณ์ที่ 1280x720 ในเกม จึงยังไม่ยืนยันว่าภาพจริงตรงกับ mockup
