# แผนผังแอสเซ็ตตลาด V2

ม็อกอัปอ้างอิง: `docs/gui/market/20-market-latest-composed-mockup.png`

## แอสเซ็ตใหม่ที่เสนอ

- `market-shell-source.png` - ต้นฉบับโปร่งใสที่สร้างสำหรับกรอบนอกคงที่
- `market-shell-crisp.png` - กรอบที่เสนอ ตัดแล้วและมีอัลฟาสองค่า ขนาด 1530 x 882
- `market-detail-panel-source.png` - ต้นฉบับโปร่งใสที่สร้างสำหรับแผงรายละเอียดว่าง
- `market-detail-panel-crisp.png` - แผงรายละเอียดที่เสนอ ตัดแล้วและมีอัลฟาสองค่า ขนาด 602 x 1354
- `market-assets-crisp-edge-preview.png` - ภาพตรวจทั้งสองชิ้นบนตารางหมากรุก

ผลส่งออกขอบคมใช้อัลฟาเฉพาะ 0 หรือ 255 หลังใช้ threshold 224 และเว้นขอบตัดโปร่งใสสี่พิกเซล ป้องกันขอบมืดโปร่งบางเมื่อวาดบนพื้นเกมสว่างหรือมืด

## แอสเซ็ตรันไทม์ที่ใช้ซ้ำ

- `textures/gui/market/market_slot_states.png` - ช่องจัตุรัสปกติ ชี้เมาส์ และเลือก
- `textures/gui/market/market_search_states.png` - ช่องค้นหาปกติและโฟกัส
- `textures/gui/market/market_widgets.png` และแอสเซ็ต `NeoButton` ร่วม - สถานะตัวควบคุม

## เนื้อหาไดนามิก

อย่าฝังหัวข้อ หมวด ไอคอนไอเทม ผู้ขาย ยอดเงิน จำนวน ราคา ตัวจับเวลา แบ่งหน้า การเลือก หรือป้ายปุ่มใน PNG กรอบและแผงรายละเอียด

ไฟล์ V2 นี้เป็นตัวเลือกออกแบบเท่านั้น ยังไม่ติดตั้งเป็นเท็กซ์เจอร์รันไทม์หรืออ้างจาก `MarketScreen` จนกว่าองค์ประกอบจะอนุมัติและได้รับอนุญาตให้พัฒนา
