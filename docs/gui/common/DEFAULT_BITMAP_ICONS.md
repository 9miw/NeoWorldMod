# ไอคอนบิตแมปในฟอนต์เริ่มต้น

ทะเบียนไอคอนทุกชุดพร้อม Font ID, Unicode, เมตริก, ภาพ PNG และตัวอย่างเรียกใช้ อยู่ที่ [bitmap-icons/README.md](bitmap-icons/README.md) ค้นทะเบียนนี้ก่อนสร้างไอคอนใหม่ ชุดข้อมูลไม่รวมตัวอักษรไทย/อังกฤษ

`assets/minecraft/font/default.json` อ้างรีจิสทรี icons, currency, ranks, gui_controls, dungeon_hud, fashion_tooltip และ activity_icons เดิมโดยตรง ร่วมกับ Roboto และภาษาไทย ไม่ต้องมีรีจิสทรีแชตแยก รีจิสทรีไอคอนที่รวมต้องไม่อ้าง default กลับ เพื่อป้องกันวงจร

พิมพ์/วาง glyph ไอคอนร่วมทั้ง 109 ตัวในแชต Minecraft ได้เมื่อโหลดรีซอร์สไคลเอนต์ที่อัปเดตแล้ว คงเมตริก glyph ต้นทางทั้ง default และ GUI ไม่ทำให้อักขระ private-use ใช้ได้ในแอปแชตภายนอกหรือไคลเอนต์ที่ไม่มีแอสเซ็ต NeoWorld

| ช่วงรหัส | ชุด |
| --- | --- |
| E001–E01F | ไอคอนทั่วไป |
| E020–E045 | ตรา/ไอคอนแรงก์ |
| E046–E048 | สกุลเงิน |
| E100–E107 | การกระทำปาร์ตี้ร่วม |
| E110 | นาฬิกาดันเจี้ยน |
| E200–E20D | ไอคอนทูลทิปแฟชั่น |
| E220–E223 | กิจกรรมรายวัน/รายเดือน/ออนไลน์/รอรับ |
| E300–E309 | ไอคอนระบบ/ควบคุมเกมใหม่ |

ย้าย Activity จาก E200–E203 เป็น E220–E223 เพื่อแก้ชนกับแฟชั่น การจับคู่ไอคอนอื่นคงเดิม ตัวแปร member/icon/control ร่วมใช้ภาพเดียวกันในรหัสเดียว และรวมรายการซ้ำสำหรับการวาด default

`src/regressionTest/java/com/ambition/neoworld/font/FontBitmapGenerator.java` สร้าง icons/currency/ranks ใหม่โดยไม่เพิ่ม fallback ไป default คงการอ้างอิงตรงของ default และตรวจกราฟการอ้างอิงกับการจับคู่ glyph ต่อภาพไม่ซ้ำเมื่อเพิ่มฟอนต์ ไม่สร้างไฟล์แชตแยก

รีโหลดรีซอร์ส (F3+T) หรือรีสตาร์ตไคลเอนต์เพื่อดูการเปลี่ยนแปลง การคอมไพล์และตรวจรีซอร์สไม่ยืนยันภาพแชตหรือ GUI ยังต้องตรวจในเกม แนะนำตัวช่วยฟอนต์แบบมีชื่อเมื่อขนาด GUI สำคัญ
