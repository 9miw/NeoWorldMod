# Shared GUI reuse

Approved scope: named access to every catalogued icon, one balance-text builder, and reuse of the close control. Existing inventory, server actions and custom skins retain their lifecycle.

## Named icons

`NeoBitmapIcon` is generated by `tools/fonts/icon_catalog.py` from the same ten icon fonts as the catalogue. Each constant represents a Font ID + Unicode + metrics variant. Use the `java_constant` field in `bitmap-icons/catalog.json` to find the name, then call `.component()`; `.font()`, `.glyph()`, `.height()` and `.ascent()` are also available. The returned Component specifies a font only, so callers retain control of color. Append ordinary labels as separate Components.

Existing NeoSystemIcons, NeoGuiIcons, NeoBitmapFonts and PvpTitles APIs remain compatible. Activity labels, Fashion tooltips and Dungeon HUD now use named constants rather than allocating glyphs locally. No font/PNG registration was added.

## Balances

`NeoEconomyText.balances(silver, gold, diamond, Order)` consumes already formatted amounts. HUD uses SILVER_FIRST and the balance widget uses DIAMOND_FIRST. Shared text inserts one separator between currencies and keeps amount text in the ordinary font; this also fixes the former missing separator before Silver in the widget. `amount(currencyIcon, value)` builds an individual currency label, including tooltips. No balances are mutated here.

## Close controls

`NeoCloseButton.create(x,y,width,height,label,tooltip,onClose)` supports rectangular hitboxes and feature descriptions. Trade keeps cancellation, PvP keeps its ongoing confirmation timer, and Upgrade keeps its existing PNG renderer and return-items behavior. The common PNG appearance is used for Trade/PvP. Existing feature callbacks remain the source of truth.

Other legacy close controls and feature-specific frames remain for separate migration; this phase does not claim every GUI has been converted.
