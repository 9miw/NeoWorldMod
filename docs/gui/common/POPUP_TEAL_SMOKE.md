# ป๊อปอัป Teal Smoke

ภาพอนุมัติ: `neo-popup-teal-smoke-approved-mockup.png` เฉพาะคอลัมน์ Teal Smoke ซ้าย แทนภาพ Compact ทึบแสง โดยคงขนาด Compact ปุ่ม H20, API ตัวเลือก/นับถอยหลัง และพฤติกรรมคอลแบ็ก/อินพุตโมดัล ยังไม่ได้ทำ Frost Silver หน้าต่างอ้างอิง 1280x720 แยกจาก GUI Scale

## การจับคู่แอสเซ็ต

แอตลาสรันไทม์: `src/main/resources/assets/neoworld/textures/gui/common/popup_teal_smoke.png` ขนาดจริง 1536x1024 เมทาดาทาปิด blur เปิด clamp ไม่ฝังป้ายหรือค่าไดนามิก ตัววาด: `client/gui/common/NeoPopupTextures.java`

| ส่วน | กรอบต้นทาง x,y,w,h | การวาด |
| --- | --- | --- |
| ภายในเท็กซ์เจอร์พื้นรอง | 100,160,590,260 | เว้าขอบเข้า 2px ใช้อัลฟารันไทม์ 0.55 |
| กรอบเงิน/ทีลกลางโปร่งใส | 795,106,695,374 | nine-slice ขอบต้นทาง 40 ขอบเชิงตรรกะ 4 |
| แผ่นหัวข้อเข้ม | 460,560,617,105 | nine-slice ขอบ 30/4 ความทึบกลาง 0.8 |
| ปุ่มทีลหลัก | 460,701,617,108 | nine-slice ขอบ 32/4 ความทึบกลาง 0.9 |
| ปุ่มชาร์โคลรอง | 460,845,617,108 | nine-slice ขอบ 32/4 ความทึบกลาง 0.9 |

พื้นรองที่สร้างมีมุมตกแต่ง จึงสุ่มตัวอย่างเฉพาะด้านใน มุมตกแต่งมาจากสไปรต์ขอบอย่างเดียว อัลฟาพื้นรองต้นทางที่ (350,290) คือ 253 กลางกรอบที่ (1150,290) และนอกกรอบที่ (0,0) คือ 0 จึงไม่ซ้อนกรอบกับพื้นรองจนกลางทึบ อัลฟากลางหัวข้อ/ปุ่มต้นทาง 253 คูณความทึบรันไทม์ ขอบคงความทึบตนเอง

สีสถานะ: ปกติ 0.88 ชี้เมาส์/โฟกัส 1.0 ปิดใช้ 0.45 ปุ่มรองเมื่อชี้เพิ่มทีล เลือกเพิ่มทอง Destructive ใช้แดงเมื่อผู้เรียกเลือก ข้อความไดนามิกมีเงาให้อ่านบนกระจกง่าย ตัวหรี่ฉากคือ 0x40000000 ห้ามวาด blur โลกซ้ำหลังโมดัล ใช้ชั้น Z ที่ระบุชัดเจนเดิมต่อไป

## สถานะการตรวจสอบ

ตรวจภาพ PNG ขนาด อัลฟากลาง/นอก และพาธต้นทางแล้ว `compileJava` ผ่าน ยังไม่ได้เทียบสกรีนช็อตในเกม ต้องตรวจการหรี่หน้าจอแม่ ความอ่านง่าย และภาพแต่ละสถานะเทียบภาพอ้างอิงที่ GUI Scale จริงก่อนสรุปว่าภาพเสร็จ
