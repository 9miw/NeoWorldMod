# ทูลทิปพิกเซล Deepslate

ชุดสีฉบับอนุมัติ: Common ชาร์โคล/เงิน Uncommon เขียวมอสกลางเขียวเข้ม Rare ไซแอนน้ำเงินกลางกรมท่า Epic อเมทิสต์กลางม่วงเข้ม Legendary ทองอำพันกลางน้ำตาลเข้ม `export-assets.py` ใช้ palette ต่อระดับแบบทำซ้ำได้กับ slice ต้นฉบับ คงเรขาคณิต padding และเวลาแอนิเมชัน PNG/GIF ที่สร้างจากแอสเซ็ตติดตั้งแสดงฉบับนี้ ภาพอ้างอิงก่อนหน้าบันทึกเรขาคณิตหิน คอมไพล์/ประมวลผลรีซอร์สผ่าน ตรวจสีกลางต่างกัน อัลฟา มุมสะท้อน รอยต่อ tile และ PNG ในแพ็กเท่ากันแล้ว ยังไม่ยืนยันภาพในเกม

ภาพอนุมัติ `approved-reference.png` แถวสอง Common/Uncommon/Rare นิ่ง Epic มีคริสตัลเต้นสลับกับประกายกากบาทเล็ก Legendary เพิ่มแสงทองสั้นตามขอบตามเข็มและประกายแรงขึ้นเล็กน้อย ไม่มี bloom, blur, เกรเดียนต์เรียบ ตรากลาง หรือรูนสลัก

แผนแอสเซ็ต: `frame-source.png` ให้แผงหินห้าชุดกลางทึบนอกโปร่งใส ชิ้นมุมขนาดเดิมและขอบปูซ้ำแพ็กรวมพื้น เพื่อแยกลายรอบนอกจากพิกเซลกลางเรียบ เนื้อหาไอเทมวาดไดนามิก ไม่ฝัง PNG มุมขนาดคงที่ ขอบปูซ้ำแทนยืดพิกเซลหิน ข้อมูลความหายาก/อัปเกรดสแต็กและฟอนต์ไทยเดิมไม่เปลี่ยน

คงมุม 6/7/8/9/10 พิกเซลและระยะเนื้อหา 8/9/10/11/12 แอสเซ็ตเต้น/ประกายเป็น mask พิกเซลขอบคม แพ็กแถบ PNG แนวตั้งพร้อมเมทาดาทาแอนิเมชัน Minecraft แสงทองเป็นแถบขอบคมอีกชุด ไม่ใช่โค้ดวาดเส้นรันไทม์ เฉพาะ Epic/Legendary เข้ารอบเอฟเฟกต์ ขนาด tile หน้าตัดจุดต่อ และ mask พิกเซลอยู่ในตัวส่งออกกับ JSON เรขาคณิต

เป้าหมายเทียบหลัก 1280x720 ที่ GUI Scale จริงผู้ใช้ ภาพประกอบ PNG/GIF ออฟไลน์และการตรวจแอสเซ็ตไม่ใช่ยืนยันภาพในเกม ยังรอเทียบเมื่อมีสกรีนช็อต

ตรวจสอบ: `compileJava`, `processResources` ผ่าน ไบต์ PNG ติดตั้งตรงแพ็ก ตรวจอัลฟาตัด ตัวอย่างกลางทึบ มุมสะท้อน หน้าตัดจุดต่อแปดแบบ ปลาย tile บางส่วน เมทาดาทาสไปรต์ และเงื่อนไขระดับนิ่ง/เคลื่อนไหวผ่าน ตรวจ PNG/GIF ออฟไลน์แล้ว ยังไม่ได้ตรวจในเกม
