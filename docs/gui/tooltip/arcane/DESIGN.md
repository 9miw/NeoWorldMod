# Arcane Crystal A — การพัฒนาที่อนุมัติ

อ้างอิง `approved-reference.png` แถว A (Rune Flow) ข้อกำหนดเพิ่มเติมที่อนุมัติคือเคลื่อนไหวเฉพาะ Epic และ Legendary ส่วน Common, Uncommon, Rare นิ่งทั้งหมดรวมคริสตัลมุม คงการไล่ความหายากกะทัดรัดและพื้นที่เนื้อหาไดนามิกว่าง

แผนแอสเซ็ต: ต้นฉบับกรอบคริสตัล/รูนโปร่งใสห้าชุด แอตลาสมุม/ขอบขนาดเดิม ต้นฉบับประกายขาวแยก และสไปรต์ GUI เคลื่อนไหวแนวตั้งหนึ่งชิ้นที่ตัววาดย้อมม่วง/ทอง ไม่มีตรากลางบน ข้อความ ไอคอน และข้อมูลสแต็กเป็นไดนามิก เก็บธีมก่อนหน้าเป็นแหล่งประวัติ

เรขาคณิต: มุมกินพื้นที่ 6/7/8/9/10 พิกเซล GUI ระยะเนื้อหา 8/9/10/11/12 ตามลำดับ ลายจึงโตเล็กน้อยแต่ข้อความคงขนาดปกติ เนื้อหาทูลทิปยังกำหนดกว้าง/สูง ไม่บังคับกล่องว่างตายตัว แถบรูนปูซ้ำขนาดเดิม รอยต่อขอบใช้หน้าตัดจากพิกเซลจุดต่อมุม

Rune Flow: 16 เฟรมใน PNG แนวตั้ง 32x64 (32x4 ต่อเฟรม) สองทิกต่อเฟรม มี interpolation และ GUI tile scaling แอตลาส GUI Minecraft เดินสไปรต์ ขอบตรงวาดตามเข็ม Epic ม่วงหม่น Legendary ทองสว่างกว่าเล็กน้อย ระดับอื่นไม่เข้ารอบวาดเอฟเฟกต์

เป้าหมายเทียบหลักคือหน้าต่างเกม 1280x720 ที่ GUI Scale จริงผู้ใช้ ห้ามเปลี่ยน GUI Scale ให้เข้าดีไซน์ พรีวิวออฟไลน์ไม่ใช่ภาพเกม ยังรอการยืนยันภาพในเกมจนมีสกรีนช็อตเทียบอ้างอิง
