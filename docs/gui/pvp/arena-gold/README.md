# แอสเซ็ต Title PvP ธีม Arena Gold

ภาพอนุมัติคือคอลัมน์กลาง `approved-three-tones.png` ผู้ใช้เลือกแบบ 2 `source.png` เป็นชีตผลิตโปร่งใสจากเครื่องมือภาพในตัว `runtime-preview.png` แสดง PNG ส่งออกจริงบนตารางหมากรุก ไม่ใช่สกรีนช็อตเกม

## แอสเซ็ตที่ติดตั้ง

- ฟอนต์มีชื่อ `neoworld:pvp_titles` ไม่เปลี่ยนฟอนต์เริ่มต้น
- PNG รันไทม์ `assets/neoworld/textures/font/pvp_titles/`
- U+E400 ชัยชนะ, U+E401 พ่ายแพ้, U+E402–E406 นับถอยหลัง 5–1, U+E407 เริ่มต่อสู้
- ทุก provider ใช้ height 18, ascent 14 วาดภาพสีด้วยสีขาวเพื่อคงทอง/งาช้าง/แดงเข้ม ตัวเลขแต่ละตัวมีแคนวาส 128 x 96 glyph คำกว้าง 256 พิกเซล PNG ทั้งหมดมีขอบโปร่งใส อัลฟาสองค่า และ blur:false/clamp:true `manifest.json` เก็บกรอบตัดที่วัดกับขนาดผลลัพธ์
- `PvpTitles` ให้ Component ของ glyph `PvpRoomManager` ใช้กับนับก่อนสู้ เริ่ม ผลยก และผลแมตช์ เสมอยังใช้ข้อความปกติ ซับไตเติลคะแนน Rating เวลากลับ และแชตเป็นไดนามิกและฟอนต์ปกติ

รัน `export.py` จากรากรีโพซิทอรีด้วย Python/Pillow เพื่อส่งออกซ้ำ สคริปต์ตัดพื้นที่แยกที่วัด ลบขอบจางเฉพาะอัลฟา ปรับด้วย nearest-neighbor สร้าง JSON ฟอนต์และพรีวิวตารางหมากรุก ไม่ลบพิกเซลมืดด้วย color key

## ขนาดและการตรวจสอบ

Title Vanilla สเกลพิกัดฟอนต์สี่เท่า glyph สูง 72 พิกเซล GUI เชิงตรรกะ คำกว้างประมาณ 132–156 ที่หน้าต่าง 1280 x 720 และ GUI Scale 3 จะกว้างจริงประมาณ 396–468 พิกเซล GUI Scale ใหญ่ขึ้นเปลี่ยนขนาดจริง ascent วาง glyph เหนือ baseline ซับไตเติลไดนามิกพร้อม padding โปร่งใส นี่คือตรวจเมตริกออฟไลน์ ไม่ใช่วัดภาพเกม

ตรวจขอบอัลฟา ไม่มีเศษสไปรต์ข้างเคียง ตัวเลขห้าตัวแคนวาสเท่ากัน ลิงก์รีซอร์ส JSON ฟอนต์ compileJava และชุดรีเกรสชัน PvP แล้ว ภาพ Title จริง สเกล เงา Vanilla เฟด และการเทียบที่ GUI Scale ผู้ใช้ยังต้องตรวจในเกม ภาพรันไทม์ดัดแปลงจากสไตล์อนุมัติ ไม่ใช่ตัดพื้นหลังชีตเปรียบเทียบ

## พรอมป์ต์สร้างภาพ

ใช้เครื่องมือภาพในตัว อ้างอิง `approved-three-tones.png`:

สร้างสไปรต์ชีต PNG โปร่งใสสำหรับผลิต ให้ตรงเฉพาะคอลัมน์ ARENA GOLD กลางของภาพอ้างอิง สองคอลัมน์สี่แถว รวมแปดสไปรต์แยก วางช่องเท่ากัน 512x256 บนแคนวาสโปร่งใส 1024x1024 ไม่มีพื้นหลัง ป้าย ซับไตเติล เส้นกริด หรือภาษาอังกฤษ เว้นร่องโปร่งใสมากพอระหว่างช่อง ภาพพิกเซล Minecraft มุมมองตรง ขอบขั้นบันไดคม สไตล์ nearest-neighbor ไม่มีแสงเรืองนุ่ม
แถว 1 ซ้าย: คำไทย 'ชัยชนะ' สะกดถูก ตัวอักษรบิตแมปหนาบากทองงาช้าง มงกุฎด้านบน ลอเรลทองด้านข้างตามแบบชนะคอลัมน์กลาง ขวา: 'พ่ายแพ้' สะกดถูก ตัวอักษรพิกเซลหนาหน้างาช้างบนไล่แดงเข้มล่าง ลอเรลทองแดงเข้มหักด้านข้างและอัญมณีแดงกลาง ตามแบบแพ้
แถว 2 ซ้ายเลขทอง '5' ขวา '4'; แถว 3 ซ้าย '3' ขวา '2'; แถว 4 ซ้าย '1' ทั้งห้าตัวใช้ฟอนต์ทองงาช้างบากเดียวกัน และวงทองแบ่งส่วนกะทัดรัดมีอัญมณีแดงข้างตามภาพนับถอยหลัง จัดกลางช่อง แถว 4 ขวา: 'เริ่มต่อสู้' สะกดถูก ตัวอักษรพิกเซลบากทองงาช้างพร้อมดาบไขว้และปีกทองกะทัดรัดในชุดภาพเดียวกัน
แต่ละสไปรต์อยู่ครบในช่อง เว้นขอบปลอดภัย 28px หัวข้อแนวนอนกว้างไม่เกิน 456px ตัวเลขและวงสูงราว 180px ห้ามข้ามขอบช่อง คงสระและวรรณยุกต์ไทย อัลฟาภายนอกแปดสไปรต์ต้องโปร่งใสจริง วาดเฉพาะภาพ glyph แปดชุดนี้สำหรับฟอนต์บิตแมป Minecraft

ตัวสร้างคืนภาพ 1254 x 1254 ที่ระยะแถวไม่เท่ากัน จึงวัดพิกัดส่งออกจากชีตที่ได้ ไม่สมมติขนาดกริดตามที่ขอ

## ลูกศรทิศทาง Rating

`neoworld:pvp_rating` มี U+E408 ลูกศรขึ้นเขียว และ U+E409 ลงแดง วาดเป็นสามเหลี่ยมพิกเซลเล็กด้วย `export-rating-arrows.py` ไฟล์รันไทม์ `textures/font/pvp_titles/rating_up.png`, `rating_down.png` (16 x 16 ขอบโปร่งใส height 9 / ascent 8) `rating-arrows-preview.png` แสดงไอคอนจริงขยายด้วย nearest-neighbor

ซับไตเติลผลสุดท้ายแรงก์เลือกไอคอนตามผลต่าง Rating จริงต่อคน แยกจากชนะ/แพ้ จำนวนบวก/ลบใช้ข้อความธรรมดาเขียว/แดง ศูนย์แสดง `Rating ±0` ไม่มีลูกศร Rating รวม คะแนน และเวลากลับเป็นไดนามิก ทั้งผลครั้งแรกและอัปเดตซับไตเติลตามเวลาคง Component ไอคอน กรณีไม่มีรายงานผล แมตช์ส่วนตัว และยกระหว่างทางคงข้อความเดิม แชตคงรายงานข้อความล้วน การจัดแนวยังต้องตรวจสกรีนช็อต Minecraft
