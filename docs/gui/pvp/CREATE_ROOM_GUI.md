# เลือกสนาม / สร้างห้อง

ภาพอนุมัติ `docs/gui/pvp/pvp-create-room-mockup-v2.png` ผู้ใช้อนุมัติรายการสนามพร้อมสกรอลล์บาร์แนวตั้งบาง วิวพอร์ตแรกวางสามการ์ด สนามที่ลงทะเบียนเกินนั้นยังเข้าถึงด้วยล้อเมาส์ ลาก คลิกราง หรือปุ่มลูกศร/Home/End/Page Up/Page Down

แอสเซ็ตรันไทม์:

- `assets/neoworld/textures/gui/pvp/create_room_frame.png`: 1672 x 941 RGBA นอกโปร่งใส (อัลฟามุม 0) แผ่นหัวข้อ/หัวส่วนว่าง ช่องพรีวิว/สถิติขวาว่าง และพื้นที่รายการซ้ายต่อเนื่อง ไม่ฝังข้อความหรือตัวควบคุม
- `assets/neoworld/textures/gui/pvp/arena_preview.png`: 1672 x 941 ภาพสนามทั่วไป เป็นภาพสำรอง ไม่ใช่สกรีนช็อตโครงสร้างที่บันทึก
- PNG ใหม่ทั้งคู่มีเมทาดาทา blur=false/clamp=true
- สถานะ NeoButton PNG ร่วมปกติ/ชี้/เลือก/ปิดใช้เป็นขอบการ์ด ตัววาดกรอบเฉพาะฟีเจอร์รักษามุมบางให้เหมาะภาพย่อ
- NeoScrollbar ร่วมใช้ `textures/gui/common/scrollbar_slim.png`

ใส่ภาพจริงรายสนามในรีซอร์สแพ็กหรือรีซอร์สม็อดที่ `assets/neoworld/textures/gui/pvp/arenas/<arena_id>.png` อ่านขนาดจริงและตัดกลางตามสัดส่วนพรีวิว/การ์ด หากไม่มีภาพใช้ได้ จะติดป้าย `ภาพประกอบสนาม` ในพรีวิวที่เลือก แคชการค้นหารีซอร์สภายในจอและล้างเมื่อเริ่มจอ ไม่อ่านโครงสร้างหรือฐานข้อมูล เลือกได้เฉพาะ ID สนามจากเซิร์ฟเวอร์ arena_2/3 ในม็อกอัปเป็นภาพประกอบ ไม่ใช่สนามเกมเพลย์ที่ลงทะเบียนใหม่

การพัฒนา: PvpSelectionScreen มอบการ์ดให้ PvpArenaList และค้นภาพให้ PvpArenaImages เฉพาะ Create แบบส่วนตัวเปิดตัวเลือกนี้ Ranked เข้าคิวกลางตรงและเซิร์ฟเวอร์สุ่มสนามหลังจับคู่ ไม่ต้องเปลี่ยนเพย์โหลด/ฐานข้อมูล การเลือกเปลี่ยนเฉพาะสถานะในเครื่อง

พิกัด/ฮิตบ็อกซ์ใช้สเกลเดียวจากขนาดหน้าต่างหลังสเกลจริง ภาพหลักหน้าต่างจริง 1280 x 720 ไม่เปลี่ยน GUI Scale การวาดและเลือกการ์ดใช้ scroll offset ที่ปัดค่าเดียวกัน การตัดป้องกันการ์ดนอกจอและช่องว่างรับคลิก ขณะรอเซิร์ฟเวอร์ปิดรายการ สกรอลล์บาร์ และปุ่มส่ง เก็บการเลือกด้วย ID สนาม ตำแหน่งเลื่อนคงเมื่อสร้างวิดเจ็ตใหม่/ย่อขยาย และจำกัดตามเนื้อหา

แอสเซ็ตสร้างด้วย ImageGen ในตัว พรอมป์ต์สุดท้าย: กรอบคงเรขาคณิต V2 อนุมัติ ลบข้อความ ภาพ การ์ด สกรอลล์บาร์ ปุ่ม และทำด้านนอกโปร่งใส พรีวิวเป็นลานประลองหิน Minecraft ว่าง มีธงทีล แท่นเกิดสองสี ไม่มี UI/ข้อความ ต้นฉบับใน generated_images ของเซสชันคือ `exec-fbe96230-0786-469e-b43d-15e7c5ea7f65.png` และ `exec-415c0633-daa7-4bc0-ac98-ec2370c9b10b.png`

การตรวจสอบ: compileJava และรีเกรสชัน PvP ผ่าน การทดสอบเลื่อนครอบคลุม 128 แมป ขอบล้อเมาส์ ช่องว่างการ์ด ฮิตบ็อกซ์ที่ตัด เลื่อนบางส่วน ไปแมปสุดท้ายด้วยลากตัวเลื่อน/คีย์บอร์ด อินพุตปิดใช้ และรายการสามแมปไม่ล้น ตรวจขนาด PNG อัลฟา และการอ้างรีซอร์สแล้ว โค้ดคอมไพล์ แต่ยังไม่ยืนยันภาพตรงม็อกอัปในเกม ไม่มีภาพเกม/หลักฐาน GUI Scale สำหรับรีวิชันนี้
