# GUI ห้องส่วนตัว

ภาพอนุมัติ `docs/gui/pvp/pvp-private-room-mockup-v2.png` ผู้ใช้อนุมัติแบบ Invite แทนแผงคำสั่งเข้าห้อง ไม่มี Ready/Unready ในลอบบี้ เจ้าของใช้ Fight เพื่อเปิดยืนยันให้ทั้งคู่

กรอบรันไทม์ `src/main/resources/assets/neoworld/textures/gui/pvp/private_room_frame.png` ขนาด 1672 x 941 RGBA อัลฟามุม 0 ด้านใน 253 ใช้ blur=false/clamp=true กรอบที่แสดงคือ (300,0,1080,920) หัวว่าง แถบข้อมูล แผงผู้เล่นสองฝั่ง ช่องสถิติ และแท่นหินเป็นภาพฝัง โมเดลผู้เล่น ข้อความ อันดับ ปุ่ม มงกุฎ และดาบเป็นไดนามิก ตัววาดและฮิตบ็อกซ์ใช้กรอบตัด/สเกลเดียว พอดีหน้าต่าง Minecraft หลังสเกลจริงโดยไม่เปลี่ยน GUI Scale หน้าต่างหลักอ้างอิง 1280 x 720 พิกเซลจริง

พรีวิวลอบบี้และยืนยันใช้ `PvpPlayerPreview` ร่วม สำเนาพรีวิวหมุน 360 องศาทุก 400 ทิกไคลเอนต์ (ประมาณ 20 วินาที) รวมเกราะและของถือ partial tick ทำให้ลื่น หัวและตัวตรงกันที่ yaw เอนทิตีคงที่ หมุน pose โมเดลทั้งตัวรอบแกนตั้ง แม้ตัววาดอื่นแทน body yaw ก็ยังหมุนเกราะ แขนขา และของถือพร้อมกัน คงขอบตัดและขนาดโมเดลเดิม ไม่ส่งแพ็กเก็ตทิศผู้เล่นหรืออ่านฐานข้อมูลเพื่อแอนิเมชันนี้

Invite ใช้ NeoGuiIcons.INVITE และ NeoButton มาตรฐานร่วม Fight ใช้เท็กซ์เจอร์ดาบเดิมและปุ่ม primary เจ้าของใช้ glyph หัวหน้าร่วม ตัวเลือกแสดงชื่อออนไลน์ที่ไคลเอนต์รู้ หน้าละหกคน เซิร์ฟเวอร์ตรวจ UUID ที่เลือกอิสระ ผู้รับใช้ NeoPopupScreen ร่วมพร้อม Join/Decline และนับ 30 วินาที Invite ปิดเมื่อเต็มหรือผู้ดูไม่ใช่เจ้าของ Fight ปิดจนเต็มสองช่อง

การเปลี่ยนห้องส่งสแนปช็อตเฉพาะหลังเหตุการณ์สมาชิก/เริ่ม/ปิด อ่านอันดับใช้ PvpRankingCache ร่วม TTL 30 วินาที จอเหล่านี้ไม่ขอ Top 10 โปรโตคอล 21 เพิ่มการเชิญ เพย์โหลดเชิญ พรีวิว/อุปกรณ์สมาชิกแบบเสริม และสนามห้องที่ระบุชัด ทั้งคู่ต้องตรงรุ่น

กรอบสร้างด้วย ImageGen ในตัวจากม็อกอัป V2 อนุมัติ พรอมป์ต์สุดท้าย: คงเรขาคณิตแผง/กรอบตรงเดิม ลบข้อความ ตัวเลข ตัวละคร VS ปุ่ม ไอคอน เก็บช่องว่างและแท่น ทำภายนอกโปร่งใส และพื้นชาร์โคลต่อเนื่องหลังวิดเจ็ต ต้นฉบับ `C:/Users/miw/.codex/generated_images/01a12cf1-5f4e-7c33-b3db-dd38351503fa/exec-f443e7c6-b99c-486b-a4e1-cedccee14541.png`

คอมไพล์ Java และรีเกรสชัน PvP ผ่าน ตรวจขนาด อัลฟา และการอ้างกรอบแล้ว ยังไม่ยืนยันภาพตรงม็อกอัปที่ 1280 x 720 ในเกม การเชิญ/ยืนยันสองคนจริงและวาดอุปกรณ์จากรีจิสทรีต้องทดสอบในเกมด้วย ไม่มีภาพรันไทม์สำหรับรีวิชันนี้ จึงไม่อ้างว่าภาพเทียบเท่า
