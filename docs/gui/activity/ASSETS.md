# แอสเซ็ต GUI กิจกรรม

ภาพอ้างอิง: `monthly-reference.png` พร้อมการแก้ที่อนุมัติภายหลัง: เอารีเฟรช/รับทั้งหมดออก ใช้วันตามปฏิทิน วันก่อนหน้าหมดอายุ และใช้หีบแทนชุดรางวัล ปุ่มท้ายภาพเดิมและจำนวน 28 วันในแถบข้างถูกแทนแล้ว

`frame-source.png` และ `components-source.png` เป็นต้นฉบับที่สร้างจากภาพนั้น `export-assets.py` วัดขอบเขตอัลฟาทึบแยกคอมโพเนนต์ ไม่ใช้ช่องแอตลาสเท่ากัน ตัดพร้อมขอบเผื่อสี่พิกเซล และส่งออก PNG แบบ nearest-neighbor พร้อมเมทาดาทา `blur:false,clamp:true` ไม่ลบพิกเซลด้วย color key ส่วน `asset-manifest.json` เก็บกรอบต้นทาง ขนาดผลลัพธ์ และค่าอัลฟาต่ำสุด/สูงสุดที่วัดทั้งหมด

## ไฟล์และเลย์เอาต์

- `frame.png`: 1280×840 วาดที่ขนาดเชิงตรรกะ 640×420 มีเฉพาะกรอบว่างและเส้นแบ่งแถบข้าง ไม่มีส่วนสรุปท้ายแถบข้างหรือเส้นแบ่งท้าย
- `nav_normal/hover/selected/disabled.png`: 320×128 พื้นนำทางว่างแบบ nine-slice
- `button_normal/hover/selected/disabled.png`: 280×100 พื้นปุ่มรับ/ควบคุมว่างแบบ nine-slice
- `slot_normal/hover/selected/disabled.png`: 96×96 แสดง 48×48 สถานะเลือกคือขอบทองวันปัจจุบัน
- `icon_daily/monthly/online/pending.png`: 32×32 ตรงปฏิทินแดง/น้ำเงิน นาฬิกา และหีบในภาพอ้างอิง
- `icon_silver.png`: 32×32 ใช้ภาพเงินตลาดเดิม
- `scroll_track.png`: 16×160; `scroll_thumb.png`: 32×128 ทั้งคู่มาจากชิ้นโลหะว่างชุดเดียวกัน
- ฟอนต์ชื่อ `neoworld:activity_icons` ให้ E220–E223 สำหรับไอคอนแถบข้างรายวัน/รายเดือน/ออนไลน์/รอรับ หลบช่วง E200–E20D ของแฟชั่น `minecraft:default` อ้างรีจิสทรีนี้โดยตรง

เนื้อหาขวาเริ่ม (180,58) ขนาด 444×330 ปฏิทินมีหกคอลัมน์ ระยะ 70 แสดงสามแถว ระยะ 84 จุดเริ่มช่องคือ (column×70+9,42+row×84+10) ปุ่มรับ (column×70+4,102+row×84) ขนาด 62×20 รางเลื่อน (432,62) ขนาด 10×212 ตัวเลื่อนสูง 126 เดินทาง 86 สำหรับทั้งหมดห้าแถว ข้อความ วัน ไอคอนไอเทมรางวัล จำนวน ตัวจับเวลา และสถานะปุ่มเป็นไดนามิก

`ActivityTextures` ใช้แอสเซ็ตเหล่านี้ `NeoButton.frameRenderer` เป็นจุดเชื่อมสกินแบบเลือกใช้ ปุ่มที่อื่นคงภาพและอินพุตเดิม พรีวิวชุดรางวัลใช้หีบโดยไม่ให้หรือสร้างไอเทมกล่องรางวัลใหม่ หากมีไอเทมชนิดเดียวใช้ไอคอนและจำนวนเดิม เงินรวมกับไอเทมก็นับเป็นชุด รายการทูลทิปแยกบรรทัด

## การตรวจสอบ

รัน `export-assets.py` และ `preview-assets.py` ด้วย Python/Pillow ตัวส่งออกตรวจ RGBA ขอบตัดอัลฟาทึบครบ และขอบเผื่อไม่ทึบ `exported-parts-preview.png` แสดงชิ้นส่งออก `assembled-runtime-preview.png` ประกอบจาก PNG จริงและกรอบพิกัดรันไทม์ พร้อมตัวอย่างข้อความไทยและรางวัล เป็นการตรวจประกอบ ไม่ใช่ภาพ Minecraft และข้อความ Tahoma ไม่ใช่ฟอนต์เกม

ตรวจ Java: `gradlew.bat compileJava activityRegressionTest`
ยังต้องตรวจในเกมที่ GUI Scale รองรับ รวมชี้เมาส์/โฟกัส การตัดขอบ ลากสกรอลล์บาร์ และทูลทิป

## รางวัลออนไลน์

`online-approved-reference.png` คือเลย์เอาต์ออนไลน์สี่การ์ดที่อนุมัติ `OnlineActivityPanel` ใช้การ์ด 104×194 สี่ใบที่ x=2/114/226/338, y=98 ในเนื้อหา 444×330 เว้นแนวนอนแปดพิกเซลและขอบนอกสองพิกเซล พื้นการ์ดใช้ PNG ช่องเงิน/ทองเดิมแบบ nine-slice ขอบต้นทาง 16 มุมปลายทางคงที่ 6 จึงไม่ยืดมุมสี่เหลี่ยมเป็นทรงสูง มีเฉพาะการ์ดรับได้ที่มีขอบทอง
ช่องไอเทม 76×76 ที่การ์ด+(14,34) แถบคืบหน้า 84×10 ที่ +(10,122) จำนวน +(52,139) ปุ่ม 88×26 ที่ +(8,160) ปุ่มอยู่เหนือขอบล่างการ์ดแปดพิกเซล ใช้ `NeoProgressBar` และกรอบ/ไส้ `progress_soft_slim.png` เดิม ไม่ฝังข้อความคืบหน้าใน PNG
`preview-online.py` สร้าง `online-frame-layout-preview.png` จากกรอบส่งออกที่พิกัดรันไทม์ ภาพไอเทมสุ่มตัวอย่างจากภาพอนุมัติเพื่อตรวจเลย์เอาต์ ไม่ใช่สกรีนช็อตในเกม
