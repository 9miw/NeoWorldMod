# Player profile V4
Approved reference: docs/gui/player-profile-approved-v4.png. User approved implementation after reviewing the mockup.
One window, persistent left full-body portrait/name/level/public title, four tabs: Overview, Combat, Equipment/Fashion, Skills. No main/offhand names or slots. Armor has four slots; fashion has six. No refresh button; reopen to obtain a new snapshot. Effects tab remains absent.
Overview shows HP/Stamina/owner-only EXP; PvP rating/rank/wins/losses/win rate with unavailable/unranked states; sin and separated self title/fashion shortcuts or party invite. Combat uses real supported server values with a snapshot disclaimer. Equipment and skills show selection details. Skill names/icons come from the installed mod; no mockup levels or invented skills are used. Current conditional values are labeled as such, not added to permanent stats.
Data comes from one server snapshot; cached PvP may be older and must be described as cached. Snapshot item copies exclude containers/books/custom NBT and both hands. All dynamic content stays out of PNGs. Reference game window 1280x720; actual scale and visual equivalence require in-game verification.
