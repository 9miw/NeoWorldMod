# ที่มาต้นฉบับ

อ้างอิง `../approved-mockup.png` ตรึงจาก `../../concept-01-obsidian-silver.png` หลังผู้ใช้เลือกธีม 1

ImageGen ในตัวสร้างต้นฉบับแยกต่อไปนี้จากภาพเงิน/ดำอนุมัติ:

- `frame.png`: กรอบเหล็กตีเข้มว่าง ขอบบากเงินเหลี่ยมและมุมเรขาคณิต ไม่มีแผงใน แผ่นหัว ข้อความ ไอเทม ช่อง หรือตัวควบคุม
- `panels.png`: แผ่นหัว แผงสินค้า แผงรายละเอียดมีเส้นแบ่ง และแผงคลังแยกว่าง คงวัสดุ/ลายเงินดำตามอ้างอิง ไม่มีข้อความ ไอเทม glyph ราคา หรือกริดช่อง
- `widgets.png`: ชีตสี่คอลัมน์ปกติ/ชี้/เลือก/ปิดใช้ สำหรับช่องจัตุรัส ปุ่มมาตรฐาน ปุ่มหลักทีล และพื้นปิด สัญลักษณ์ด้านหน้าแยกต่างหาก
- `icons.png`: สำเนาม็อกอัปอนุมัติ ไม่ใช่ชีตไอคอนสร้างใหม่ ตัวส่งออกตัดลูกศรซ้าย/ขวาและปิดที่สว่างจากกรอบแคบที่วัด ไอคอนที่ทดลองสร้างถูกปฏิเสธเพราะเส้นสึกและไม่ได้ติดตั้ง

การส่งออกมีตัดภาพ ล้างอัลฟาคม เพิ่ม padding โปร่งใส และจัดตระกูลสถานะด้วย nearest-neighbor ครั้งเดียว ข้อความรันไทม์ ไอคอนไอเทม จำนวน แบ่งหน้า และค่าเงินทั้งสามเป็นไดนามิก ไม่อยู่ในพื้นเหล่านี้
