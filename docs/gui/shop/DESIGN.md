# UI ร้านค้าแบบกะทัดรัด

ธีมภาพล่าสุดที่อนุมัติ: [Obsidian Silver (ธีม 1)](obsidian/ASSETS.md) อ้างอิง `obsidian/approved-mockup.png` ตอนนี้ `ShopTextures` และ `ShopScreen` อ้างคอมโพเนนต์แยก 24 ชิ้นแล้ว เก็บ Arcane เป็นทางเลือก ส่วนด้านล่างอธิบายระบบคลาสสิกก่อนหน้า ไม่แทนการอนุมัติล่าสุด ยังไม่ได้ยืนยันภาพตรงในเกม

## การเชื่อม Obsidian

รีวิชัน V2 อนุมัติ `obsidian/layout-mockup-2026-10-20-v2.png` ผู้ใช้อนุมัติให้พัฒนาชัดเจน ขอบบนกรอบนอกตัดกึ่งกลางหัวข้อที่ y=17 ขอบล่างคงที่ หัวสินค้าที่ `(23,26)` หัวคลัง `(23,135)` แผงคลังถึง y=221 แถวเดิมเริ่ม y=146 ระยะ 18 ฮอตบาร์ y=202 เว้นหัวโดยไม่ทับช่อง แผงรายละเอียดบนตรงสินค้า y=36 ชื่อ y=46 พรีวิว y=62 ปุ่มซื้อ/ขายเต็มกว้าง H20 ที่ y=160/184 ใช้ตัวควบคุมจำนวนและตรวจเซิร์ฟเวอร์เดิม `compileJava` ผ่าน ตรวจการแยกช่อง/ป้ายแล้ว ยังไม่มีภาพในเกมใหม่เทียบ V2 พิกัดรุ่นก่อนด้านล่างเป็นประวัติ

รีวิชันเลย์เอาต์ 2026-10-20 ตามคำขอแก้ `obsidian/before-layout-2026-10-20.png`: คลังและฮอตบาร์เริ่ม x=23 ตรงกริดสินค้า ระยะ 18 พิกเซล แผงคลัง `(18,131,173,62)` รายละเอียดเลื่อนลงเป็น `(199,48,88,167)` ชื่อ y=60 พรีวิว y=76 แทนจำนวนสำเร็จรูปด้วยปุ่มลบ/บวก y=136, server action 10/11 เพิ่มลดทีละหนึ่งใน 1..64 และล้างการยืนยันที่เตรียมไว้ ซื้อ/ขายกว้าง 77 ซ้อนที่ y=160 และ y=187 สูง 22 ช่องคอนเทนเนอร์ ขอบคลิก และซิงก์ใช้พิกัดใหม่เดียวกัน พิกัดเชื่อมเดิมด้านล่างเป็นประวัติ คอมไพล์ผ่าน ยังไม่ยืนยันภาพใหม่ในเกม

รากรันไทม์ `textures/gui/shop/obsidian/` `ShopTextures` เก็บขนาด PNG และขอบทึบทั้ง 24 จาก manifest ละ padding โปร่งใสเมื่อวาด กรอบนอกแบ่งแนวนอนห้าส่วนเพื่อรักษาเพชรกลางและมุมตกแต่งคงที่ แผง/ตัวควบคุมใช้ slice มุมคงที่ แผ่นหัวข้อคงสัดส่วนครบ PNG ซ้าย/ขวา/ปิดแยกวางบนพื้น NeoButton เดิม พร้อมทูลทิปและการบรรยาย

ขอบเขตเชิงตรรกะเมนูเดิม 300x225: กรอบ `(0,0,300,225)` หัว `(80,2,140,30)` สินค้า `(18,36,173,89)` รายละเอียด `(199,36,88,93)` คลัง `(18,131,269,62)` ช่องจริงและเรขาคณิตอินพุตเดิมเป็นหลัก ฮอตบาร์อยู่ใต้แผงคลัง ป้าย ไอเทม จำนวน ราคา และ glyph Silver/Diamond เป็นไดนามิกแยก ตัวควบคุมที่ลบยังไม่มี

ตรวจสอบ: `gradlew.bat compileJava` ผ่าน ตรวจอิสระเทียบพาธ ขนาด ขอบทึบ และเมทาดาทาของ 24 รีซอร์สกับไฟล์ติดตั้ง/manifest แล้ว เกมที่เปิดยังไม่ได้โหลดคลาสใหม่ ไม่มีภาพในเกมใหม่หรือการเทียบ GUI Scale จริง โค้ดคอมไพล์แล้วแต่ยังไม่ยืนยันภาพตรงม็อกอัป

ภาพอนุมัติ `shop-compact-approved.png` คือม็อกอัปกะทัดรัดล่าสุดในงานนี้ องค์ประกอบมีกริดสินค้า 9x3 ซ้ายบน รายละเอียด/จำนวน/การกระทำขวาบน และคลังผู้เล่น 9x3 กลางพร้อมฮอตบาร์เก้าช่องด้านล่าง คงช่องจริงที่เซิร์ฟเวอร์ควบคุม ไม่มีดูทุกร้าน หมวด รีเฟรช หรือยอดกระเป๋า ยังแสดงราคา

แอตลาสหัว/ปุ่มกลางเดิมมีลายต่างจากม็อกอัป แผ่นหัวว่างใหม่เป็นส่วนภาพกรอบอนุมัติ วาดข้อความแยก ไม่ซ้อนแผ่นกลางซ้ำ สกินใช้ `NeoButton.frameRenderer` ไม่เปลี่ยนวิดเจ็ตร่วม ไม่ใช้เท็กซ์เจอร์ Market หรือสี่เหลี่ยมวาดด้วยโค้ดเป็นภาพกรอบ แผง ช่อง หรือปุ่ม

## พิกัดเชิงตรรกะ

- แคนวาส 300x225 พอดีวิวพอร์ต 320x240 พร้อมขอบ
- ภายในช่องสินค้า `(23 + column*18, 43 + row*18)` เก้าคอลัมน์สามแถว ฮิตบ็อกซ์เดิม 16x16 PNG ช่องล้อมรอบหนึ่งพิกเซลเชิงตรรกะ
- คลังผู้เล่น `(62 + column*20, 137 + row*20)` 9x3 ฮอตบาร์คอลัมน์เดียวกัน `y=199` ภายใน 16x16 และฮิตบ็อกซ์ตรงกัน
- แผงขวา `x=205..282` ชื่อ `y=45` พรีวิวที่เลือก `y=60` ราคาต่อหน่วย `y=59/72` ป้ายจำนวน `y=86` ปุ่มจำนวน `y=98` ซื้อ/ขาย `y=113`
- หัวกลางแผ่นว่าง ชื่อไอเทมกลาง ย่อ/ตัดในขอบชัดเจนและมีทูลทิปเต็ม ป้ายการกระทำยาวเลื่อนในปุ่ม
- ปิด/แบ่งหน้า/จำนวน/การกระทำใช้ขอบวิดเจ็ตเดิมเดียวกันทั้งวาดและอินพุต มีปกติ ชี้/โฟกัส เลือก ปิดใช้

## ที่มาภาพ

ใช้ `image_gen` ในตัว อ้าง `shop-compact-approved.png` ไม่ใช้ API หรือ CLI สำรอง

พรอมป์ต์กรอบ: แยกเฉพาะกรอบเงินนอกคงที่ แผงมืด เส้นแบ่ง และหัวว่างจากม็อกอัป ลบข้อความ สไปรต์ไอเทม/เหรียญ ช่องและปุ่ม คงสัดส่วนกะทัดรัด ด้านในแผงทึบและนอกกรอบโปร่งใส

พรอมป์ต์วิดเจ็ต: แอตลาสโปร่งใสแยกสี่คอลัมน์สี่แถว ตรงภาพเงิน/ทีลอนุมัติ คอลัมน์ปกติ/ชี้/เลือก/ปิดใช้ แถวช่องจัตุรัส ปุ่มเงิน ปุ่มซื้อทีล พื้นปิดจัตุรัส ไม่มีข้อความ/ไอคอน/ตัวเลข วัดขนาดและกรอบจริงหลังสร้าง ไม่สมมติตามกริดที่ขอ

## สถานะตรวจสอบ

ตรึงภาพอ้างอิงและตรวจภาพ PNG รันไทม์ที่ติดตั้งทั้งคู่แล้ว ตรวจอัลฟาและขนาดจริง วัดสไปรต์จาก alpha >220 ทั้งคู่มี `.mcmeta` ตั้ง `blur:false`, `clamp:true` หน้าจออ้างกรอบและแอตลาสใหม่ผ่าน `ShopTextures`

`compileJava` และการตรวจรีเกรสชัน Shop 37 รายการผ่านตอนเชื่อม ผลตรวจสุดท้ายอยู่ในสรุปส่งต่องาน ไม่มีภาพในเกมในงานนี้ จึงยังต้องเทียบขนาดฟอนต์ Minecraft จริง อินพุต ชี้/โฟกัส GUI Scale และสัดส่วนหน้าต่างกับม็อกอัป ภาพสร้างและคอมไพล์ผ่านไม่ใช่หลักฐานว่าภาพในเกมตรง
