# ที่มาภาพจาก ImageGen

โหมด ImageGen ในตัว พื้นโปร่งใส อ้างอิง `../approved-mockup.png` ด้านล่างเป็นสรุปพรอมป์ต์ ไม่ได้ขอเลย์เอาต์หรือเกมเพลย์ใหม่

- **กรอบนอก:** คงกรอบบางกรมท่า/ไซแอน/ม่วง คริสตัลมุม/ข้าง/ล่าง และรูนที่อนุมัติ ลบแผ่นหัว แผงใน ช่อง ตัวควบคุม ข้อความ ตัวเลข และพื้นโลก เก็บพื้นรองกรมท่าทึบว่างหนึ่งชิ้น ด้านนอกโปร่งใส
- **ชีตแผง:** แยกแผ่นหัวหลักเหลี่ยมว่าง แผงสินค้ากว้าง แผงรายละเอียดแคบมีเส้นแบ่งกลาง และแผงคลังกว้างตื้น ขอบตรงภาพอนุมัติ ไม่มีช่อง ปุ่ม ข้อความ สไปรต์ไอเทมหรือเงิน
- **แก้แผง:** คงตำแหน่งชีตและหัวว่าง ลบคริสตัลใหญ่เกินกับโซ่รูนแนวตั้งข้างแผงใน คงขอบบางเรียบ อัญมณีมุมเล็ก และเส้นแบ่งรายละเอียดตาม UI เต็มที่อนุมัติ `panels-initial.png` เก็บต้นฉบับก่อนหน้า
- **ชีตวิดเจ็ต:** สี่คอลัมน์ปกติ/ชี้/เลือก/ปิดใช้ สี่แถวช่องจัตุรัส ตัวควบคุมมาตรฐาน ปุ่มซื้อหลัก พื้นปิดจัตุรัส กรมท่า/ฟ้าน้ำแข็ง เลือกม่วง/ไซแอน แดงเฉพาะปิดขณะชี้/เลือก ไม่มีข้อความ/ไอคอนด้านหน้าหรือสัญลักษณ์เงิน
- **ไอคอนควบคุม:** เชฟรอนซ้าย ขวา และ X แยก เส้นพิกเซลขาว/ฟ้าน้ำแข็ง ไม่มีกรอบปุ่ม ป้าย ตัวเลข เงิน หรือแผ่นรอง

เก็บชีตต้นฉบับทั้งหมดครบที่นี่ ตัวส่งออกบันทึกกรอบต้นทางแม่นยำและสร้างไฟล์แยก ไม่ใช้ม็อกอัปทั้งภาพเป็นเท็กซ์เจอร์รันไทม์ ใช้ glyph เงิน Silver/Gold/Diamond เดิม ไม่สร้างใหม่
