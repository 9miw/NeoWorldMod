# ร้านค้า — ชุดแอสเซ็ต Midnight Arcane

สถานะ: เก็บเป็นทางเลือก ผู้ใช้เลือกธีม 1 ภายหลัง ดูชุดปัจจุบันที่ `../obsidian/ASSETS.md` ประวัติด้านล่างอธิบายการเลือกธีม 3 ก่อนหน้า

ภาพล่าสุดที่อนุมัติ `approved-mockup.png` คัดจาก `../concept-03-midnight-arcane.png` หลังเลือกธีม 3 แทนม็อกอัปเงินคลาสสิกเป็นภาพเป้าหมาย งานปัจจุบันคือสร้างภาพผลิตแยกชิ้น ไม่ใช่เสนอเลย์เอาต์ใหม่

## แผนแอสเซ็ตก่อนสร้าง

โฟลเดอร์รันไทม์ `src/main/resources/assets/neoworld/textures/gui/shop/arcane/`

| ไฟล์ | เนื้อหา | เนื้อหารันไทม์ที่แยก |
| --- | --- | --- |
| `frame.png` | กรอบ/พื้นรองกรมท่า ขอบไซแอนเหลี่ยมและคริสตัลม่วง ไม่มีกรอบแผงในหรือหัว | ข้อความ ตัวควบคุม แผ่นหัว กรอบแผง ช่องและไอเทมทั้งหมด |
| `panels/{title,products,details,inventory}.png` | แผงว่างสี่ชิ้นแยกส่งออก | หัว/ชื่อ/ป้าย ไม่ฝังกริดช่องหรือช่องตัวควบคุม |
| `slots/{normal,hover,selected,disabled}.png` | ช่องจัตุรัสสี่สถานะ เลือกม่วง/ไซแอนตรงภาพ | พรีวิวไอเทมและจำนวนสแต็ก |
| `buttons/{standard,primary,close}/{normal,hover,selected,disabled}.png` | พื้นตัวควบคุมว่าง 12 ชิ้น | ข้อความ ราคา ไอคอนควบคุม |
| `icons/{left,right,close}.png` | สัญลักษณ์ด้านหน้าสามชิ้น มี padding จัตุรัส ไม่รวมพื้นปุ่ม | กรอบปุ่มและสถานะอินพุต |

Silver/Diamond ใช้ `assets/neoworld/textures/font/icons/{silver,diamond}_coin.png` ผ่านฟอนต์เงินเดิม ห้ามวาดหรือลงทะเบียน glyph เงินซ้ำ

คงกริดสินค้า 9x3 อนุมัติ แผงรายละเอียดขวาบนกะทัดรัด คลัง 9x3 กลางและฮอตบาร์เก้าช่อง และเอาทุกร้าน/หมวด/รีเฟรช/ยอดกระเป๋าออก ราคาและไอคอนไดนามิก

ตรวจขนาดจริง ขอบอัลฟา และขอบสไปรต์ก่อนกำหนดแอตลาส ใช้ nearest sampling ขอบวาดจำนวนเต็ม และ slice รักษามุม หน้าต่างหลัก 1280x720 ขนาด GUI เชิงตรรกะยังขึ้นกับ GUI Scale

## ระยะส่งมอบ

ส่งออก PNG รันไทม์แยก 24 ชิ้นแล้ว ทุกชิ้นอัลฟาคม 0/255 มี padding โปร่งใสและ `.png.mcmeta` ปิด blur เปิด clamp ช่องและไอคอนใส่ padding ให้แคนวาสจัตุรัสโดยไม่ย่อขยายภาพต้นทาง ตรวจแล้วว่าปกติ/ชี้/เลือก/ปิดใช้ต่างกัน

`manifest.json` ในโฟลเดอร์รันไทม์เก็บขนาดต้นทาง กรอบตัด ขนาดผล ขอบทึบ แฮช ขอบ slice แนะนำ และอ้างอิงไอคอนเงินร่วม ลดลายกลางแผงหลังเทียบภาพอนุมัติ คริสตัลใหญ่อยู่กรอบนอก ไม่ซ้ำทุกแผงใน

ต้นฉบับอยู่ `sources/` เครื่องมือ ImageGen ในตัวสร้างจากภาพอนุมัติ `tools/export_shop_arcane_assets.py` ตัดคอมโพเนนต์และส่งออกอัลฟาคมซ้ำได้ (threshold 224) ไม่สุ่มขนาดภาพรันไทม์ใหม่ เฉพาะภาพย่อ QA ใช้ nearest-neighbor สรุปพรอมป์ต์ `sources/PROMPTS.md`

ตรวจสอบ: ข้อกำหนดส่งออกทั้ง 24 PNG ผ่าน ตรวจชิ้นจริงบนพื้นตารางใน `export-preview.png` แล้ว `compileJava` ผ่านหลังเพิ่มตัวส่งออก **แอสเซ็ตเหล่านี้ยังไม่เชื่อมตัววาด Shop Java** การส่งมอบนี้คือชุดแยกตามผู้ใช้ขอ ไม่ใช่ยืนยันว่า UI ในเกมเปลี่ยนธีมหรือตรงม็อกอัป หลังเชื่อมยังต้องตรวจในเกม 1280x720 และ GUI Scale จริง
