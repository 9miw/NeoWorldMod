# HUD โต้ตอบผู้เล่นแบบลอย

อัปเดตพฤติกรรม 2026-10-20: HUD ขณะกดค้างติดตามผู้เล่นทั้งหมดในห้าบล็อก เพิ่มชื่อเจ้าของแต่ละคนที่หัว และจัดหลายแผงไม่ให้ทับกัน ขนาดฐานใหม่ 180 x 142 (หัว 42 ออฟเซ็ตปุ่ม y 50/94) วิวพอร์ตแออัดรายงานแผงที่ซ่อนและใช้ล้อเมาส์ปรับลำดับวาง ภาพด้านล่างยังเป็นวัสดุ/สไตล์อนุมัติจากรุ่นเป้าหมายเดียว ยังไม่ได้ยืนยันภาพหลายคน ดูพฤติกรรมปัจจุบันและคำสั่งทดสอบเรขาคณิตใน `../../PLAYER_ACTION_MVP.md`

ภาพอนุมัติ `action-hud-approved.png` ม็อกอัปล่าสุดไม่มี X วันที่ 2026-10-20 หน้าต่างเทียบหลัก 1280 x 720 ต้องบันทึก GUI Scale จริงตอนตรวจในเกม ภาพนี้แทนม็อกอัปก่อนหน้าที่มีแถวชื่อและ X

## แผนผังแอสเซ็ตและเลย์เอาต์

- กรอบรันไทม์ `assets/neoworld/textures/gui/player/action_frame.png` 1456 x 1080 RGBA เมทาดาทาปิด blur เปิด clamp มีเฉพาะมุม/ขอบเงิน พื้นรองเข้ม และแถบหัวว่าง กรอบต้นทาง (88,134) ขนาด 1280 x 788 ขอบที่ alpha >=128 คือ (92,136)..(1364,916) ละ padding จางจากการสร้างนอกต้นทาง
- คอลัมน์ nine-slice 100 / 1080 / 100 แถว 220 / 468 / 100 ขอบปลายทางแนวนอน 14 หัวเต็ม 34 ล่าง 14 ทั้งหมดตามสเกล เพื่อคงมุม/หัวแทนยืดกรอบตกแต่ง
- ปุ่มใช้ `textures/gui/common/buttons.png` เดิม 1536 x 1024 สถานะ standard ปกติ/ปิดใช้ และ primary ทีลชี้/โฟกัส พิกัดต้นทางจากแอตลาส NeoButton ร่วม คงอินพุต โฟกัส เสียง การบรรยาย และสถานะ active เดิม ให้เฉพาะตัววาดฟีเจอร์
- ไอคอน `NeoSystemIcons.Icon.PROFILE` และ `PARTY` เดิม วาดแยก
- เลย์เอาต์เดิมฐาน 180 x 134 หัว y=0..34 ปุ่ม (12,42), (12,86) สูง 34 กว้าง 156 ไม่มี X แถวชื่อ/อวตาร หรือ Trade
- หัวข้อ ป้ายปุ่ม ไอคอน และคำแนะนำกดค้างขวาล่างเป็นเนื้อหารันไทม์ คำแนะนำใช้ชื่อปุ่มที่ตั้งแทนระบุ B ตายตัว

สเกลตามระยะเดิม 1.2..0.9 สำหรับ 0..3 บล็อก คูณตัวประกอบวิวพอร์ต 0.75..1.0 ความกว้างขั้นต่ำคำนึงข้อความเชิญไทยที่วัด คงขนาดข้อความเดิม การวาดกับฮิตบ็อกซ์ใช้ขอบคำนวณเดียวกัน คำแนะนำตัดบรรทัดข้างฮอตบาร์ Vanilla จอแคบมากวางเหนือแถบล่างสงวนและเว้นที่เพิ่มจากแผง

## สถานะตรวจสอบ

ตรวจขนาด/อัลฟา PNG ขอบต้นทาง การอ้างรีซอร์ส ตัวควบคุมไม่มี X และคอมไพล์ Java แล้ว โค้ดและแอสเซ็ตเชื่อมในซอร์สแล้ว ยัง **ไม่ได้** ยืนยันภาพตรงม็อกอัปในเกม ไม่ได้บิลด์หรือติดตั้งแพ็กเกจใหม่ในงานนี้

ภาพที่ต้องตรวจต่อ: จับภาพสองผู้เล่นที่ 1280 x 720 พร้อม GUI Scale จริง เทียบหัว มุม ระยะปุ่ม ไอคอน และชี้เมาส์กับภาพอนุมัติ ตรวจขนาดใกล้/ไกล คลิกเมาส์อิสระ ปล่อยแล้วปิด ตำแหน่งสำรองริมจอ ระยะหลบ HUD โฟกัส และชื่อปุ่มที่ตั้งยาว
