# แอสเซ็ตทูลทิปแฟชั่น

- `tooltip-icons-source.png`: ชีตไอคอนโปร่งใสที่ดัดแปลงจากคอนเซปต์อนุมัติ
- `export-tooltip-icons.ps1`: วัดขอบอัลฟาต่อช่องและส่งออกไอคอน 32 x 32 พร้อม padding ปรับขนาดด้วย nearest-neighbor
- `preview-tooltip-icons.ps1`: แสดงผลส่งออกจริงที่ 64, 32 และ 10 พิกเซล ไม่ใช่สกรีนช็อตในเกม
- ฟอนต์รันไทม์ `neoworld:fashion_tooltip`: glyph การกระทำ E200-E207 และช่อง E208-E20D, height 10 / ascent 8 รีจิสทรีดูแลเองนี้แยกจากสามรีจิสทรีของตัวสร้างฟอนต์ทั่วไป
- `tooltip-slot-icons-source.png`: ไอคอนหกหมวด ศีรษะ ใบหน้า หลัง ลำตัว ขา เท้า รันสคริปต์ส่งออก/พรีวิวด้วย `-Slots` เพื่อทำชีตนี้โดยไม่แทนไอคอนการกระทำเดิม
- PNG ช่องคือ `slot_head`, `slot_face`, `slot_back`, `slot_body`, `slot_legs`, `slot_feet` ในโฟลเดอร์เท็กซ์เจอร์ทูลทิปรันไทม์ จับคู่ E208-E20D ตามลำดับ `FashionTooltip.slotIcon` ครอบคลุมทุก `FashionSlot` ชัดเจน
- กรอบรันไทม์ใช้ `fashion_shell.png` แบบ nine-slice ไม่ฝังข้อความหรือข้อมูลไอเทม
- `FashionTooltip` เพิ่มเนื้อหาตามภาษาฝั่งไคลเอนต์ให้ `SimpleFashionItem` และคลาสลูก GeckoLib คง lore แอตทริบิวต์ และบรรทัดทูลทิปขั้นสูงหลังเนื้อหาที่แทรก
- ความเป็นเจ้าของใช้ตู้ที่ซิงก์ฝั่งไคลเอนต์ ตัวจัดการทูลทิปไม่ส่งแพ็กเก็ตหรือใช้ไอเทม
- color hook ของ NeoForge ให้ตำแหน่งทูลทิป Vanilla สุดท้าย การตัดบรรทัด วาดคอมโพเนนต์ และตำแหน่งยังเป็นหน้าที่ Minecraft

ยังต้องเทียบภาพใน Minecraft โดยเฉพาะสระ/วรรณยุกต์ไทย GUI Scale ขอบจอ และม็อดแก้ทูลทิป ไอคอนส่งออกใช้ต้นทาง 32 พิกเซลเพื่อคงรายละเอียดภาพอนุมัติ แต่แสดงที่ความสูงฟอนต์เล็กกว่า
