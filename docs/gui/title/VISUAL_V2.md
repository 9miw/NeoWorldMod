# การแก้ภาพ GUI ฉายา

ภาพอนุมัติ `title-management-mockup-v1.png` ภาพในเกมที่รายงานว่าไม่ตรง `title-before-v2.png` ไม่ระบุ GUI Scale

การเปลี่ยน: ใช้สไปรต์ปุ่มเงินขอบบากเฉพาะหน้าฉายาที่ไม่มีหมุด สถานะหลัก/เลือกทีล และหมู่บ้าน voxel มืดหลังผู้เล่น วาดผู้เล่นนอกทรานส์ฟอร์มเลย์เอาต์เชิงตรรกะด้วยขอบจอจริงเพื่อให้กรอบตัดของตัววาดคลังตรงวิวพอร์ต เพิ่มวิวพอร์ตเป็น (333,76)-(447,169) เชิงตรรกะ ขนาด 44 หน้าจอคงเลย์เอาต์ 480x320

แอสเซ็ตรันไทม์ใต้ `assets/neoworld/textures/gui/title/`:

- `title_button_{normal,hover,primary,disabled}.png`: ไฟล์ละ 1440x200 แอตลาสต้นทาง `sources/title-buttons-v2.png` กรอบ (48,64+228*i,1440,200) ส่งออกใหม่ด้วย `export-title-buttons.ps1` ขอบต้นทาง nine-slice 40 พิกเซล
- `title_preview_scene.png`: 1024x1536 วาดที่ (312,49,152,172) จากต้นทาง (0,220,1024,1159) เพื่อคงสัดส่วน
- กรอบหลัก แผงซ้าย/ขวา และสไปรต์แถวเดิมยังแยกกัน

สร้างด้วยเครื่องมือภาพในตัว ชุดพรอมป์ต์:

1. แอตลาสเท็กซ์เจอร์ UI เกมพร้อมผลิต 1536x1024 โปร่งใส ปุ่มแนวนอนว่างสี่แถวตรงกัน พิกเซลอาร์ต RPG Minecraft ขอบเงินบากบาง ไม่มีหมุด นอต ข้อความ ไอคอน ปกติชาร์โคล ชี้ไซแอน หลักทีล ปิดใช้เทา กลางเรียบสำหรับ nine-slice
2. ภาพแนวตั้ง 1024x1536 ทึบ หมู่บ้านยุคกลาง voxel Minecraft ช่วงฟ้าสีน้ำเงิน กลางว่างสำหรับผู้เล่นรันไทม์ ลานหิน ต้นไม้ กระท่อมโคมอุ่น คอนทราสต์ต่ำกรมท่า/ทีล ไม่มีตัวละคร ข้อความ กรอบ ปุ่ม

ตรวจสอบ: ตรวจคอมไพล์ Java ขนาด/อ้างอิงรีซอร์สรันไทม์แล้ว ยังไม่มีภาพในเกมใหม่ ให้เทียบที่ 1280x720 และบันทึก GUI Scale จริงก่อนอ้างว่าตรงภาพอนุมัติ
