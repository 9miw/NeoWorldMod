# สกินปุ่มลอยร่วม

ภาพอนุมัติ `floating-menu-preview-v3-bottom-center.png` หน้าต่างอ้างอิง 1280x720 ต้องทราบ GUI Scale จริงก่อนเทียบขอบเขตเชิงตรรกะ

ใช้ `NeoButton.skin(NeoButton.Skin.FLOATING)` แยกจากสไตล์สี/การกระทำ `CLASSIC` ยังเป็นค่าเริ่มต้น ตัววาดร่วมรับผิดชอบภาพ nine-slice สีสถานะ และความทึบ `NeoPauseScreen` ไม่ทำตัววาดซ้ำแล้ว คงเลย์เอาต์ ฮิตบ็อกซ์ เนื้อหาไดนามิก และการกระทำเดิม

## การจับคู่แอสเซ็ต

- PNG: `src/main/resources/assets/neoworld/textures/gui/menu/floating_button.png`
- ขนาด 1386x1135 กรอบต้นทาง x34, y140, กว้าง 1318, สูง 836
- ขอบ slice 120 พิกเซลต้นทาง มุมปลายทางเริ่มต้น 8 พิกเซลเชิงตรรกะ ปรับด้วย `.skinCornerSize(int)` และจำกัดตามขอบวิดเจ็ต
- อัลฟากลางต้นทาง 252/255 ตัวคูณความทึบกลาง 0.62 ขอบ 1.0 ทั้งคู่คูณอัลฟาวิดเจ็ต พื้นนอกโปร่งใส
- `.png.mcmeta` ตั้ง blur false และ clamp true
- ไม่ฝังข้อความ/ไอคอนใน PNG

Standard ปกติเป็นกลางและไฮไลต์ทีล Primary ปกติทีล Destructive ใช้แดง ชี้เมาส์/โฟกัสเพิ่มความชัด เลือกใช้ทองสำหรับ Standard/Primary และแดงสำหรับ Destructive ปิดใช้หรี่ทั้งกรอบ การแทนด้วย `frameRenderer(...)` เดิมยังสำคัญกว่าสกินที่เลือก

## การตรวจสอบ

`compileJava` ผ่าน ตรวจขนาด PNG จริง อัลฟากลาง/นอก และการจับคู่ต้นทางแล้ว ยังไม่ได้เทียบภาพเกม จึงยังไม่ยืนยันความตรงกับม็อกอัปและความชัดของสถานะในเกม งานไอคอนเมนูอื่นที่กำลังทำอยู่นอกขอบเขตเปลี่ยนสกินนี้
