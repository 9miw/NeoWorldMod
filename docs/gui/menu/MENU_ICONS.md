# ไอคอนเมนูลอย

องค์ประกอบอนุมัติ `floating-menu-preview-v3-bottom-center.png` หน้าต่างอ้างอิง 1280 x 720 GUI Scale จริงเป็นการตั้งค่าแยก

สร้างด้วย imagegen ในตัวโดยใช้องค์ประกอบอนุมัติอ้างอิง พรอมป์ต์: แอตลาสโปร่งใส 4 คูณ 4 มีไอคอนระบบหกตัวตามด้วยตัวควบคุมเกมเจ็ดตัว ให้ตรงภาพอ้างอิง ไม่มีป้าย ปุ่ม หรือฉาก

แอตลาสรันไทม์ `src/main/resources/assets/neoworld/textures/gui/menu/menu_icons.png` ขนาดจริง 1254 x 1254 อัลฟาด้านนอกศูนย์ เมทาดาทาปิด blur เปิด clamp กรอบสไปรต์ที่วัดจริงแทนสมมติช่องเท่ากันอยู่ใน `docs/gui/menu/export-menu-font-icons.ps1` ส่งออกเป็น glyph บิตแมปร่วม `client/gui/common/NeoSystemIcons.java` วาด glyph แทน `NeoMenuIcons` เฉพาะเมนูที่ลบแล้ว ดู ID ฟอนต์ การจับคู่ การแทน และตรวจสอบใน `MENU_FONT_ICONS.md` ข้อความ สถานะปุ่ม และฮิตบ็อกซ์แยกต่างหาก

ลำดับ: โปรไฟล์ ป้ายฉายา หีบ เกราะหนัง หัวผู้เล่นสามหัว กุญแจทอง เล่นต่อทีล เฟืองเงิน บล็อกหญ้า หนังสือเปิด แท่งเงินสูงขึ้น เครือข่ายทีล ออกแดง สามช่องแอตลาสสุดท้ายไม่ใช้ ระบบเพิ่มเติม PvP และกิจกรรมคงไอคอนไอเทมที่ลงทะเบียน ปุ่มปิดใช้หรี่ไอคอน

การตรวจสอบ: ตรวจภาพต้นทางและขอบเขตที่วัดแล้ว รายงานคอมไพล์ในแชต ยังไม่มีสกรีนช็อตในเกมที่อัปเดต ต้องตรวจภาพเทียบม็อกอัปที่ 1280 x 720, GUI Scale อื่น และสถานะชี้/ปิดใช้ในเกม
