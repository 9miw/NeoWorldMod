# ไอคอนระบบบิตแมปร่วม

ต้นฉบับอนุมัติ `floating-menu-preview-v3-bottom-center.png` และ `textures/gui/menu/menu_icons.png` เดิม 1254x1254 หน้าต่างอ้างอิง 1280x720 แยกจาก GUI Scale ของ Minecraft การย้ายนี้ไม่ได้สร้างภาพใหม่

## ส่งออกและใช้ซ้ำ

รัน `export-menu-font-icons.ps1` จากโฟลเดอร์นี้เพื่อสร้างภาพโปร่งใส 64x64 แยก 13 ภาพจากกรอบต้นทางที่วัด คงสัดส่วน มีขอบเผื่ออย่างน้อยสองพิกเซล ใช้ nearest-neighbor และเมทาดาทา blur:false/clamp:true เก็บแอตลาสเดิมไว้

กรอบต้นทางที่เคยอยู่ใน `NeoMenuIcons` บันทึกในตัวส่งออกแล้ว `NeoPauseScreen` ใช้การวาดบิตแมป `common/NeoSystemIcons` ลบตัววาดแอตลาสเฉพาะเมนูที่เลิกใช้แล้ว ข้อความไดนามิก สกินปุ่ม อินพุต และคอลแบ็กฟีเจอร์แยกจากตัววาดฟอนต์

## ตรวจรายการซ้ำ

ตรวจแอตลาสต้นทางและภาพรวมพาธภาพไม่ซ้ำ 196 รายการจากรีจิสทรีฟอนต์ปัจจุบัน รวมชีตภาษา/แรงก์ แทนภาพเฉพาะความหมายเดิม: หีบ เฟืองตั้งค่า และเสื้อ/เกราะสำหรับเปิดแฟชั่น คง glyph, ID ฟอนต์ และเมตริก provider

คงความหมายแยก: ช่องอุปกรณ์เกราะกับเปิดแฟชั่น โปรไฟล์กับสมาชิก/กลุ่ม LAN กับเชิญปาร์ตี้ ออกจากเกมแดงกับออกปาร์ตี้ไซแอน กิจกรรมรอรับกับหีบเก็บ ไม่เปลี่ยนรีจิสทรีเงิน แรงก์ ภาษา กิจกรรม การกระทำปาร์ตี้ หรือ HUD ดันเจี้ยน การใช้ codepoint เดียวข้ามฟอนต์มีชื่ออาจตั้งใจไว้ ต่อมาย้ายกิจกรรมไป E220–E223 เพื่อรองรับฟอนต์เริ่มต้น เหลือ E200 ให้แฟชั่น ไอคอนทั้งหมดเข้าถึงผ่านการอ้างตรงจาก `minecraft:default` ไปรีจิสทรีเดิม ตัวช่วยแบบมีชนิดและเมตริกต้นทางยังใช้ได้ ไม่มีฟอนต์แชตแยก

## การตรวจสอบ

- compileJava และ compileRegressionTestJava ผ่าน
- ตรวจการอ้างเท็กซ์เจอร์และเมตริกบิตแมป 215 provider ไม่พบ glyph ไม่ใช่ศูนย์ซ้ำภายในรีจิสทรีเดียว E300–E309 ว่างก่อนย้าย
- คงรหัสและเมตริกไอคอนทั่วไปเดิม ไฟล์รีจิสทรีอื่นทั้งหมดไม่เปลี่ยน
- รันตัวสร้างสองครั้งในสำเนาแยก ยังคงการจับคู่ glyph/ไฟล์/เมตริกทั้งหมด ไม่ได้นำภาพภาษาเข้าไอคอนทั่วไป
- ตรวจอัลฟา/ขนาดแคนวาส PNG ส่งออก และภาพรวมไอคอนแล้ว
- ยังไม่มีภาพในเกม ต้องเทียบเลย์เอาต์ฟอนต์และสถานะปิดใช้ที่ GUI Scale จริง คอมไพล์อย่างเดียวไม่ใช่หลักฐานภาพ

งานเลย์เอาต์เมนู/ขนาดด็อกที่ทำพร้อมกันเป็นของแชตต้นทาง การย้ายนี้เปลี่ยนเฉพาะการวาด glyph ไม่เปลี่ยนกริดที่ตั้งใจหรือการกระทำฟีเจอร์
