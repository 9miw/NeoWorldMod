# ปุ่มติดตามในรายการเควสต์ Custom NPCs

## ขอบเขต

เพิ่มปุ่มเดียวใน GuiQuestLog เดิมซึ่งเปิดด้วยปุ่ม L ไม่เปลี่ยนคีย์ ไม่แทนที่สมุดเควสต์ และไม่เปลี่ยนวิธีสำเร็จ/รับรางวัลเควสต์

## การจัดวาง

- ใช้ `NeoButton` สี Primary และ PNG ปุ่มกลางเดิม ไม่มีภาพหรือข้อความอบลงพื้นหลังใหม่
- ฝั่งซ้ายของ Custom NPCs เดิมมีรายการที่ `(guiLeft+5, guiTop+15)` ขนาด `134x174`
- ลดรายการเป็น `134x150` และเพิ่มปุ่ม `134x20` ที่ `(guiLeft+5, guiTop+169)` เว้นช่อง 4 logical pixels ปุ่มสิ้นสุดที่ y+189 ภายในกรอบหนังสือสูง 195
- ตำแหน่งและ hitbox ใช้ logical GUI coordinates เดียวกัน ไม่สมมติว่า 1280x720 ใช้ GUI Scale เท่าใด

## พฤติกรรม

- แสดงคำว่า “ติดตาม” / “Track” ตามภาษาเกม ใช้สถานะ normal/hover/disabled ของ NeoButton
- เลือกเควสต์ก่อนจึงกดได้ ตรวจ ID ปัจจุบันอีกครั้งตอนคลิก และต้องยังอยู่ในรายการ activeQuests
- ปิดหน้าจอผ่าน `onClose()` แล้วส่ง `neoworld questnav track <id>` เซิร์ฟเวอร์ตรวจเควสต์และจุดหมายเหมือนคำสั่งที่พิมพ์เอง ข้อผิดพลาดแสดงในแชต
- ไม่แสดงปุ่มเหนือ sub-GUI และไม่ให้ใช้ขณะตาย/เป็นผู้ชม
- เชื่อมกับ init ของ GuiQuestLog โดยตรง เพราะต้นฉบับเรียก init เองเมื่อเปลี่ยนหมวด เควสต์ และหน้า ลบปุ่มเดิมก่อนเพิ่มใหม่เพื่อไม่ให้ซ้ำ

## การตรวจสอบ

โค้ดคอมไพล์และ regression tests ผ่านแล้ว ยังไม่มี screenshot จากเกม จึงยังไม่ยืนยันตำแหน่งภาพจริง ต้องตรวจที่หน้าต่าง 1280x720 และ GUI Scale ที่ผู้เล่นใช้อยู่ พร้อมเปลี่ยนหมวด/หน้า ย่อขยายหน้าต่าง สถานะไม่มีเควสต์ และการควบคุมด้วยคีย์บอร์ด
