# ภาพพรีวิวดันเจี้ยน

ตั้ง PNG รายดันเจี้ยนด้วยสิทธิ์แอดมิน:

```mcfunction
/neoworld dungeon set dung01 image neoworld:textures/gui/dungeon/previews/forgotten_mine.png
/neoworld dungeon info dung01
```

คืนภาพเริ่มต้นที่ติดตั้ง:

```mcfunction
/neoworld dungeon set dung01 image clear
```

บันทึกภาพอัตโนมัติใน `data/neoworld_dungeons.dat` ของ Overworld การเปลี่ยนรูปลักษณ์นี้คงสถานะ enabled/draft ของนิยาม โลกเดิมที่ไม่มีฟิลด์ภาพใช้ค่าเริ่มต้น เปิดเบราว์เซอร์ใหม่หลังเปลี่ยนภาพเพื่อรับค่าใหม่

## ไฟล์สกรีนช็อต

ใช้ภาพ PNG จาก F2 ใน Minecraft ที่ความละเอียดเดิมได้ แนะนำต้นทาง 1280x720 หรือ 1920x1080 และวัตถุหลักใกล้กลาง ไม่มีขนาดตายตัว ทั้งภาพย่อจัตุรัสและพรีวิวแนวนอนตัดกลางจากขนาด PNG จริงโดยไม่ยืด หน้าสร้างห้องใช้ภาพเดียวกันแต่ตัดกลางตามกรอบของตน

ใช้ชื่อไฟล์ตัวเล็ก เช่น `forgotten_mine.png` แล้ววางในที่ใดที่หนึ่ง:

- ซอร์สม็อด: `src/main/resources/assets/neoworld/textures/gui/dungeon/previews/` ต้องบิลด์/ติดตั้งม็อดใหม่เพื่อแจกไฟล์นี้
- รีซอร์สแพ็ก: `assets/neoworld/textures/gui/dungeon/previews/` ผู้เล่นทุกคนต้องเปิดแพ็ก หรือรับเป็นรีซอร์สแพ็กของเซิร์ฟเวอร์

คำสั่งส่งตัวระบุรีซอร์ส ไม่ส่งไบต์ภาพ รูปที่เหลือใน `screenshots/` ของเครื่องหรือคัดลอกไว้เฉพาะเซิร์ฟเวอร์ไม่ใช่เท็กซ์เจอร์ไคลเอนต์ หาก PNG ไม่มี/อ่านไม่ได้ใช้พรีวิวเริ่มต้น อ่านขนาด PNG ครั้งเดียวและแคชจนรีโหลดรีซอร์ส (F3+T) เพิ่ม `.png.mcmeta` ชื่อคู่กันเพื่อปิด blur เปิด clamp ให้ภาพคมได้

โปรโตคอลไคลเอนต์/เซิร์ฟเวอร์เป็น 22 หลังเพิ่มฟิลด์ภาพ ตรวจคอมไพล์ การบันทึก/โหลด NBT ภาพและรองรับย้อนหลัง การเข้ารหัส/ถอดรหัสฟิลด์แพ็กเก็ต พาธผิด และเรขาคณิตการตัดสกรีนช็อตแล้ว ภาพในเกมและการรีโหลดแพ็กจริงยังต้องตรวจ
