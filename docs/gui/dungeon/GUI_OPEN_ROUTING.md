# การเลือกเส้นทางเปิด GUI ดันเจี้ยน

คำสั่งเปิดห้องเดิมของผู้เล่นเมื่อเป็นสมาชิกอยู่แล้ว ตัวจัดการคำขอเบราว์เซอร์ใช้การตรวจสมาชิกโดยเซิร์ฟเวอร์แบบเดียวกัน ครอบคลุมทางเข้าตรงจากไคลเอนต์ เช่น ฮับ และไม่ต้องผ่านเบราว์เซอร์

ตัวควบคุมเปิดฝั่งไคลเอนต์รอคำตอบเซิร์ฟเวอร์แทนเปิดเบราว์เซอร์ว่างทันที คำตอบห้องยกเลิกคำขอเบราว์เซอร์ที่รอ คำตอบแค็ตตาล็อกเปิดเบราว์เซอร์เฉพาะเมื่อยังอยู่หน้าต้นทาง การอัปเดตแค็ตตาล็อกที่ไม่ได้ขอไม่แทนหน้าห้องหรือจออื่น ล้างสถานะ UI ที่รอเมื่อหลุด รูปแบบแพ็กเก็ตเดิม

ไม่เปลี่ยนกฎสร้างห้อง สมาชิก พร้อม/เริ่ม สิทธิ์ หรือเกมเพลย์ ต้องทดสอบเปิดใหม่ในฐานะเจ้าของ/สมาชิก เปิดเมื่อไม่มีห้อง ออกแล้วเปิดใหม่ เปิดจากฮับ/คำสั่ง และหลุดระหว่างรอคำตอบ การคอมไพล์/รีเกรสชันไม่แทนการตรวจหลายผู้เล่นในเกมเหล่านี้
