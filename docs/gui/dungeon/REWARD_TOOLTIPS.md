# ทูลทิปรางวัลในห้อง

การชี้รางวัลใน DungeonRoomScreen ยังเรียกตัววาดทูลทิป ItemStack เดิม ตัวจัดการ GatherComponents ฝั่งไคลเอนต์เพิ่มบรรทัดรางวัลหลังสร้างทูลทิป ไม่แทนชื่อ แอตทริบิวต์ คำอธิบาย คอมโพเนนต์ภาพ หรือหัว/กรอบไอเทม NeoWorld ร่วม มีผลเฉพาะช่องรางวัลที่กำลังชี้ในห้องรอ ไม่ใช่ไอเทมคลังหรือจออื่น ใช้ไอคอนร่วมและป้ายสีแยกส่วนที่เพิ่ม

กฎพรีเซ็ตให้โอกาสตรงตามแต่ละช่องที่บันทึก และช่วงจำนวนเมื่อได้รับช่องนั้น จำนวนเริ่มต้นใช้สแต็กเดิม เมทาดาทาเก็บในลูปเดียวกับ ItemStack พรีวิว จึงยังจัดไอเทม/รายละเอียดตรงกันเมื่อช่องว่าง โอกาสศูนย์ เกินขนาด หรือถูกตัด ไม่รวมชนิดไอเทมซ้ำ เพราะอาจมีโอกาส/ช่วงจำนวนต่างกัน

พรีวิว Loot Table ปัจจุบันระบุโอกาส/จำนวนว่าไม่ทราบ แสดงข้อความเงื่อนไข Loot Table แทนเดาความน่าจะเป็นจากน้ำหนักหรือจำนวนตัวอย่าง ไม่เปลี่ยนหรือสุ่มลูต

รันไทม์ปัจจุบันใช้คลังรางวัลแยกผู้เล่น ท้ายจึงระบุรางวัลส่วนตัวโดยไม่แย่งไอเทม ไม่แสดงโหมดแบ่งปันที่ยังไม่ได้ทำ

DungeonBrowserDataPayload ส่ง DungeonRewardDetail แบบมีขีดจำกัดหนึ่งรายการต่อไอเทม codec พรีวิวซ้อนเดิมของห้องส่งรายละเอียดด้วย โปรโตคอลเครือข่าย 29 ทั้งไคลเอนต์และเซิร์ฟเวอร์ต้องอัปเดต คอนสตรักเตอร์ Entry เก่าใช้กฎไม่ทราบเป็นค่าเริ่มต้นเพื่อรองรับผู้เรียกภายใน ไม่ใช่ข้อมูลเครือข่ายเก่า

compileJava และ dungeonBrowserRegressionTest ตรวจความถูกต้อง ค่าเริ่มต้นจำนวน รูปแบบเปอร์เซ็นต์ fallback ไม่ทราบ และการเข้ารหัส/ถอดรหัสตามลำดับ ยังไม่ยืนยันภาพทูลทิปในเกมและการใช้ร่วมกับทูลทิปภายนอก
