# HUD ดันเจี้ยน: Minimal Strip

ภาพอนุมัติปัจจุบัน: `hud-minimal-approved.png` (แบบ 02) แทนกรอบเงินเดิมใน `HUD_ASSETS.md` ซึ่งยังอธิบายแอสเซ็ตต้นทางที่เก็บไว้และสัญญาข้อมูลเซิร์ฟเวอร์

## องค์ประกอบที่ติดตั้ง

- ตัววาด: `client/gui/overlay/DungeonOverlay.java`
- พื้นที่เชิงตรรกะ 220x112 ปรับด้วยค่าตั้ง 0.6 เดิมและขนาดวิวพอร์ต เมื่อพอดีเต็มใช้ 132x67.2 หน่วย GUI จากเดิม 132x96
- ขอบขวา 8 หน่วย GUI จัดกลางแนวตั้งด้วยความสูงหลังสเกล
- กรอบว่าง `textures/gui/dungeon/hud/minimal_strip.png` 440x224 RGBA เส้นเงินบางบน/ล่าง แต้มไซแอนซ้าย พื้นรองเข้มโปร่งแสง
- หัวข้อ (18,14); เวฟ/ศัตรูหรือบอส/HP ที่ y=36; แถบคืบหน้า 188x2 ที่ (18,55)
- เวลาและสมาชิกมีชีวิต/ทั้งหมดอยู่ y=68 ร่วมกัน สถานะกลาง y=88
- ราง/ไส้ `minimal_track.png`, `minimal_fill.png` ขนาด 376x4 ทั้งคู่ HP บอสใช้ `boss_fill.png` แดงเดิม ตัดปลายทางและ UV พร้อมกัน
- ใช้ glyph นาฬิกา/สมาชิก `neoworld:dungeon_hud` เดิม ย้อมทอง/ไซแอน ภาพไม่เหมือนไอคอนนาฬิกา/คนแบบเส้นในคอนเซปต์ทุกจุด
- ข้อความเป็นไดนามิก วัด/ตัดชื่อ และไม่รับอินพุต

รุ่นนี้ไม่วาดกรอบหนา เส้นแบ่ง และแถบมีกรอบเดิม เก็บไว้เป็นแอสเซ็ตย้อนหลัง แพ็กเก็ตเซิร์ฟเวอร์ กฎรางวัล การมองเห็นและวงจร HUD คงเดิม

## ต้นฉบับและส่งออก

`hud-minimal-source.png` เป็นกรอบว่างที่สร้างจากม็อกอัปอนุมัติ ขนาด 1774x887 ขอบอัลฟาจริงเหนือค่า 8 คือ (115,256,1544,376) ไม่มีข้อความ ไอคอน หรือแถบคืบหน้าเติมสี ส่งออกโดยปรับพื้นรองว่างและเส้นตรงเป็น 440x224 องค์ประกอบเหล่านี้ไม่มีสัดส่วนลายตกแต่งที่ต้องรักษา ใช้ nearest-neighbor รางกลางและไส้ไซแอนสุ่มจากภาพอนุมัติโดยไม่มีข้อความ PNG รันไทม์ทั้งหมดปิด blur เปิด clamp

```powershell
& docs/gui/dungeon/export-hud-minimal.ps1 `
  -Shell docs/gui/dungeon/hud-minimal-source.png `
  -Mockup docs/gui/dungeon/hud-minimal-approved.png
```

ตรวจ PNG รันไทม์ ขนาด อัลฟา เมทาดาทา และการอ้างอิงโค้ดแล้ว `gradlew.bat compileJava` ผ่าน ไม่มีภาพเทียบในเกมปัจจุบัน จึงยังไม่ยืนยันว่าตรงม็อกอัป ต้องตรวจความอ่านง่ายภาษาไทย เส้นบาง GUI Scale เล็ก สถานะเวฟ/บอส/ชนะ และโหมดมีเวลา/ไม่จำกัดในการตรวจภาพในเกมครั้งหน้า
