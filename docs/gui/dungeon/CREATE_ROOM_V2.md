# หน้าสร้างห้อง V2

## เลย์เอาต์และพฤติกรรม

กรอบคงสัดส่วน 4:3 สูงสุด 560x420 หน่วยเดิม และเว้นขอบวิวพอร์ต 12 หน่วย หัวข้อ ปุ่มปิด และปุ่มท้ายอยู่นอกกรอบตัดเนื้อหา ตัดข้อความตามความกว้างคอลัมน์ที่วัดแทนสเกลทั้งหมด เนื้อหามีเมทาดาทาซ้าย พรีวิวขวาขนาดพอเหมาะ เงื่อนไขสองแถว ข้อมูลเวฟ/บอส และรางวัลไอเทมเท่านั้น

โหมดดันเจี้ยนตายตัว บิต solo/trio/raid ที่ตั้งเพียงตัวเดียวตรงกับผู้เล่น 1/3/6 คน ไม่แสดงตัวเลือกโหมด หากไม่มีหรือกำกวมปิด Create โซโลไม่แสดงข้อกำหนดปาร์ตี้ โหมดทีมแสดงข้อกำหนดหัวหน้าและขนาดปาร์ตี้ สิ่งเหล่านี้เป็นเงื่อนไข ไม่ใช่การยืนยันฝั่งไคลเอนต์ว่าผ่านเกณฑ์เซิร์ฟเวอร์แล้ว

หน้าต่างเล็กใช้สกรอลล์บาร์แนวตั้งร่วมกับเนื้อหา ปุ่มท้ายคงที่และไม่ถูกบัง การเลื่อนรางวัลแนวนอนอิสระและแสดงเฉพาะล้น กรอบตัดซ้อนจำกัดพรีวิวตามแถว/เนื้อหา โดยขอบทูลทิป/อินพุตตรงกัน ตัวควบคุมรางวัลที่ถูกตัดไม่ดักคลิกท้าย คงโฟกัส/ลาก Vanilla ล้อเมาส์เหนือรางวัลเลื่อนแถวนั้น เหนือส่วนอื่นเลื่อนเนื้อหา

ไม่มีแถว EXP หรือเงิน รางวัลสุ่มคงตัวบอกพรีวิวไม่ครบ ข้อมูลเกม glyph และ ItemStack แยกจากกรอบทั้งหมด

## การตรวจสอบ

compileJava และ dungeonBrowserRegressionTest ผ่าน ทดสอบเรขาคณิตวิวพอร์ต GUI 320x240, 426x240, 640x360, 1280x720, 1920x1080 ครอบคลุมขอบกรอบ การแยกท้าย แถวไอเทมที่เข้าถึงได้ ขนาดช่อง และ mode mask ผิด ตรวจขนาด/อัลฟา/การสุ่มตัวอย่างจาก PNG ที่ติดตั้ง

โค้ดคอมไพล์แล้ว ยังไม่ยืนยันว่าตรงม็อกอัปในเกม ต้องมีภาพจริงที่ 1280x720 พร้อม GUI Scale ที่บันทึกไว้ รวมการเลื่อนแบบเล็ก ลากแนวนอน ป้ายไทยยาว และผลตอบกลับสร้างห้อง
