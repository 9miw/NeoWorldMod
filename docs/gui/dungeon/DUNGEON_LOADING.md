# หน้ารอเริ่มดันเจี้ยน

เซิร์ฟเวอร์เข้าคิวเริ่มห้องหลังส่งเพย์โหลดโหลดให้สมาชิกออนไลน์ทุกคนห้าทิก สถานะ STARTING ปฏิเสธการเริ่มซ้ำและการกระทำห้องเดิม งานในคิวตรวจห้องและข้อกำหนดเริ่มทั้งหมดซ้ำก่อนเตรียมและวางโครงสร้างแบบซิงโครนัส

ไคลเอนต์ใช้ PNG ของ NeoTitlePlaque ร่วมและ NeoProgressBar แบบไม่ระบุความคืบหน้าที่พิกัด GUI เดิม หัวข้อเป็นไดนามิกและตัดตามความกว้าง ไม่อ้างเปอร์เซ็นต์หรือความคืบหน้ารายชิ้น บล็อก Escape ระหว่างเตรียม หน้านี้ไม่หยุด integrated server

เมื่อเสร็จ ปิดเฉพาะหน้าโหลดของห้องตรงกัน ไม่ปิดจออื่นรวมหน้ากำลังโหลดมิติของ Minecraft หากล้มเหลวล้างหน้าโหลด แจ้งเหตุในแชต และเปิดห้องปัจจุบันให้สมาชิกออนไลน์แต่ละคน ตรวจคนหลุดซ้ำก่อนเริ่ม ข้อยกเว้นรันไทม์บันทึกล็อกและปิดหน้าโหลด

การวางโครงสร้างยังทำแบบซิงโครนัสบนเซิร์ฟเวอร์ การเปลี่ยนนี้เป็นตัวบอกรอ ไม่ลดต้นทุนทิกหรือแก้โลกแบบอะซิงโครนัส โปรโตคอล 24 ต้องใช้ไคลเอนต์/เซิร์ฟเวอร์ตรงรุ่น

การตรวจสอบ: compileJava และ dungeonBrowserRegressionTest รวมการเข้ารหัส/ถอดรหัสและขอบเขต loading codec ภาพในเกม จังหวะล้มเหลว/หลุดหลายผู้เล่น และลำดับเปลี่ยนมิติยังต้องตรวจรันไทม์
