# เบราว์เซอร์ถ้ำคริสตัล

ต้นฉบับอนุมัติ: `browser-crystal-approved.png` (ธีม 1) ขอบเขตเฉพาะหน้าเลือกดันเจี้ยน

## การแยกแอสเซ็ต

รากรันไทม์: `assets/neoworld/textures/gui/dungeon/crystal/`
`assets.json` เก็บขนาดส่งออกจริงและขอบ slice ต้นทาง `export-crystal-assets.ps1` สร้างผลส่งออกซ้ำได้ `crystal-assets-preview.png` แสดงไฟล์จริงบนพื้นตารางหมากรุก

- พื้นหลัง: สร้างฉากถ้ำแยก ไม่มี UI
- กรอบ: สร้างกรอบหิน/มรกตว่างแยกจากภาพอนุมัติ มุมที่วัด ขอบตรง พื้นผิว และแผ่นตราว่างแยกไฟล์
- แถวและปุ่ม: ตัดขอบจากภาพอ้างอิง ล้างด้านใน แถวปกติปรับขอบมรกตเลือกให้เป็นกลาง
- ประตู ดาว ดาบไขว้ กะโหลก หีบ สมาชิก นาฬิกา: ตัดภาพอ้างอิงและลบพื้นแผงมืดที่เชื่อมกับขอบ
- รางวัล: ช่องไอเทมมีกรอบอิสระ ItemStack และจำนวนจริงวาดตอนรันไทม์

ต้นฉบับกรอบว่างที่สร้าง: `exec-52bb76c0-0ff5-4c3d-8685-e8b6e2db727a.png`
ต้นฉบับฉากที่สร้าง: `exec-facb755f-9c8f-4d8d-8742-3002a58225d9.png`
ทั้งคู่ยังอยู่ในโฟลเดอร์ generated-images เดิมของ Codex ที่ตัวส่งออกบันทึก กรอบว่างเป็นแอสเซ็ตดัดแปลง ไม่ใช่ตัดจากกรอบอนุมัติแบบตรงทุกพิกเซล

## การเชื่อมระบบ

`DungeonCrystalSkin` คงมุมกรอบและใช้ nine-slice กับช่อง ไม่ยืดกรอบตกแต่งทั้งภาพ หลังรีวิวภาพในเกม ไม่วาดพื้นถ้ำแล้ว ใช้เอฟเฟกต์พื้นหลังโลกเดิมเท่านั้น
`frame.png` ที่ติดตั้งเป็น nine-slice มาตรฐาน 72x72 มุม 24 พิกเซล สร้างใหม่จากแถบหินล่างเดียวกัน โดยด้านบนสะท้อนแนวตั้ง แทนการตัดขอบแยกที่ไม่ตรงกัน ความลึกขอบและมุมต้นทางใช้จุดยึดเดียวกัน
ไอคอนส่งออกครั้งเดียวที่ 16x16 ด้วย nearest-neighbor และวาด 1:1 เปิด blending ชัดเจนเพื่อคงช่องโปร่งใส จำกัดความสูงแผ่นหัวข้อให้อยู่เหนือหัวรายละเอียด padding แนวนอนและระยะท้ายใช้หน่วย GUI คงที่ ไม่หดตามหน้าต่าง
เลย์เอาต์เล็กสุดใส่ชื่อบอสในทูลทิปเส้นทางเพื่อเว้นรางวัลและท้าย `DungeonBrowserScreen` คงข้อความ Minecraft เดิม ข้อมูลแค็ตตาล็อกเซิร์ฟเวอร์ การเลือกภาพ และขั้นตอนสร้างห้อง `NeoScrollbar` ร่วมจัดรายการแนวตั้งและรางวัลแนวนอน `NeoButton` ร่วมจัดอินพุต/เสียงคลิก
ภาพประตูแทนกุญแจกลาง/สัญลักษณ์ออกแดงที่ไม่เกี่ยว โดยไม่เปลี่ยนจออื่น จอเล็กยุบเส้นทางภาพเป็นบรรทัดเดียวเพื่อคงรางวัลและท้ายคงที่ สถานะชี้เป็นเส้นขอบนิ่ง การกระทำปิดใช้มีม่านด้านในโดยไม่ย้อมกรอบหิน

## การตรวจสอบ

คอมไพล์และรีเกรสชันดันเจี้ยนตรวจการเชื่อม ขนาด PNG ที่วัด และเมทาดาทาสุ่มตัวอย่าง ตรวจภาพรวมแอสเซ็ตที่ส่งออกแล้ว ยังไม่ยืนยันว่าตรงภาพในเกม ห้ามถือภาพรวมแอสเซ็ตเป็นสกรีนช็อตเกม
