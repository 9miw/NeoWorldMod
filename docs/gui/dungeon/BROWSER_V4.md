# เบราว์เซอร์ดันเจี้ยน V4

ภาพอนุมัติ: `browser-v4-approved.png` หน้าจอเลือกใช้ `textures/gui/dungeon/browser/` แทนการอ้างกรอบ/วิดเจ็ต/พรีวิวเก่าทั้งหมด เก็บกรอบเก่าไว้เพราะ `DungeonRoomScreen` ยังใช้ การเปลี่ยนนี้ไม่ได้ออกแบบหน้าจอนั้นใหม่

## องค์ประกอบ

- ภาพอ้างอิง 734x417 ปรับขนาดเฉพาะพิกัดภาพ ข้อความ ไอเทม และตัวควบคุมวาดด้วยหน่วย GUI Minecraft เดิม หน้าต่างกะทัดรัดใช้กรอบสูงขึ้นเพื่อเว้นข้อความ ช่อง และทูลทิป
- วิวพอร์ตรายการตามภาพ (24,83)..(212,373) แถวสูงขั้นต่ำ 44 หน่วยเดิม กรอบตัดและคลิกใช้พิกัดจอจริง
- `NeoScrollbar` ร่วมกว้าง 6 ตัวเลื่อนตามสัดส่วน รับล้อเมาส์/คลิกราง/ลาก
- รายละเอียดเริ่ม x=258 พรีวิวเล็ก (484,78) ขนาด 216x118
- ปุ่มเลือกตาม (526,365) ใช้อินพุต NeoButton เดิมและสกิน PNG เฉพาะ
- ไม่มีชิปกรองเลเวล/โหมดหรือพรีวิวกลางขนาดใหญ่
- อินพุตเมาส์และการตัดใช้พิกัดจอ ไม่สเกล pose stack ครอบเนื้อหาหรือเรียกการวาดพื้นหลังคลาสแม่
- วัดและตัดชื่อ/ค่า ชื่อดันเจี้ยนยาวมีทูลทิป
- ปุ่มขึ้น/ลงเปลี่ยนการเลือกและเลื่อนแถวที่เลือกให้เห็น

พรีวิวเหมืองเป็นภาพประกอบ ไม่ใช่ภาพ NBT ที่โหลด ซับไตเติลเป็น ID ดันเจี้ยนจริง ไอคอนสมาชิกใช้ฟอนต์บิตแมปร่วม

## พรีวิวรางวัล

เซิร์ฟเวอร์อ่าน Loot Table ที่โหลดด้วยคอนเท็กซ์ซีเรียลไลซ์รีจิสทรีครบ และไล่ชนิดไอเทมคงที่ แท็ก ตารางซ้อน และรายการลูก ไม่เรียกสุ่มลูต เงื่อนไข ฟังก์ชัน หรือมอดิไฟเออร์ ฟังก์ชันและชนิดรายการที่ไม่รู้จักทำให้ระบุพรีวิวเป็นค่าประมาณ จำนวนและคอมโพเนนต์อาจต่างจากรางวัลสุ่มจริง เครื่องหมายดอกจันอธิบายเมื่อชี้เมาส์

แต่ละดันเจี้ยนพรีวิวได้ไม่เกิน 64 ชนิดไม่ซ้ำ รวมไม่เกิน 1024 ไอเทมต่อแพ็กเก็ต จำกัดความลึกเรียกซ้ำและจำนวนโหนด ไอเทมซ้ำและการอ้างตารางเป็นวงจรไม่สร้างช่องซ้ำหรือวนไม่สิ้นสุด พรีวิวขาดหรือไม่รองรับอาจว่างได้โดยไม่ขัดขวางเข้าดันเจี้ยน

สแต็กพรีวิววาดบนช่อง Vanilla 18x18 ซ้ายไปขวา พร้อมทูลทิป ไม่มีเมนูคลังหรือการโอนไอเทม ใช้สกรอลล์บาร์ร่วม `Orientation.HORIZONTAL` ใต้แถวที่ล้น ล้อเมาส์บนแถวนั้นเลื่อนแนวนอน เปลี่ยนดันเจี้ยนแล้วรีเซ็ต ยอด EXP และ Silver ยังแยกต่างหาก รูปแบบแพ็กเก็ตต้องใช้ไคลเอนต์/เซิร์ฟเวอร์โปรโตคอล 18 ตรงกัน

## ส่งออก

`export-browser-v4.ps1` บันทึกกรอบต้นทางที่วัดของทุก PNG เฉพาะหน้าจอ สร้างภาพกรอบและตัวควบคุมว่างใหม่จากภาพอนุมัติเพื่อลบข้อความและข้อมูลไอเทม พรีวิว/เส้นแบ่ง/สกรอลล์บาร์ตัดตรงจากภาพอ้างอิง ไม่ฝังข้อความรันไทม์ใน PNG

```powershell
& docs/gui/dungeon/export-browser-v4.ps1 `
  -Mockup docs/gui/dungeon/browser-v4-approved.png `
  -Shell docs/gui/dungeon/browser-v4-shell-source.png `
  -Widgets docs/gui/dungeon/browser-v4-widgets-source.png
```

เท็กซ์เจอร์เฉพาะทั้งหมดมี blur=false/clamp=true ไม่วาด PNG สกรอลล์บาร์เฉพาะเก่าแล้ว ใช้แอตลาส Slim ร่วม ไม่เขียนทับไอคอนและปุ่มร่วมของหน้าจออื่น

การตรวจสอบ: `gradlew.bat compileJava dungeonBrowserRegressionTest` ผ่าน รีเกรสชันครอบคลุมไอเทมลูตตัวอย่าง ตารางซ้อน/แท็ก/วงจร ขีดจำกัดพรีวิว การเข้ารหัสและถอดรหัสแพ็กเก็ตพรีวิวว่าง ความยาวแพ็กเก็ตที่ปฏิเสธ และสกรอลล์บาร์สองทิศ JVM แยกเริ่มรีจิสทรีไอเทม NeoForge เต็มไม่ได้ จึงยังต้องตรวจแพ็กเก็ต ItemStack ไม่ว่างและการซีเรียลไลซ์ตารางรันไทม์ในเกม พร้อมภาพเทียบฟอนต์ไทยและ GUI Scale
