# ห้องรอดันเจี้ยน V2

ภาพอนุมัติ `waiting-room-v2-approved.png` แสดงมุมมองเจ้าของห้องสามคน หน้านี้ไม่เพิ่มเชิญปาร์ตี้ เตะ หรือจัดการปาร์ตี้

## แอสเซ็ตและเลย์เอาต์

ห้องรอใช้กรอบว่าง Create Room V2 ที่อนุมัติ 1448x1086 พร้อมแผ่นทีล/โคมไฟ ใช้ PNG เส้นแบ่ง/ปุ่มหลัก V5, NeoGuiIcons/NeoSystemIcons ร่วม, DungeonGuiIcons และตัววาดหน้าผู้เล่น/ช่องไอเทม Vanilla ไม่ฝังชื่อ สถานะ จำนวน หรือรางวัล ใช้พิกัด GUI เดิมแทนสเกล pose ทั้งหมดและสกรอลล์บาร์วาดเอง

ใช้กรอบ 4:3 ที่จำกัดและเรขาคณิตท้ายคงที่เดียวกับ Create Room V2 เนื้อหาเริ่มชื่อ/หมายเลขห้อง เมทาดาทา และพรีวิวที่ตั้งขนาดพอเหมาะ ตารางสมาชิกมีคอลัมน์ผู้เล่น/เลเวล/สถานะคงที่ หัวสกินออนไลน์จริง (สำรองค่าเริ่มต้น UUID ของ Vanilla) มงกุฎหัวหน้า และสถานะพร้อม/ออฟไลน์ชัดเจน สกรอลล์บาร์แนวตั้งร่วมรองรับหกคนในสามแถวที่เห็น
วิวพอร์ตรางวัลแยกใช้ไอเทม/จำนวน Vanilla และสกรอลล์บาร์ล้นแนวนอนร่วม จอเล็กเลื่อนเนื้อหานอกได้ ปุ่มท้ายอยู่นอกกรอบตัดทุกส่วน

เจ้าของเห็น Start และ Disband แบบไอคอนพร้อมทูลทิป/ยืนยัน Start ต้องเต็มความจุ สมาชิกออนไลน์/พร้อม และสถานะ WAITING สมาชิกเห็น Ready/Cancel Ready ไม่เห็น Start/Disband สมาชิกที่รอออกได้ ปิด X ไม่ออกห้อง เซิร์ฟเวอร์ยังตรวจทุกการกระทำ แฟล็กรอในเครื่องลดคลิกซ้ำจนได้คำตอบสถานะ การตอบเปิดห้องเดิมรีเฟรชแทนสร้างจอใหม่เพื่อคงตำแหน่งเลื่อน รองรับหน้าจอแม่ของป๊อปอัป

## เครือข่าย

DungeonRoomViewPayload มี DungeonBrowserDataPayload แบบรายการเดียวมีขีดจำกัด เพื่อส่งภาพที่ตั้งและพรีวิวรางวัลจริง แทนภาพเหมืองตายตัว ใช้ตัวสร้างพรีวิวและงบแพ็กเก็ต/ไอเทมเดิม เฉพาะนิยามเปิดใช้มีพรีวิว ถ้าขาดใช้ภาพสำรองปกติ ตัวตนสมาชิก เลเวล และความพร้อมยังมาจากเซิร์ฟเวอร์ รูปแบบข้อมูลเปลี่ยน ทั้งคู่ต้องใช้ม็อดตรงรุ่น โดยโปรโตคอลเพิ่ม 27 เป็น 28

## การตรวจสอบ

compileJava และ dungeonBrowserRegressionTest ครอบคลุม room codec ไปกลับ เมทาดาทาพรีวิวภาพ/รางวัล ขีดจำกัดพรีวิว สิทธิ์เริ่มเจ้าของ/สมาชิก คนขาด ออฟไลน์/ไม่พร้อม สถานะไม่รอ และช่วงเลื่อนหกคน/โซโล รวมการตรวจกรอบ/เรขาคณิตเดิม การถอดรหัส ItemStack ไม่ว่างบนเครือข่าย ภาพตรงในเกม การลาก พร้อม การเปลี่ยนไปหน้าโหลด และป๊อปอัปยังต้องทดสอบรันไทม์ที่หน้าต่าง 1280x720 และ GUI Scale ของผู้ใช้

โค้ดคอมไพล์แล้ว ยังไม่ได้ยืนยันว่าตรงม็อกอัปในเกม
