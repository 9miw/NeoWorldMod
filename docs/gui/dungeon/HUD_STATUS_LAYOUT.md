# HUD สถานะดันเจี้ยน

HUD แบบเรียบเดิมอยู่กลางขวา ซ่อนเมื่อนอกดันเจี้ยน เปิดหน้าจอ หลุดการเชื่อมต่อ หรือปิดการแสดง HUD ของ Minecraft

- แถวบน: ชื่อดันเจี้ยนตัดให้พอดีด้านซ้าย ป้ายเฟสด้านขวา
- แถวกลาง: เวฟและศัตรูเหลือพร้อมป้ายชัดเจน หรือชื่อบอสและ HP
- ความคืบหน้า: สัดส่วนเวฟที่จบ หรือ HP บอสปัจจุบันในเฟสบอส ไม่ใช่เปอร์เซ็นต์ฆ่ามอนสเตอร์ ซึ่งสแนปช็อตไม่มี
- ส่วนล่าง: เวลาเหลือและสมาชิกที่รอดพร้อมป้ายและไอคอนเดิม
- เมื่อสำเร็จชี้ไปยังรางวัล/ทางออก รันที่มีเฉพาะบอสไม่แสดง Wave 0/0

คงภาพแถบ Minimal เดิม ด้านในมืดสม่ำเสมอและมีเส้นแบ่งบาง พื้นที่เชิงตรรกะ 240x100 คงสเกล HUD 60% และปรับให้พอดีวิวพอร์ต (พื้นที่ปกติ 144x60 หน่วย GUI) คอลัมน์ข้อความมีความกว้างแยกและพิกัดจุดยึดจำนวนเต็ม ไม่เพิ่มเงิน/EXP หรือเปลี่ยนแพ็กเก็ต

`DungeonHudPresentation` สร้างป้ายจากสแนปช็อตเซิร์ฟเวอร์ มีรีเกรสชันเฟส บอส ไม่จำกัด/จับเวลา จำนวนผู้รอด และไม่มีเวฟ การคอมไพล์/ทดสอบไม่ยืนยันความตรงของภาพ ยังรอตรวจในเกม
