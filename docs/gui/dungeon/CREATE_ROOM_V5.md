# การจัดหน้าสร้างห้องให้ตรง V5

หน้าสร้างห้องใช้ `DungeonBrowserV5Skin` และแอสเซ็ตเบราว์เซอร์ V5 ปัจจุบันร่วมกัน ไม่เพิ่มกรอบหรือไอคอนที่สร้างใหม่

- แถบโคมไฟ/หัวข้อคงสัดส่วน ขอบเรียบยืดอิสระและมุมล่างคงสัดส่วน แทนยืด `create_room_v2_frame.png` เก่าทั้งสองแกน
- ปุ่ม X อยู่นอกกรอบขวา มีฮิตบ็อกซ์เต็ม 18x18 และป้ายไม่ถูกตัด ขอบวิวพอร์ตเว้นที่ไว้
- ภาพทางเข้าแทนกุญแจกลาง ปุ่มสร้างใช้ glyph ประตู/ลูกศรและปุ่มทีล nine-slice เดียวกับเบราว์เซอร์
- ขอบเนื้อหา ตำแหน่งหัวข้อ ระยะท้าย และสถานะปุ่มตรงกับเบราว์เซอร์ ข้อความและข้อมูลดันเจี้ยนเป็นไดนามิก
- รางวัลใช้ช่อง 18..24 หน่วยเดิม ภาพไอเทมอย่างน้อย 16 หน่วย คงเลื่อนรางวัลแนวนอนและเนื้อหาแนวตั้งในจอเล็ก
- `DungeonCreateRoomLayout.fitV5` กระทบเฉพาะหน้าสร้าง ห้องรอคง `fit` และภาพเดิม

คอมไพล์และรีเกรสชันครอบคลุมขอบวิวพอร์ต ตำแหน่งปุ่มปิด การแยกท้าย และขนาดรางวัล ยังไม่ได้ยืนยันภาพในเกม
