# เสียง PvP

ใช้แอสเซ็ตเสียง Vanilla ส่งเฉพาะผู้เล่นเกี่ยวข้องในหมวด Players วิดเจ็ต GUI เดิมคงเสียงคลิกปกติ

| เหตุการณ์ | เสียง |
| --- | --- |
| เข้าคิว | note_block.chime |
| ยกเลิกคิว | note_block.hat |
| พบคู่แข่ง ส่วนตัวและแรงก์ | note_block.bell สองครั้ง ห่างสี่ทิก |
| รับยืนยัน | note_block.pling |
| ยืนยันทั้งคู่ | player.levelup เบาและเสียงสูงขึ้น |
| ห้าวินาทีท้ายยืนยัน | note_block.hat เฉพาะคนยังไม่ยืนยัน |
| ยืนยันล้มเหลว / การกระทำ GUI ถูกปฏิเสธ | note_block.bass |
| นับก่อนต่อสู้ | note_block.hat ตรงอัปเดต Title |
| เริ่มต่อสู้ | note_block.pling สูงขึ้น |
| ชนะ / แพ้ยก | experience_orb.pickup / note_block.bass |
| ชนะ / แพ้แมตช์ | ui.toast.challenge_complete / note_block.didgeridoo |
| รับคำเชิญ | note_block.chime สองครั้ง ห่างสี่ทิก |

เสมอไม่มีเสียงชนะ/แพ้ รอคิวไม่มีเสียงแวดล้อมซ้ำ แพ็กเก็ตรีเฟรชข้อเสนอและค้นอันดับไม่เล่นเสียงแจ้ง คำขอยืนยันซ้ำไม่เล่นเสียงรับซ้ำ เสียงนับถอยหลังจำกัดหนึ่งครั้งต่อคนต่อทิกเซิร์ฟเวอร์ รวมอัปเดตครั้งแรก ล้างโน้ตหน่วงเมื่อหลุดและปิดเซิร์ฟเวอร์

คอมไพล์และรีเกรสชัน PvP เดิมผ่าน ยังต้องฟังระดับเสียง ลำดับ รีซอร์สแพ็กแทนเสียง และเสียงชนะ Vanilla ที่ยาวใน Minecraft
