# เครื่องมือจับภาพโครงสร้างดันเจี้ยน

ต้องมีสิทธิ์แอดมินดันเจี้ยนเดิม (ค่าเริ่มต้นคือ OP ระดับ 2) เครื่องมือเป็นแท่งไม้ Vanilla ที่มีตัวระบุใน custom data และชื่อเฉพาะ จึงไม่ต้องเพิ่มเท็กซ์เจอร์ไอเทมหรือลงทะเบียนไอเทมใหม่ฝั่งไคลเอนต์

## ขั้นตอนใช้งาน

บันทึกแมปแยกได้โดยยังไม่ต้องมีนิยามดันเจี้ยน:

```mcfunction
/neoworld dungeon admin structure tool
```

ถือไอเทมชื่อ Dungeon Capture Tool คลิกซ้ายที่บล็อกเพื่อเลือกมุมที่ 1 และคลิกขวาเพื่อเลือกมุมที่ 2 โดยรวมบล็อกทั้งสองมุม เครื่องมือจะยกเลิกการโต้ตอบและการทุบบล็อกตามปกติขณะเลือก ต้องเลือกภายในมิติเดียวกัน หากเปลี่ยนมิติแล้วเลือกมุมใหม่ ระบบจะเริ่มการเลือกใหม่ในมิตินั้น

```mcfunction
/neoworld dungeon admin structure selection
/neoworld dungeon admin structure save forgotten_mine
```

`selection` แสดงมุมทั้งสอง ปริมาตร และจำนวนชิ้นโดยประมาณ ส่วน `save` แบ่งพื้นที่ทรงสี่เหลี่ยมที่เลือกเป็นชิ้นไม่ทับกัน ขนาดไม่เกิน 48x48x48 บันทึกเป็น `neoworld:dungeon/forgotten_mine_01`, `_02` เป็นต้น แล้วเก็บออฟเซ็ตสัมพัทธ์ของแมปแยกต่างหาก โดยไม่สร้างหรือแก้ไขดันเจี้ยน ไม่ต้องวาง Structure Block หรือใช้คำสั่ง scan เอง จุดกำเนิดเลย์เอาต์ใช้พิกัดต่ำสุดของแต่ละแกน ไม่ขึ้นกับลำดับการเลือกมุม

เมื่อเสร็จแล้ว ให้สร้างและตั้งค่าดันเจี้ยน จากนั้นเชื่อมแมปทั้งหมดด้วยชื่อ:

```mcfunction
/neoworld dungeon admin create dung01
/neoworld dungeon admin set dung01 structure forgotten_mine
/neoworld dungeon admin validate dung01
/neoworld dungeon admin enable dung01
```

การส่งออกเก็บบล็อก อากาศ NBT ของ block entity และมาร์กเกอร์ DATA แต่ไม่เก็บเอนทิตี วางมาร์กเกอร์ปกติ ได้แก่ player_spawn, boss_spawn, reward_chest, exit และ mob_spawn_N ภายในพื้นที่เลือก คำสั่งตรวจสอบเดิมจะแจ้งมาร์กเกอร์ที่ขาด ห้ามแก้พื้นที่ต้นทางระหว่างจับภาพ เพราะแต่ละชิ้นถูกอ่านคนละทิก ไม่ใช่สแนปช็อตพร้อมกันทันที

## คำสั่งเพิ่มเติม

```mcfunction
/neoworld dungeon admin structure pos1
/neoworld dungeon admin structure pos2
/neoworld dungeon admin structure cancel
```

`pos1`/`pos2` เลือกพิกัดบล็อกที่ผู้เล่นอยู่ เหมาะสำหรับเลือกอากาศ `cancel` ล้างมุมทั้งสองและยกเลิกงานจับภาพที่รออยู่ของผู้เล่นนั้น ชื่ออาจระบุพรีฟิกซ์รีซอร์สเต็ม เช่น `othermod:dungeon/forgotten_mine` โดยไม่ใส่ `_01` หรือ `.nbt`

## แสดงรายการ อัปเดต และลบ

```mcfunction
/neoworld dungeon admin structure list
/neoworld dungeon admin structure update silme_map
/neoworld dungeon admin structure update neoworld:dungeon/silme_map
/neoworld dungeon admin structure delete neoworld:dungeon/silme_map
```

ชื่อสั้นอ้างอิงใต้ `neoworld:dungeon/` คำสั่ง save, update, delete และการเชื่อมดันเจี้ยนรองรับเนมสเปซที่ระบุชัดเจน รายการแสดงชื่อเต็ม จำนวนไฟล์ ID ดันเจี้ยนที่เชื่อม และปุ่มคำสั่งในแชต การอัปเดตใช้มุมที่เลือกอยู่

การอัปเดตเขียนไฟล์รีวิชันใหม่โดยไม่ทับเทมเพลตเดิม เมื่อทุกชิ้นสำเร็จ แมปและเลย์เอาต์ดันเจี้ยนที่เชื่อมครบทั้งชุดจะเปลี่ยนพร้อมกัน และดันเจี้ยนเหล่านั้นกลับเป็น DRAFT เลย์เอาต์เก่ายังคงอยู่ในแค็ตตาล็อกด้วยชื่อ `<map>/backup_<id>` ที่ไม่ซ้ำ พร้อมไฟล์ NBT เดิม สามารถเชื่อมชื่อแบ็กอัปเพื่อคืนเลย์เอาต์ก่อนหน้าได้ ระบบปฏิเสธการอัปเดตถ้าดันเจี้ยนที่เชื่อมมีอินสแตนซ์ใช้งาน และตรวจซ้ำตอนคอมมิต ผู้ใช้เลย์เอาต์เพียงบางส่วนต้องเชื่อมใหม่ก่อน

การลบจะขอยืนยันแบบใช้ครั้งเดียว ผูกกับผู้เล่น และหมดอายุใน 30 วินาที (600 ทิกเซิร์ฟเวอร์) ตอนยืนยันจะตรวจสิทธิ์ เลย์เอาต์ปัจจุบัน ดันเจี้ยนที่เชื่อม ไฟล์แมปที่ใช้ร่วมกัน และงานบันทึกที่รออยู่อีกครั้ง แมปที่ยังเชื่อมอยู่ลบไม่ได้ ลบได้เฉพาะไฟล์ NBT ที่สร้างขึ้น ไม่รวมรีซอร์สที่แพ็กมากับม็อดหรือดาต้าแพ็ก

เมื่อยืนยัน ระบบย้ายไฟล์ที่สร้างทั้งหมดไปยัง `dungeon_structure_backups/<id>/` ในเซฟโลก ก่อนลบรายการแค็ตตาล็อกและล้างแคชเทมเพลต หากย้ายไฟล์ได้เพียงบางส่วนจะพยายามย้อนกลับ เก็บไฟล์แบ็กอัปไว้กู้คืนด้วยตนเอง จึงไม่ใช่การลบถาวร ตัวช่วยปฏิเสธพาธที่อยู่นอกไดเรกทอรี generated จริงและไฟล์ symlink

แค็ตตาล็อกใช้การบันทึก SavedData ตามปกติ เช่นเดียวกับข้อมูลโลกอื่น หากโปรเซสหยุดกะทันหันก่อนเซฟโลก จะไม่รับประกันธุรกรรมแบบอะตอมมิกร่วมกับการเขียนหรือย้ายไฟล์ ควรสำรองโลกไว้ และใช้แบ็กอัปรีวิชันหรือแบ็กอัปจากการลบเพื่อกู้คืนเมื่อเกิดเหตุ

## ที่เก็บข้อมูลและข้อจำกัด

ไฟล์ใหม่บันทึกผ่าน StructureTemplateManager ของ Minecraft ใต้ `generated/<namespace>/structures/<prefix>_01.nbt` ของเซฟเซิร์ฟเวอร์ ตัวอย่างค่าเริ่มต้นคือ `generated/neoworld/structures/dungeon/forgotten_mine_01.nbt`
แค็ตตาล็อกแมปและออฟเซ็ตเก็บใน SavedData ดันเจี้ยนเดิมของ Overworld (`neoworld_dungeons.dat` ฟิลด์เสริม `maps`) จึงคงอยู่หลังรีสตาร์ตแม้ไม่มีนิยามดันเจี้ยน การเชื่อมแมปทำให้ดันเจี้ยนเป้าหมายกลับเป็น DRAFT ส่วน ID รีซอร์สแบบเต็มยังรองรับเทมเพลต NBT เดี่ยวที่มีอยู่ บล็อกต้นทางไม่เปลี่ยนแปลง

- คิวเครื่องมือนี้จับภาพและเขียนหนึ่งชิ้นต่อทิกเซิร์ฟเวอร์ ช่วยกระจายงาน แต่ชิ้นที่หนาแน่นหรือที่เก็บข้อมูลช้าอาจทำให้ทิกนานขึ้น
- ชังก์ที่เลือกทั้งหมดต้องโหลดอยู่แล้ว เครื่องมือไม่บังคับสร้างชังก์ใหม่ อยู่ใกล้พื้นที่จนเสร็จ หากชังก์ที่จำเป็นถูกยกเลิกการโหลด งานจะยุติ
- จำกัด 8,388,608 บล็อก และ 512 ชิ้นต่องาน ความกว้างแกน X ต้องพอดีกับระยะห่างอินสแตนซ์ปัจจุบัน ความสูงต้องอยู่ในมิติดันเจี้ยนเมื่อวางจากจุดกำเนิด Y=64
- ปฏิเสธไฟล์ generated ที่มีอยู่ เทมเพลตที่แพ็กมา และชื่อสงวน ใช้พรีฟิกซ์ใหม่เมื่อต้องการส่งออกอีกชุด ไม่มีการเขียนทับโดยปริยาย
- ดันเจี้ยนที่มีอินสแตนซ์ใช้งานเชื่อมใหม่ไม่ได้ การบันทึกแมปอิสระใหม่ไม่กระทบดันเจี้ยนที่กำลังทำงาน และเลย์เอาต์เก่าที่เชื่อมไว้ไม่เปลี่ยน
- การยกเลิก หลุดการเชื่อมต่อ ถูกถอนสิทธิ์ หรือปิดเซิร์ฟเวอร์ตามปกติ จะยุติงานที่ไม่เสร็จและลบเฉพาะไฟล์ใหม่ที่งานนั้นพยายามสร้าง หากล้างไม่สำเร็จจะบันทึกล็อก โปรเซสแครชอาจทิ้งไฟล์ไม่ครบ ให้ใช้พรีฟิกซ์ใหม่หรือตรวจไฟล์ก่อนลบเอง
- การเลือกพื้นที่และงานเป็นข้อมูลชั่วคราว ไม่คงอยู่หลังออกจากเกมหรือรีสตาร์ตเซิร์ฟเวอร์

## การตรวจสอบ

```powershell
.\gradlew.bat compileJava dungeonCaptureRegressionTest dungeonOverlapRegressionTest
```

การทดสอบแบ่งชิ้นครอบคลุมขอบเขตแบบรวมปลาย ขอบขนาด 48 บล็อกพอดี มุมสลับลำดับ ออฟเซ็ตสัมพัทธ์ ชื่อไม่ซ้ำ การครอบคลุมปริมาตรโดยไม่ทับกัน ชิ้นสุดท้ายที่ไม่เต็ม และการปฏิเสธขนาดหรือพาธ การทดสอบเหล่านี้และการทดสอบพื้นที่ทับซ้อนเดิมผ่านแล้ว
การทดสอบจับภาพยังครอบคลุมกลุ่มคำสั่งแอดมิน รูปแบบ save การเก็บแมปอิสระโดยไม่มีนิยาม การปฏิเสธชื่อซ้ำ และการเชื่อมหลายชิ้นแบบระบุชัดเจน ยังไม่ได้ทดสอบการคลิกเครื่องมือ การเขียน NBT จริง การล้างงานที่ยกเลิก และวงจรส่งออก / ตรวจสอบ / เริ่มดันเจี้ยนครบชุดบนเซิร์ฟเวอร์ที่ทำงานจริง
