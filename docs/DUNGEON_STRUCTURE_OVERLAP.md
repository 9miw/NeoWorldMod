# ขอบเขตโครงสร้างดันเจี้ยนที่ทับซ้อนกัน

พื้นที่บันทึกของ Structure Block ทับกันได้ บันทึกชิ้นเป็น `_01`, `_02` ต่อไป แล้วสแกนตำแหน่งสัมพัทธ์ด้วยคำสั่ง structure scan เดิม ไม่ต้องตั้งค่าใหม่

## กฎตรวจสอบก่อนวาง

- ตำแหน่งเดียวกัน มีสถานะ/พร็อพเพอร์ตีบล็อกและ NBT ของ block entity เท่ากัน: วางครั้งเดียว
- อากาศกับบล็อกทึบตำแหน่งเดียวกัน: เก็บบล็อกทึบ ไม่ว่าลำดับใด
- อากาศสองชนิด: ล้างช่องครั้งเดียว อากาศนอกพื้นที่ทับซ้อนยังวางตามปกติ กฎนี้ไม่ใช่ตัวเลือกละอากาศทั่วทั้งแมป
- บล็อกทึบที่มีสถานะ พร็อพเพอร์ตี หรือ NBT ต่างกัน: ปฏิเสธก่อนวาง ข้อผิดพลาดระบุ ID เทมเพลตทั้งคู่และพิกัดบล็อกเป้าหมายแบบสัมบูรณ์
- มาร์กเกอร์ DATA ชื่อเดียวกันในตำแหน่งเดียวกัน: นับครั้งเดียว แต่ชื่อเดียวกันคนละตำแหน่งยังเป็นจุดเกิด/ออกหลายจุด
- ชื่อ DATA ต่างกันในตำแหน่งเดียวกัน: ปฏิเสธก่อนวาง
- บล็อกทึบตรงมาร์กเกอร์ DATA: ปฏิเสธเพื่อไม่ให้กีดขวางจุดเกิด/ออก
- ไม่วางบล็อกควบคุมโครงสร้างและ Structure Void ไม่เปรียบเทียบฟิลด์ x/y/z ของ block entity ใน NBT แต่ยังเปรียบเทียบคลัง ข้อความป้าย การตั้งค่าลูต และข้อมูลสำคัญอื่น

เก็บข้อมูลเจ้าของช่องเฉพาะบริเวณขอบเขตชิ้นที่ทับกัน ช่องอื่นวางเทมเพลตตามปกติ โหลดเทมเพลตและหามาร์กเกอร์ก่อนเขียนโลก การตรวจสอบใช้กฎวางแผนเดียวกับการวาง ล็อกตัวเลือก palette ให้คงที่ต่อเทมเพลต/ออฟเซ็ตสัมพัทธ์ตลอดการเก็บมาร์กเกอร์ ตรวจสอบ และวาง รวมเทมเพลตที่มีหลาย palette

การตรวจสอบนี้ป้องกันความขัดแย้งของเทมเพลตที่ทำให้สร้างได้บางส่วน แต่ไม่ใช่การย้อนธุรกรรมสำหรับข้อผิดพลาดรันไทม์หรือการเขียนโลกอื่น การวางยังใช้กระบวนการเทมเพลต Minecraft สำหรับ block entity และอัปเดตบล็อกข้างเคียง การลบแบบทยอยเดิมยังล้างขอบเขตทุกชิ้นที่บันทึก

## การตรวจสอบและทดสอบ

```mcfunction
/neoworld dungeon validate dung01
/neoworld dungeon build dung01 0
```

รันการตรวจสอบระหว่างพัฒนาด้วย:

```powershell
.\gradlew.bat compileJava dungeonOverlapRegressionTest
```

รีเกรสชันครอบคลุมบล็อกซ้ำ ลำดับอากาศ/ทึบทั้งสองแบบ พร็อพเพอร์ตีและ NBT ขัดกัน การสำเนา NBT ป้องกันการแก้ต้นฉบับ การรวมมาร์กเกอร์ซ้ำ และมาร์กเกอร์ขัดกัน ยังไม่ได้ทดสอบวางจริงในโลกหรือหลายผู้เล่น ให้ใช้สล็อตทดสอบ บันทึกสองชิ้นที่ใช้ผนังและมาร์กเกอร์ร่วมกัน ตรวจว่าคงผนัง/มาร์กเกอร์เพียงหนึ่งชุด จากนั้นแก้บล็อกร่วมในชิ้นหนึ่ง แล้วตรวจว่าการตรวจสอบปฏิเสธเลย์เอาต์โดยไม่แก้โลก ใช้สล็อตที่ยังว่างสำหรับทดสอบสร้าง
