# ชุดข้อมูล NPC โซนนักผจญภัย

วันที่ 2026-10-25 · สถานะ: เตรียมข้อมูล ยังไม่ติดตั้งเซิร์ฟเวอร์

ขอบเขตที่ยืนยัน: เพิ่ม NPC ใหม่ชื่อ **เซริน** ตำแหน่ง **เจ้าหน้าที่กิลด์นักผจญภัย** ลงชุดข้อมูล ทำหน้าที่รับสมัคร อธิบายกฎ และแนะนำลำดับเควสต์ การสร้างระบบสมาชิกหรือระดับกิลด์ยังไม่อยู่ในงานนี้

## รายการประจำโซน

| NPC | หน้าที่ | สถานะ |
|---|---|---|
| เซริน | เจ้าหน้าที่กิลด์นักผจญภัย | รายการสร้างใหม่ ยังไม่มี UUID หรือพิกัดติดตั้ง |
| Kocimira | เควสต์หลัก | ตัวเดิม UUID `d781a6af-921e-48b4-be21-346ee190f0ea` ยังไม่มีเควสต์หลัก |
| นาริน | เควสต์ประจำวัน | ตัวเดิม UUID `c8483996-230c-432d-b7cd-e0f303180268` มีเควสต์1–4แล้ว |
| ลีโอ | ผู้ดูแลดันเจี้ยน | ตัวเดิม UUID `506815a0-f23b-47f0-bf33-b8febea6fe9f` ยังไม่ผูกบริการ |
| ทหารรักษาโถงนักผจญภัย | ลาดตระเวนและรักษาพื้นที่ | ตัวเดิม UUID `231dd439-dfe2-4f94-af8c-6cc740b2ec94` มีเส้นทางPatherแล้ว |

ตัวเดิมเป็นข้อมูลอ้างอิงเท่านั้น ชุดนี้ยังไม่แก้ชื่อ บทสนทนา เควสต์ หรือเส้นทางของตัวเดิม

## ข้อมูลเซริน

| รายการ | ค่า |
|---|---|
| ชื่อในเกม | เซริน |
| Title | เจ้าหน้าที่กิลด์นักผจญภัย |
| โซน | โถงนักผจญภัย |
| จุดประจำ | จุดต้อนรับใกล้ทางเข้า ต้องตรวจพื้นที่จริงก่อนกำหนดพิกัด |
| UUID | สร้างและบันทึกเมื่อสร้างตัวจริง ห้ามใช้ UUID ของตัวเดิม |
| Dialog ID / Quest ID | ยังไม่จัดสรร ต้องตรวจ ID ล่าสุดก่อนทำไฟล์ติดตั้ง |
| การเดิน | เสนอให้ยืนประจำจุดต้อนรับ ไม่ขวางทางเดินหรือเส้นทางทหาร |
| เงินและไอเทม | ยังไม่มีค่าใช้จ่าย รางวัล หรือคำสั่งเงินในชุดนี้ |

## ร่างบทสนทนา

ข้อความต้อนรับ: “ยินดีต้อนรับสู่โถงนักผจญภัย @p! ข้าชื่อเซริน เป็นเจ้าหน้าที่กิลด์ หากเพิ่งรับเสบียงจากอัลเลย์มา ข้าจะช่วยแนะนำขั้นตอนต่อไปให้เจ้า”

| ตัวเลือก | เนื้อหา/การเชื่อมที่เตรียมไว้ |
|---|---|
| ข้าต้องการสมัครนักผจญภัย | `serin.join` |
| มีคำแนะนำสำหรับมือใหม่ไหม? | `serin.advice` |
| ข้าควรเริ่มงานจากใคร? | `serin.first_work` |
| ใครดูแลงานแต่ละประเภท? | `serin.services` |
| ข้าแค่อยากพูดคุย | `serin.chat` |
| ไว้ข้าจะมาใหม่ | `serin.goodbye` |

คำตอบแต่ละหัวข้อเตรียมให้กลับเมนูหลักหรือปิดบทสนทนาได้ ยังเป็นร่างเนื้อหา ไม่ใช่ไฟล์NBTที่ม็อดโหลด

## บทสนทนาฉบับพร้อมใช้เป็นเนื้อหา

ผู้ใช้สั่งสร้างบทสนทนาพูดคุยและส่งข้อมูลให้แอนนาเมื่อ2026-10-25 รหัสด้านล่างเป็นชื่ออ้างอิงภายในชุดข้อมูล ไม่ใช่Dialog IDตัวเลขที่จองบนเซิร์ฟเวอร์ เมนูหลักมี6ตัวเลือกตามตาราง ไม่ให้เงิน ไอเทม สมาชิก หรือปลดล็อกเควสต์จากการอ่าน

### serin.join — ข้าต้องการสมัครนักผจญภัย

“ยินดีเลย @p! ข้าดูแลเรื่องต้อนรับและการสมัครของกิลด์ แต่ตอนนี้ยังไม่เปิดลงทะเบียนสมาชิก ระหว่างนี้เจ้ามาถามทางและเตรียมตัวกับข้าได้ หากยังไม่ได้รับเสบียง ให้กลับไปพบเอลริคที่ลานเกิดก่อน แล้วคุยกับอัลเลย์เพื่อรับชุดเริ่มต้น”

### serin.advice — มีคำแนะนำสำหรับมือใหม่ไหม?

“ก่อนออกเดินทาง ลองตรวจอาหาร อาวุธ และช่องว่างในกระเป๋าให้พร้อม อ่านจำนวนและชนิดของที่งานต้องการให้ครบ แล้วจำชื่อคนที่เจ้าต้องกลับมาส่งงานไว้ด้วย ถ้าศัตรูเกินกำลัง การถอยกลับมาเตรียมตัวใหม่ก็เป็นเรื่องปกติ นักผจญภัยที่กลับถึงเมืองย่อมมีโอกาสออกเดินทางอีกครั้ง”

### serin.first_work — ข้าควรเริ่มงานจากใคร?

“ถ้าเพิ่งเข้าเมือง เริ่มจากเอลริค แล้วไปรับเสบียงกับอัลเลย์ก่อน เมื่อพร้อมแล้วเจ้ามาถึงโถงถูกที่แล้ว! นารินมีงานประจำวันให้ทำ ส่วนงานเนื้อเรื่องของ Kocimira ยังอยู่ระหว่างเตรียมการ ข้ายังไม่มีภารกิจหลักให้รับแทนเขา”

### serin.services — ใครดูแลงานแต่ละประเภท?

“นารินดูแลงานประจำวัน ทำครบชุดจะได้เหรียญ Silver หนึ่งชิ้นมูลค่า100 และรับชุดใหม่ได้หลังส่งงานสุดท้ายครบ24ชั่วโมง Kocimiraรับผิดชอบงานหลักของเมือง ส่วนลีโอดูแลเรื่องดันเจี้ยน แต่สองบริการหลังยังไม่เปิด หากต้องการซื้อของให้ไปย่านตลาด หรือไปหาอีเทอร์ที่ย่านช่าง”

### serin.chat — ข้าแค่อยากพูดคุย

“ได้สิ! วันหนึ่งข้าได้ยินทั้งเรื่องคนลืมเสบียง คนหลงทาง และคนที่กลับมาเล่าเรื่องการเดินทางครั้งแรก บางคนออกไปด้วยท่าทางมั่นใจ แต่กลับมาถามหาขนมปังก่อนอย่างอื่นเสียอีก แล้วเจ้าล่ะ @p วันนี้อยากเดินชมเมือง หรือเตรียมตัวออกผจญภัย?”

ตัวเลือกย่อย: “ข้าอยากชมเมือง” → `serin.city`, “ข้าอยากออกผจญภัย” → `serin.ready`, “กลับไปถามเรื่องอื่น” → เมนูหลัก, “ไว้คุยกันใหม่” → `serin.goodbye`

### serin.city — ข้าอยากชมเมือง

“ลองแวะตลาดก่อนก็ได้ เจ้าจะได้จำทางซื้อของไว้ แล้วค่อยเดินขึ้นไปชมปราสาท ถ้าชอบมุมสงบก็มีหอสมุดเวท แต่บริการบางแห่งยังเตรียมไม่เสร็จ หากจำทางกลับไม่ได้ ให้ดูพิกัดลานเกิดประมาณ X160 Y98 Z310 ไว้เป็นหลัก”

### serin.ready — ข้าอยากออกผจญภัย

“เช่นนั้นตรวจอาหารกับอาวุธอีกครั้ง แล้วลองถามงานจากนารินดู งานส่งของและงานล่าต้องทำตามลำดับ อ่านเป้าหมายของขั้นที่รับอยู่ก่อนออกไปด้วยนะ ข้าจะรอฟังเรื่องเล่าตอนเจ้ากลับมา”

### serin.goodbye — ไว้ข้าจะมาใหม่

“เดินทางปลอดภัยนะ @p! ถ้าต้องการคำแนะนำ แวะมาหาข้าที่จุดต้อนรับได้เสมอ”

ทุกคำตอบยกเว้นบทพูดคุยย่อยและคำลามีตัวเลือก “กลับเมนูหลัก” และ “ไว้ข้าจะมาใหม่” คำลาแสดงข้อความแล้วให้ปิดบทสนทนาได้ การสมัครเป็นข้อความแจ้งสถานะเท่านั้น ไม่ส่งคำสั่งลงทะเบียน

## ก่อนจัดทำไฟล์ติดตั้ง

- ตรวจพิกัดทางเข้าและจุดว่าง กำหนดรูปลักษณ์และทิศหัน โดยไม่ย้ายตัวเดิม
- กำหนดขอบเขตการสมัคร: เป็นบทสนทนา/เควสต์ครั้งเดียว หรือระบบสมาชิกที่มีข้อมูลจัดเก็บจริง ห้ามเพิ่มระบบสมาชิกหรือโค้ดโดยอาศัยการยืนยันชื่อNPCเพียงอย่างเดียว
- ตรวจและจัดสรรDialog/Quest IDล่าสุด รวมทั้งกำหนดเงื่อนไข รางวัล และลำดับงานที่ได้รับอนุมัติ
- เมื่ออนุมัติติดตั้งแล้ว สำรองข้อมูล สร้างเซรินเพียง1ตัว ผูกข้อมูล และตรวจ UUID/การอ้างอิง อัปเดตทะเบียนจริงภายหลัง

ตรวจชุดข้อมูลแล้ว: เซรินไม่ซ้ำชื่อในทะเบียนที่อ่าน และตัวเดิมทั้ง4ระบุ UUID แยกชัดเจน จำนวนNPCจริงยัง25ตัว ไม่มีการเชื่อมต่อหรือแก้ข้อมูลเซิร์ฟเวอร์จากการเตรียมเอกสารนี้

## การส่งข้อมูลให้แอนนา

ส่งบทสนทนาเซรินฉบับเต็ม พร้อมทะเบียนNPC25ตัว สถานะSpawn/เควสต์นาริน เส้นทางทหาร งานที่ลบแล้ว งานค้าง และนโยบายSilver ผ่านทักษะannaไปยังโปรเจคNeoWorldMod บทสนทนา “Greeting and Hello” เมื่อ2026-10-25 ตรวจพบข้อความเป็นUser messageแล้ว แอนนาแสดงสถานะWorkingขณะตรวจการส่ง ยังไม่ถือว่าแอนนาอัปเดตข้อมูลเสร็จหรือมีการติดตั้งเซริน

ขอบเขตข้อความที่ส่ง: อัปเดตข้อมูลอ้างอิงเท่านั้น ไม่อนุมัติแก้โค้ด สร้างNPC หรือติดตั้งเซิร์ฟเวอร์เพิ่มเติม แจ้งด้วยว่าพาธในเครื่องผู้ใช้ไม่ใช่หลักฐานว่าremoteของแอนนาอ่านไฟล์ได้
