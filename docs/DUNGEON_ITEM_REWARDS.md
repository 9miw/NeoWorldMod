# รางวัลดันเจี้ยนแบบไอเทมเท่านั้น

```mcfunction
/neoworld dungeon admin set silme reward neoworld:chests/dungeon/test_reward
/neoworld dungeon admin validate silme
/neoworld dungeon admin enable silme
```

เมื่อจบดันเจี้ยนจะเตรียมเฉพาะหีบรางวัลเดิม ไม่เพิ่ม EXP ผู้เล่นหรือฝากเงิน การสุ่ม Loot Table ส่วนตัว เงื่อนไขผู้มีสิทธิ์รับ และการจัดการคลังหีบยังเหมือนเดิม ใน Loot Table ยังใส่เหรียญหรือไอเทม EXP แบบใช้แล้วหมดได้ โดยพฤติกรรมปกติของไอเทมเหล่านั้นไม่เปลี่ยน

DungeonRewardConfig มีเฉพาะ lootTableId แล้ว SavedData จะละฟิลด์ experience/money แบบเก่าเมื่อโหลด และไม่เขียนในการบันทึกครั้งถัดไป ลิงก์ Loot Table เดิมยังอยู่ แต่นิยามเก่าไม่สามารถมอบจำนวน EXP หรือเงินที่เคยบันทึกไว้ คำสั่งรางวัลและข้อมูลหรือวิธีใช้ในแชตไม่รับหรือแสดงจำนวนเหล่านั้นอีก

แพ็กเก็ตเบราว์เซอร์คงฟิลด์ตัวเลขเก่าสองช่องไว้ โดยเซิร์ฟเวอร์ส่งศูนย์เสมอ เพื่อเลี่ยงการเปลี่ยนรูปแบบข้อมูลที่ไม่เกี่ยวข้อง เบราว์เซอร์ไม่แสดงฟิลด์เหล่านี้

การตรวจสอบ: compileJava และ dungeonBrowserRegressionTest ครอบคลุมการย้าย NBT เก่า การคง Loot Table และโครงสร้างคำสั่งที่มีเฉพาะไอเทม ยังไม่ได้ทดสอบการจบดันเจี้ยนและรับรางวัลจากหีบซ้ำในเกม
