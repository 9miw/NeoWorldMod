# การเตรียมชุดข้อมูล NPC ก่อนติดตั้ง

ผู้ใช้ยืนยันแนวทางนี้เมื่อ 2026-10-25 เพื่อประหยัดการอ่านข้อมูลซ้ำและลดการแก้เซิร์ฟเวอร์ทีละรายการ

## ลำดับงาน

1. อ่านทะเบียน `docs/NPCS.md` เฉพาะส่วนที่เกี่ยวข้อง และอ่าน `maps/starter_sky_land_spawn_v1/MAP.md` ก่อนงานในแมพ
2. เตรียมชุดข้อมูลในเครื่องก่อน โดยรวมงานตามโซนหรือชุดเควสต์ ไม่สร้าง NPC หรือแก้เซิร์ฟเวอร์ระหว่างร่าง
3. ตรวจชุดข้อมูลทั้งหมดพร้อมกัน แล้วสรุปส่วนที่เปลี่ยนให้ผู้ใช้ตรวจ หากขอบเขตยังไม่ได้รับอนุมัติให้รอการยืนยันก่อนติดตั้ง หากอนุมัติไว้แล้วให้ดำเนินการภายในขอบเขตนั้น
4. ก่อนติดตั้ง ตรวจข้อมูลจริงและ ID ที่ถูกใช้ล่าสุดเพียงรอบเดียว ป้องกันชนกับงานอื่น แล้วสำรองข้อมูลที่ได้รับผลกระทบ
5. ติดตั้งเฉพาะรายการเปลี่ยนแปลงเป็นชุด โหลดข้อมูลใหม่ และตรวจผลที่บันทึก ไม่เขียนทับข้อมูลนอกขอบเขตด้วยสำเนาเก่า
6. อัปเดตทะเบียน NPC และประวัติแมพ พร้อมผลตรวจและตำแหน่งสำรอง

## ข้อมูลที่แต่ละชุดต้องมี

| ส่วน | รายละเอียด |
|---|---|
| ขอบเขต | ชื่อชุด โซน สถานะร่าง/อนุมัติ/ติดตั้ง และสิ่งที่ผู้ใช้อนุมัติ |
| NPC | UUID เดิมหรือรายการสร้างใหม่ ชื่อ หน้าที่ พิกัด และเฉพาะค่าที่ต้องเปลี่ยน |
| บทสนทนา | ID ชื่อ ข้อความ ตัวเลือก ปลายทาง และเงื่อนไขแสดง |
| เควสต์ | ID ผู้เริ่ม ผู้รับส่ง เป้าหมาย จำนวน ลำดับขั้น เงื่อนไขรับซ้ำ และรอบเวลา |
| รางวัล | Item ID จำนวน และ Data Components รวมถึงการหักของจากผู้เล่น |
| การเชื่อม | NPC → Dialog → Quest → ขั้นถัดไป และบริการเดิมที่ต้องคงไว้ |
| แผนติดตั้ง | รายชื่อไฟล์และ NPC ที่แก้ ลำดับโหลด สำรอง และวิธีคืนเฉพาะส่วน |
| ผลตรวจ | การอ้างอิง ID รูปแบบ NBT รางวัล เงื่อนไข และขอบเขตข้อมูลที่เปลี่ยน |

ใช้ตาราง Markdown สำหรับตรวจเนื้อหา และไฟล์ข้อมูล CustomNPCs สำหรับติดตั้งจริงเมื่อมีงานชุดนั้น ไม่สร้างสคริปต์หรือเครื่องมือนำเข้าใหม่โดยไม่มีความจำเป็นและการอนุมัติโค้ด

## กติกาข้อมูล

- ใช้ UUID ระบุ NPC เดิม ไม่สร้างซ้ำจากชื่อ และรักษาโลก `maps/starter_sky_land_spawn_v1` เดิม
- ID ที่ร่างไว้ต้องตรวจซ้ำกับเซิร์ฟเวอร์ก่อนติดตั้ง ตรวจว่าเป้าหมายบทสนทนา เควสต์ และรายการไอเทมมีอยู่จริง
- ไฟล์ CustomNPCs เป็น NBT text ไม่ใช่ JSON มาตรฐานทั้งหมด รักษาชนิดตัวเลข เช่น long ลงท้าย `L` และตรวจรูปแบบข้อความ ไม่ใช้การแปลง JSON ที่ทำชนิดข้อมูลสูญหาย
- เงินสำหรับงานใหม่ใช้ Silver ตามนโยบายปัจจุบัน Gold ถูกนำออกจากระบบใช้งาน เก็บยอดเดิมไว้เฉพาะข้อมูลเก่า ไม่แปลงเงิน ไม่เดาอัตราแลกเปลี่ยน และไม่เปลี่ยนราคาเอง Diamond ยังใช้ตามเดิม
- เหรียญที่รวมมูลค่าไว้ในไอเทมต้องระบุทั้งจำนวนชิ้นและค่า `neoworld:coin_value` ให้ชัด เช่น Silver 1 ชิ้น มูลค่า100 ไม่ใช่100ชิ้น
- ตรวจไฟล์และเงื่อนไขเป็นหลัก ไม่เดินทดสอบเควสต์ในเกมทุกครั้ง ทดสอบในเกมเฉพาะเมื่อจำเป็นหรือผู้ใช้สั่ง และแยกสิ่งที่ตรวจแล้วออกจากสิ่งที่ยังไม่ตรวจ
- การแก้ข้อมูล NPC หรือเอกสารไม่ต้องคอมไพล์ หากต้องแก้โค้ด ให้ทำตามการอนุมัติของโครงการและรัน `compileJava` หลังแก้
