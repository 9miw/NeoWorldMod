# Monster EXP

มอนสเตอร์ในตาราง `MonsterExperienceRules.reward` ดรอปไอเทม NeoWorld EXP จำนวน 1 ชิ้นเมื่อผ่านเงื่อนไข ไม่มีเจ้าของไอเทม ผู้เล่นคนอื่นสามารถแย่งเก็บได้ สุ่มค่าเป็นจำนวนเต็มตั้งแต่ดรอปและบันทึกค่าแน่นอนลงไอเทม การรวมกองจึงไม่สุ่มใหม่ ไม่เปลี่ยน EXP ของ Minecraft

ไอเทมช่วงสุ่มที่มีอยู่เดิมหรือที่แอดมินกำหนดด้วย `expitem set` ยังรองรับ โดยสุ่มแต่ละชิ้นแยกกันตอนเก็บ ไม่ใช้ผลสุ่มเดียวคูณทั้งกอง ยอดรวมอิ่มตัวที่ Long.MAX_VALUE เมื่อเกินขอบเขต

## เงื่อนไข

- ดาเมจจากผู้เล่น Survival/Adventure รวมกันอย่างน้อย 50% ของเลือดสูงสุดของมอนสเตอร์
- นับเลือดที่ลดจริงหลังเกราะและ absorption ไม่รวม overkill, ดาเมจจากสัตว์เลี้ยง โกเลม เครื่องจักร หรือ Thorns
- ธนูและสกิลนับได้เมื่อ DamageSource ระบุผู้เล่นเป็นเจ้าของ
- ดาเมจจากผู้เล่นครั้งล่าสุดต้องไม่เกิน 300 game ticks (15 วินาทีที่ 20 TPS) ก่อนดรอป
- ถ้าเว้นการโจมตีจากผู้เล่นเกิน 300 ticks เริ่มนับดาเมจสะสมใหม่
- มอนสเตอร์จาก SPAWNER และ TRIAL_SPAWNER ใช้ช่วง EXP 25% ปัดลงเป็นจำนวนเต็ม ขั้นต่ำ 1 EXP
- สถานะสปอว์เนอร์คงอยู่หลังโหลดโลกใหม่ การแปลงร่าง และ Slime/Magma Cube แตกตัว แต่ไม่ส่งต่อดาเมจสะสม
- เคารพ `doMobLoot` และการยกเลิก LivingDropsEvent
- Vex, Warden, สัตว์ทั่วไป และชนิดมอนสเตอร์ที่ไม่อยู่ในตาราง ไม่ดรอปอัตโนมัติ

ค่าเริ่มต้น เช่น Zombie 80–120, Skeleton 120–180, Creeper 160–240 และ Witch 280–420 EXP สามารถปรับใน config ได้ตามหัวข้อถัดไป

## Config

NeoForge โหลดค่าจาก `config/neoworld/monster-experience.toml` เมื่อเปิดโลกหรือเซิร์ฟเวอร์ ไฟล์เดิมใน `config/neoworld-monster-experience.toml` จะย้ายอัตโนมัติหากยังไม่มีไฟล์ปลายทาง ค่าถูกกำหนดจากฝั่งเซิร์ฟเวอร์ ดู [ไฟล์ตัวอย่าง](config/neoworld-monster-experience.toml)

| ตัวเลือกใน `[monsterExperience]` | ค่าเริ่มต้น | ความหมาย |
|---|---:|---|
| `enabled` | `true` | เปิด/ปิดดรอป EXP ใหม่ ไอเทมที่มีอยู่แล้วใช้ได้เหมือนเดิม |
| `minimumPlayerDamagePercent` | `50.0` | เปอร์เซ็นต์ดาเมจผู้เล่นรวมขั้นต่ำ ปรับได้ 0–100; แม้ตั้ง 0 ยังต้องมีดาเมจจริงจากผู้เล่น |
| `combatWindowSeconds` | `15` | เวลาต่อสู้ในเกม ปรับได้ 1–3600 วินาที |
| `spawnerExpMultiplier` | `0.25` | ตัวคูณ EXP สปอว์เนอร์ ปรับได้ 0–100; 0=ปิด, 0.25=25%, 1=เต็ม |
| `rewards` | รายการเดิม | ช่วง EXP รายชนิด รวมถึงรหัสมอนสเตอร์จากม็อดอื่น |
| `levels` | เลเวลตามชนิด | เลเวลบนป้ายชื่อ 1–100; 0 หรือเอารายการออกเพื่อซ่อน |

แก้รายการใน `rewards` เช่น `"minecraft:zombie=100,200"` เพื่อให้ Zombie ดรอป 100–200 EXP ใช้ `"minecraft:zombie=0,0"` หรือเอารายการออกเพื่อปิดชนิดนั้น รายการว่างปิดทุกชนิด รหัสซ้ำใช้รายการท้ายสุด ช่วงที่เปิดต้องมี `1 <= ต่ำสุด <= สูงสุด`

Slime/Magma Cube ใช้ `@small`, `@medium`, `@large` เช่น `"minecraft:slime@large=100,150"` สำหรับขนาด 4 ขึ้นไป ขนาดเฉพาะมีผลก่อนค่าที่ระบุแค่รหัสชนิด Vex/Warden ปิดไว้ด้วย `0,0` เป็นค่าเริ่มต้น

ระบบอ่านค่าเมื่อโหลดหรือ reload config โดย NeoForge; ถ้าปิด config watcher ให้รีสตาร์ตเซิร์ฟเวอร์เพื่อใช้ค่าใหม่ การแก้ค่ามีผลกับการพิจารณาดรอปถัดไป ส่วนไอเทม EXP ที่ดรอปแล้วเก็บช่วงค่าของเดิมไว้

## ป้ายเลเวลเหนือหัว

รูปแบบ `[Lv. 3] Zombie` โดยเลเวลนำหน้าชื่อเดิมของมอนสเตอร์ ชื่อที่ผู้เล่นตั้งเองและชื่อแปลตามภาษาเกมยังใช้เหมือนเดิม แสดงในระยะ 32 บล็อก เคารพการซ่อนชื่อของทีม มอนสเตอร์ล่องหน การปิด HUD และการระงับป้ายชื่อโดยระบบอื่น

ปรับในรายการ `levels` ของ config เดิม เช่น `"minecraft:zombie=3"`, `"minecraft:slime@large=10"` หรือ `"minecraft:warden=90"` รายการว่างซ่อนป้ายเลเวลทั้งหมด ค่ารหัสชนิดทั่วไปเป็นค่า fallback ให้ขนาดที่ไม่ได้กำหนดเอง รหัสซ้ำใช้รายการท้ายสุด

ป้ายใช้ config ฝั่งเซิร์ฟเวอร์ที่ NeoForge ซิงค์ให้ไคลเอนต์ แสดงอย่างเดียว ไม่แก้ชื่อถาวร ไม่ทำให้มอนสเตอร์คงอยู่แทนการ despawn และไม่ปรับเลือด ดาเมจ หรือ EXP แม้ปิด `enabled` ของระบบดรอป EXP ป้ายเลเวลยังควบคุมแยกด้วย `levels` ได้

## ขอบเขต

ไม่มีเป้าหมายเวลาเก็บเลเวล ไม่มีการเพิ่มหรือล็อกทางเข้าโลกเลเวล 20 ในงานนี้ จุดเกิดที่ระบบอื่นเรียกด้วย SPAWNER/TRIAL_SPAWNER จะได้ 25% เช่นกัน; จุดเกิดแบบกำหนดเองต้องใช้แหล่งเกิดที่ตรงกับเจตนา

กติกานี้ลดฟาร์มที่เครื่องจักรฆ่าหรือทำให้เหลือเลือดแล้วตีปิด แต่ไม่สามารถตรวจจับมาโครโจมตีหรือฟาร์มที่ผู้เล่นทำดาเมจเองครบเงื่อนไขได้ทั้งหมด ข้อมูลการต่อสู้เก็บในหน่วยความจำ ไม่คงดาเมจเก่าหลัง unload/restart

## Verification

ใช้ `monsterExperienceRegressionTest` ทดสอบเกณฑ์ดาเมจ เวลา overkill และรางวัล พร้อม `compileJava` ก่อนส่งงาน ยังต้องทดสอบในเกมเรื่องดรอปจริง การแย่งเก็บ ธนู/สกิลจากม็อด สปอว์เนอร์ การแปลงร่าง และบอส
