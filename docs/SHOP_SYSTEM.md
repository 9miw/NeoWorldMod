# ระบบร้านค้าของเซิร์ฟเวอร์

Shop แยกจากตลาดกลาง ผู้ดูแลกำหนดสินค้าและราคา เลือกใช้ Silver หรือ Diamond จากระบบเงินเดิมได้ต่อรายการสินค้า
แต่ละรายการใช้สกุลเงินเดียวกันทั้งซื้อและขายคืน ไม่มีการแปลงเงินอัตโนมัติ สินค้าเดิมยังเป็น Silver
รองรับหลายร้านและ NPC หลายตัวต่อร้าน สต็อกในรุ่นนี้ไม่จำกัด ร้านใหม่เริ่มว่าง

## คำสั่ง

ผู้เล่น:

- `/neow shop` เลือกร้านจากชื่อและไอคอน
- `/neow shop open "ร้านอาวุธ"` เปิดด้วยชื่อร้าน หรือเลือกรหัสอัตโนมัติด้วย Tab
- ใช้ `/neoworld shop` แทน `/neow shop` ได้ ไม่มีคำสั่ง `/shop` เดี่ยว

ผู้ดูแล (ระดับ OP 2):

- `/neow shop admin open <ผู้เล่น> [ร้านค้า]` เปิด GUI ให้ผู้เล่น รองรับชื่อผู้เล่น, `@p`, `@a`; ไม่ระบุร้านเปิดหน้าเลือกร้าน
- `/neow shop admin create ร้านอาวุธ` สร้างร้านและรับรหัสอัตโนมัติ เช่น `shop_001`
- `/neow shop admin list` แสดงชื่อและรหัสร้านทั้งหมด
- `/neow shop admin add "ร้านอาวุธ" 100 25 อาวุธ` เพิ่มไอเทมที่ถือ ราคาซื้อ 100 / ขายคืน 25 Silver ต่อ **หนึ่งชิ้น** รวมข้อมูลไอเทมเดิม
- `/neow shop admin add "ร้านอาวุธ" 100 0` ขายอย่างเดียว; `0 25` รับซื้ออย่างเดียว
- `/neow shop admin add "ร้านอาวุธ" 100 25 silver อาวุธ` ระบุสกุลเงิน Silver
- `/neow shop admin add "ร้านอาวุธ" 10 2 silver อาวุธ` ใช้ Silver ทั้งซื้อและขายคืน
- `/neow shop admin add "ร้านอาวุธ" 5 1 diamond อาวุธ` ใช้ Diamond ทั้งซื้อและขายคืน
- ไม่ระบุสกุลเงินใช้ Silver ตามรูปแบบคำสั่งเดิม; หมวดหมู่หลังสกุลเงินไม่จำเป็นต้องใส่
- `/neow shop admin remove "ร้านอาวุธ" <หมายเลขสินค้า>` ลบรายการ ดูหมายเลขใน ทูลทิป สินค้า
- `/neow shop admin bind "ร้านอาวุธ" <NPC>` ผูก เอนทิตี ที่เลือกด้วย UUID หรือ ซีเล็กเตอร์ (ไม่ใช่ผู้เล่น)
- `/neow shop admin unbind <NPC>` ยกเลิกการผูก
- `/neow shop open "ร้านอาวุธ" <ผู้เล่น>` เปิดร้านให้ผู้เล่น ใช้จาก คอนโซล/NPC คำสั่ง ได้

ชื่อร้านในอาร์กิวเมนต์ใช้เครื่องหมายคำพูด โดยเฉพาะภาษาไทยหรือชื่อที่มีช่องว่าง
ถ้าชื่อซ้ำให้เลือกรหัสอัตโนมัติด้วย Tab ผู้ดูแลไม่ต้องตั้งรหัสเอง

ตัวอย่างในคอมมานด์บล็อก (ไม่ต้องใส่ `/` ด้านหน้า):

```text
neow shop admin open @p
neow shop admin open @p "ร้านอาวุธ"
neow shop admin open @a shop_001
```

ใช้คอมมานด์บล็อกแบบ Impulse เพื่อเปิดครั้งเดียวต่อการกดปุ่ม ผู้เล่นที่ตายหรืออยู่ ผู้ชม จะถูกข้าม
คำสั่งคืนค่าจำนวนผู้เล่นที่เปิด GUI ได้จริง ใช้ตรวจ ความสำเร็จ/ผลลัพธ์ ของคำสั่งได้

## ซื้อขาย

เลือกร้าน → เลือกสินค้า → เลือกจำนวน 1/16/64 → ตรวจยอดรวมบนปุ่ม → กดซื้อ/ขายคืน → กดยืนยันอีกครั้ง
ชี้ไอเทมเพื่อดูราคา หมวด และหมายเลขสินค้า เปลี่ยนหน้าได้ด้วยปุ่มลูกศร
หน้าร้านใช้กรอบและ แอตลาสวิดเจ็ต ของ Shop แยกจาก Market ตาม `docs/gui/shop/shop-compact-approved.png`
ไม่มีปุ่มร้านทั้งหมด เปลี่ยนหมวด รีเฟรช หรือยอดเงินคงเหลือในหน้าร้าน
ราคายาวแสดงแบบย่อบนปุ่ม/รายละเอียด และแสดงยอดเต็มใน ทูลทิป ก่อนยืนยัน
รับซื้อเฉพาะ ItemStack ที่ตรงทั้งชนิดและ คอมโพเนนต์ รวมชื่อ ความเสียหาย และ เอนชานต์
ใช้เฉพาะกระเป๋าหลักและ ฮอตบาร์ ไม่ขายของที่สวมใส่หรือ มือรอง
เงินไม่พอ กระเป๋าเต็ม ไอเทมไม่ครบ หรือเคอร์เซอร์มีของ จะไม่ทำธุรกรรม
สินค้าตัวอย่างในเมนูหยิบ โยน สลับ ลาก หรือ shift-click เอาออกมาไม่ได้
การเพิ่มสินค้าตรวจราคาข้ามร้านสำหรับ ItemStack และสกุลเงินที่ตรงกันเท่านั้น ราคาต่างสกุลไม่ถูกนำมาเปรียบเทียบเป็นตัวเลขเดียวกัน

## ที่เก็บข้อมูลและข้อจำกัด

สคีมา 8 เพิ่มตาราง `<prefix>shop_stores`, `shop_offers`, `shop_transactions` ในฐานข้อมูล NeoWorld เดิม
สคีมา 9 เพิ่ม `currency` ให้สินค้าและธุรกรรม และ `total_amount` ให้ธุรกรรม โดยรักษาราคาและประวัติ Silver เดิม
`total_silver` เป็นคอลัมน์เดิมสำหรับประวัติ Silver; ธุรกรรมเก่า Gold และธุรกรรม Diamond เก็บยอดจริงใน `total_amount` และเก็บ `total_silver=0`
รหัสร้านใช้ คีย์ที่สร้างอัตโนมัติ ของฐานข้อมูล; NPC เก็บรหัสร้านใน ข้อมูลเอนทิตีถาวร
การซื้อขายทำบน เธรดเซิร์ฟเวอร์ ใช้แผนกระเป๋าทั้งชุด และคืนเงิน/ไอเทมเมื่อบันทึกธุรกรรมล้มเหลว
บันทึกธุรกรรมใช้ ธุรกรรมฐานข้อมูล แต่กระเป๋าและเงินยังใช้ข้อมูลผู้เล่นของ Minecraft ตามระบบเดิม:
**ยังไม่รับประกัน การกู้คืนแบบอะตอมมิก ระหว่างฐานข้อมูลกับ เซฟผู้เล่น เมื่อ โปรเซสแครช/ไฟดับ**
ไม่มีการเพิ่มสต็อกจำกัด โควตารายวัน หรือเงื่อนไขเลเวลในรุ่นนี้

ตรวจด้วย `compileJava`, `shopRegressionTest`, และ `regressionTest`
ต้องตรวจหน้าจอ ซื้อขาย NPC การเชื่อมต่อใหม่ และ เซิร์ฟเวอร์แยก ในเกมเพิ่มเติม
