# คลังต้นไม้ NeoWorld

ใช้ maps/tree_library เดิม แทนต้นไม้เดิม 14 แบบด้วยชุด exsilit 370 แบบ ตามที่ผู้ใช้ยืนยัน 2026-10-23

พื้นที่ 1024 × 832 บล็อก พื้น Y64 เกิด 8 65 16 แถวเริ่ม Z24 ไปทาง +Z เรียงตามความสูงจากเล็กไปใหญ่ ป้ายรหัสอยู่บนพื้นด้าน +Z ของแต่ละแปลง

แปลงเผื่อรอบต้นอย่างน้อย 4 บล็อก มีทางเดินเชื่อม ใบไม้ persistent=true ป้องกันสลาย ไม่มี command block หรือคำสั่งจากโลกต้นฉบับ

แปลง legacy ID/metadata เป็น block state 1.21.1; ท่อนไม้ bark ใช้ wood บล็อกสีและของตกแต่งคงชนิดเดิม ต้นที่ไม่มีใบไม่ได้เติมใบใหม่ ไฟล์ structures/t001.nbt–t370.nbt มีเฉพาะบล็อกต้น ไม่รวมพื้นและป้าย จุดวางเป็นมุมต่ำสุดของ copyBounds ไม่ใช่กึ่งกลางลำต้น

แหล่งที่มา: https://www.planetminecraft.com/project/tree-bundle-370-custom-trees-download/ โดย exsilit

พิกัดแปลง ขอบเขตคัดลอก ขนาด และไฟล์แยกต้นอยู่ใน catalog.json; รายละเอียดวัสดุและรูปทรงอยู่ downloads/exsilit-tree-repository/TREE-CATALOG.md

ยังไม่ทดสอบในเกมจริง
